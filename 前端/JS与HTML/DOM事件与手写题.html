DOM 事件与手写题

适用岗位：前端（笔试输出 + 面试手写必考） ｜ 形态：知识点 + 可运行手写实现（node 实跑核对） ｜ 更新：2026-09-30
要点速记：事件流三阶段 捕获 → 目标 → 冒泡；addEventListener 第三参缺省走冒泡，{capture:true} 走捕获；事件委托把 N 个子元素监听合并成父容器 1 个，靠 e.target 认触发源；preventDefault 管默认行为、stopPropagation 管传播，互不替代；防抖 = 停手才执行（搜索框输入），节流 = 固定频率执行（scroll/resize），timer/last 都存在闭包里；深拷贝思路 = 递归逐字段复制，JSON.parse(JSON.stringify) 快但函数/undefined 丢失、Date 变字符串、循环引用报错。

一、知识点梳理

事件流三阶段：一个事件从 window 沿 DOM 树向下找目标（捕获）→ 到达目标元素（目标阶段）→ 再沿原路向上回 window（冒泡）。addEventListener 的第三参决定监听器在哪个阶段触发。

JavaScript 
el.addEventListener('click', fn);              // 第三参缺省（falsy）→ 冒泡阶段
el.addEventListener('click', fn, true);        // 布尔 true → 捕获阶段
el.addEventListener('click', fn, { capture: true, once: true, passive: true });
// once: 触发一次后自动移除；passive: 承诺不调 preventDefault，scroll 性能优化

事件委托：利用冒泡，把子元素的监听统一挂到父容器上，用 e.target 判断真正被点的元素。好处：① 省监听器——1000 个列表项只要 1 个监听器，省内存；② 动态新增的子元素无需重新绑定。两个对象别记反：

对象指向委托场景下的值
e.target真正触发事件的元素被点击的子元素（如 li）
e.currentTarget绑定监听器的元素父容器（如 ul）

preventDefault vs stopPropagation：preventDefault 取消默认行为（a 跳转、表单提交、右键菜单），事件照常传播；stopPropagation 阻断捕获/冒泡继续传播，默认行为照常发生。两者互不包含，要同时阻止就都调。

手写防抖 debounce（完整可运行，本机 node 实跑核对：连续调用 d(1) d(2) d(3)，50ms 后只输出 debounce:3）：

JavaScript 
// 防抖：最后一次触发后停顿 delay 才执行（清掉上一次计时，只认最后一次）
function debounce(fn, delay) {
  let timer = null;                        // 状态存在闭包里，多次触发共享
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

手写节流 throttle（完整可运行，实跑核对：每 20ms 调一次共 7 次、窗口 50ms，触发 0、3、6 三次）：

JavaScript 
// 节流：每 interval 最多执行一次（时间戳版）
function throttle(fn, interval) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= interval) {
      last = now;
      fn.apply(this, args);
    }
  };
}

区别一句话 + 场景配对：防抖是"等你停手才执行"（只认最后一次），节流是"固定频率执行"（稀释频率）。搜索框输入联想用防抖（停手 300ms 再发请求，省一半接口）；scroll/resize 监听用节流（页面滚动过程中要保持响应，不能等停手）。

场景选型理由
搜索框输入联想 / 自动保存草稿防抖只要最终态，中间过程都可以丢弃
scroll 懒加载 / resize 重算布局节流过程也要响应，但要稀释到固定频率

手写深拷贝思路一句：递归遍历，引用类型逐字段复制、原始类型直接赋值，按类型分支处理 Date/RegExp/Map/Set。JSON.parse(JSON.stringify(obj)) 是偷懒版，局限：函数、undefined、Symbol 属性直接丢失（实跑核对：{f:()=>1, u:undefined} 转回来 Object.keys 长度是 0）、Date 变字符串、NaN/Infinity 变 null、循环引用直接报错、原型链丢失。

三、示例题目（点击选项即时判分）

单选1. 用事件委托把 click 监听挂在 ul 上，点击其中的 li 时（  ）

A. e.target 和 e.currentTarget 都指向 li
B. e.target 指向 li，e.currentTarget 指向 ul
C. e.target 指向 ul，e.currentTarget 指向 li
D. 委托模式下不存在 e.target
答案 B。e.target 是真正触发事件的元素（被点的 li），e.currentTarget 是绑定监听器的元素（ul）；事件委托正是靠 e.target 认出"点的是谁"。事件流三阶段为浏览器行为，按 DOM 规范：捕获 → 目标 → 冒泡。来源：牛客经典题。

多选2. 关于事件流与事件监听，正确的有（  ）

A. 事件流三阶段顺序：捕获 → 目标 → 冒泡
B. addEventListener 第三参缺省时，监听器在冒泡阶段触发
C. 调用 stopPropagation 之后，a 链接的默认跳转也会被取消
D. 事件委托能把 N 个子元素的监听合并成父容器上的 1 个
答案 ABD。stopPropagation 只阻断传播，取消默认行为要 preventDefault——两者互不替代，C 错。A、B 是浏览器行为，按 DOM 规范。来源：JavaGuide 收录题型。

单选3. 搜索框输入联想（希望停手 300ms 才发请求）与 scroll 触发懒加载（希望滚动中每 200ms 最多处理一次），应分别使用（  ）

A. 都用防抖
B. 都用节流
C. 防抖 / 节流
D. 节流 / 防抖
答案 C。防抖 = 最后一次触发后停顿才执行，适合"只要最终态"的搜索框输入；节流 = 固定频率执行，适合"过程也要响应"的 scroll/resize。记法：防抖保尾、节流控频。来源：面试高频改编。

输出判断4. 下面代码的输出是（  ）

JavaScript 
const src = { x: 1, nested: { y: 2 } };
const copy = JSON.parse(JSON.stringify(src));
copy.nested.y = 99;
console.log(src.nested.y);
console.log(Object.keys(JSON.parse(JSON.stringify({ f: () => 1, u: undefined }))).length);
A. 99 / 2
B. 1 / 0
C. 1 / 2
D. 99 / 0
答案 B。本机 node 实跑：1、0。JSON.parse(JSON.stringify) 复制时已断开嵌套引用，改 copy 不影响 src；但它会静默丢弃函数和值为 undefined 的属性（还有 Symbol、Date 变字符串、循环引用报错）——所以转回来的对象一个键都不剩，这正是手写深拷贝存在的理由。来源：面试高频改编。

面试口述5. 现场手写防抖 debounce，并说明它和节流的区别。

参考回答思路：闭包保存 timer，每次触发先 clearTimeout 推翻上一次计时，再 setTimeout 一个新的——只认最后一次，停满 delay 才真正执行。
function debounce(fn, delay) { let timer = null; return function (...args) { clearTimeout(timer); timer = setTimeout(() => fn.apply(this, args), delay); }; }
区别一句话：防抖是"等你停手才执行"（只留最后一次），节流是"固定频率执行"（每 interval 最多一次）。选型：搜索框输入联想用防抖——只要最终关键词；scroll 懒加载用节流——滚动过程中要保持响应。加分点：this 与参数用 fn.apply(this, args) 保留；可提节流的时间戳版与定时器版差异。来源：牛客经典题。

四、易错点小结

① e.target ≠ e.currentTarget：委托场景前者是子元素、后者是挂监听的父容器；② preventDefault 管默认行为、stopPropagation 管传播，互不替代；③ 防抖节流的 timer/last 必须存在闭包里——写在全局会互相污染，写在函数里每次新建就失效了；④ JSON 深拷贝五宗罪：函数/undefined/Symbol 丢失、Date 变字符串、NaN/Infinity 变 null、循环引用报错、原型丢失；⑤ 第三参既能传布尔也能传 options 对象，capture: true 才走捕获；⑥ scroll 监听可加 { passive: true } 提升性能（实现细节）。
