CSS 布局基础：盒模型 / BFC / Flex

适用岗位：前端（笔试选择 + 计算题） ｜ 形态：知识点 + 盒模型计算 + 居中方案 ｜ 更新：2026-09-30
要点速记：盒模型两模式——content-box 实占宽 = width + padding + border，border-box = width（内容被压缩），工程惯例全局 * { box-sizing: border-box }；BFC 独立渲染区域：触发记 float / absolute·fixed / inline-block / flow-root / overflow 非 visible，解决 margin 塌陷、浮动高度塌陷；Flex：justify-content 主轴、align-items 交叉轴，flex:1 = 1 1 0%（完全均分），flex:auto = 1 1 auto（先按内容再分剩余）；居中三大流派：flex / grid / absolute+translate；position 四种：static / relative / absolute / fixed。

一、知识点梳理

盒模型两种模式：标准盒模型 content-box（CSS 默认）里 width 只含内容区；IE 盒模型 border-box 里 width 已包含 padding 和 border。

模式width 指什么元素实际占宽（width:100px; padding:10px; border:5px）
content-box（默认）仅内容区100 + 10×2 + 5×2 = 130px
border-box内容 + padding + border100px（内容区被压到 70px）
CSS 
.box { width: 100px; padding: 10px; border: 5px solid #000; }
/* content-box：总宽 130px；border-box：总宽 100px */
/* 工程惯例：全局走 border-box，写多大就是多大 */
*, *::before, *::after { box-sizing: border-box; }

BFC（块级格式化上下文）：一块独立的渲染区域，内部布局不影响外部。触发条件（满足其一）：根元素 html；float 非 none；position 为 absolute / fixed；display 为 inline-block / flow-root / table-cell / flex；overflow 为 hidden / auto / scroll（visible 除外）。它解决三件事：① 父子 margin 塌陷——父元素内部第一个子元素的 margin-top 会"顶出"父元素，把父元素变成 BFC（overflow:hidden 或 display:flow-root）即可包住；② 浮动导致父元素高度塌陷——BFC 计算高度时会包含浮动子元素；③ 相邻元素垂直 margin 合并——各自包进不同 BFC 后不再合并。

Flex 常用属性：容器的 justify-content 管主轴对齐（flex-start / center / space-between），align-items 管交叉轴对齐，另有 flex-direction（row 默认水平、column 主轴变垂直）、flex-wrap、gap；项目的 flex 是缩写：flex:1 = flex-grow:1 + flex-shrink:1 + flex-basis:0%——基准为 0，剩余空间完全按比例均分；flex:auto = 1 1 auto——基准按内容宽度，先满足内容再分剩余。一句区别：flex:1 无视内容均分，flex:auto 保内容优先。

水平垂直居中至少三种（子元素尺寸未知时前三种都成立）：

CSS 
/* 1. Flex（首选） */
.parent { display: flex; justify-content: center; align-items: center; }
/* 2. Grid（最短写法） */
.parent { display: grid; place-items: center; }
/* 3. 绝对定位 + transform（不脱文档流也要配合父 relative） */
.parent { position: relative; }
.child  { position: absolute; left: 50%; top: 50%; transform: translate(-50%, -50%); }
/* 4. 绝对定位 + margin:auto（四角归零） */
.child  { position: absolute; inset: 0; margin: auto; width: fit-content; height: fit-content; }

position 四种：

值定位基准是否脱离文档流
static默认值，不参与定位否
relative相对自身原本位置偏移否（原占位保留）
absolute相对最近的非 static 祖先是
fixed相对浏览器视口是

补充（加分项）：sticky 粘性定位——相对最近的滚动祖先，滚到阈值前按 relative、之后固定（实现细节）。

二、考点说明

笔试选择计算题面试口述

  • 笔试：盒模型两种模式下的总宽计算（给 width/padding/border 算实占宽）、BFC 触发条件判断、Flex 属性归属（主轴/交叉轴、flex 缩写展开）。
  • 面试口述：BFC 是什么、怎么触发、解决什么问题；水平垂直居中至少说三种；position 四种差异。
  • 追问储备：为什么工程上全局 border-box（心智模型简单，写多大就是多大）；margin 塌陷只发生在垂直方向相邻块级元素；flex:1 与 flex:auto 的 basis 差异。

三、示例题目（点击选项即时判分）

单选1. 下列哪一项能创建 BFC（块级格式化上下文）？（  ）

A. overflow: visible
B. display: inline-block
C. position: relative
D. float: none
答案 B。触发记法：float 非 none、absolute/fixed、inline-block/flow-root/table-cell/flex、overflow 非 visible。overflow:visible 是默认值不触发；position:relative 不脱流不触发；float:none 等于没浮动。来源：牛客经典题。

单选2. 父元素与子元素尺寸都不确定，要做水平垂直居中，最直接可靠的方案是（  ）

A. 父元素 display:flex + justify-content:center + align-items:center
B. 子元素 margin: 0 auto
C. 子元素 position:absolute + left:50% + top:50%
D. 父元素 text-align:center + 子元素 line-height:100px
答案 A。B 只能水平居中；C 只把子元素左上角定位到中心点，还要补 transform:translate(-50%,-50%) 才算居中；D 要求固定行高且只适合单行文本。flex 两条属性对齐主轴与交叉轴，天然适配未知尺寸。来源：面试高频改编。

多选3. 关于 Flex 布局，正确的有（  ）

A. justify-content 控制主轴对齐，align-items 控制交叉轴对齐
B. flex:1 等价于 flex-grow:1; flex-shrink:1; flex-basis:0%
C. flex:1 与 flex:auto 的差异在 flex-basis：0% 完全均分，auto 先按内容分配
D. flex-direction: column 后主轴变为水平方向
答案 ABC。flex-direction:column 把主轴变为垂直方向（row 才是水平），D 错。flex:1 的 basis 是 0%——无视内容完全按比例均分；flex:auto 的 basis 是 auto——先按内容宽度占位再分剩余。来源：面试高频改编。

计算4. 元素样式为 width: 100px; padding: 10px; border: 5px solid #000; margin: 4px;。分别在 box-sizing 为 content-box 与 border-box 两种模式下，计算该元素实际占据的水平宽度（含 margin），并说明 border-box 下内容区宽度是多少。按 CSS 规范作答。

先自己算，再展开对答案content-box：width 只指内容区，总占宽 = 100（内容）+ 10×2（padding）+ 5×2（border）+ 4×2（margin）= 138px。border-box：width 已含内容 + padding + border，元素本体就是 100px，加 margin 后总占宽 = 100 + 4×2 = 108px；此时内容区被压缩为 100 − 20 − 10 = 70px。记忆口径：content-box 加法越加越大，border-box 写多大是多大。来源：JavaGuide 收录题型。

面试口述5. BFC 是什么？怎么触发？能解决什么问题？

参考回答BFC（块级格式化上下文）是一块独立的渲染区域，内部元素的布局不影响外部。触发条件挑顺手的记：overflow: hidden / auto、display: flow-root（专为触发 BFC 设计，无副作用）、display: inline-block、float 非 none、position: absolute/fixed。解决三类问题：① 父子 margin 塌陷——父元素变 BFC 就能包住子元素的 margin-top；② 浮动导致父元素高度塌陷——BFC 的高度计算包含浮动子元素；③ 相邻元素垂直 margin 合并——各自包进 BFC 后不再合并。加分点：overflow:hidden 有裁剪内容的副作用，推荐 display:flow-root；两栏布局中给右侧文字区触发 BFC 也能防环绕。来源：牛客经典题。

四、易错点小结

① content-box 是默认值，别想当然以为写的 width 就是最终占宽——还有 padding 和 border 要加；② margin:0 auto 只水平居中，垂直方向要 flex/grid/translate；③ absolute 定位的基准是"最近的非 static 祖先"，父元素没设 relative 就会一路找到视口；④ BFC 不会让两个 BFC 之间的垂直 margin 合并，但同一个 BFC 内相邻块级会合并；⑤ flex:1 均分的前提是 basis 0%，别和 flex:auto（basis auto）背反；⑥ 盒模型计算题属于 CSS 规范题，按规范作答即可，无需实跑。
