SVM 速览

适用岗位：AI/算法笔试 ｜ 关联页：LR 与正则化 ｜ 更新：2026-09-30
要点速记：SVM 找间隔最大的分隔超平面，只有落在间隔边界上的支持向量决定它（解稀疏）。线性不可分 → 软间隔（松弛 $\xi$ + 惩罚 C）→ 核技巧把样本映到高维。C 大=更看重训练正确（易过拟合），C 小=间隔更宽（易欠拟合）。常与 LR 对比：hinge loss vs 交叉熵、无概率输出、对归一化与核更敏感。

一、知识点梳理

间隔最大化。超平面 $w^\top x+b=0$，样本到它的函数间隔为 $y(w^\top x+b)$。SVM 的目标是最大化「最近的点离平面」的距离：$\max \dfrac{2}{\|w\|}$（几何间隔），等价于 $\min \dfrac{1}{2}\|w\|^2$ s.t. $y_i(w^\top x_i+b)\ge 1$——一个凸二次规划。距离超平面最近、恰好卡在 $y(w^\top x+b)=1$ 边界上的样本就是支持向量；最终解只由它们决定，其余样本删掉不影响模型（解的稀疏性，来自 hinge 损失在间隔外为 0）。

软间隔。线性不可分/有噪声时引入松弛变量 $\xi_i\ge 0$ 与惩罚系数 C：

$$\min \frac{1}{2}\|w\|^2 + C\sum_i \xi_i \quad \text{s.t.}\ y_i(w^\top x_i+b)\ge 1-\xi_i$$

C 大 → 对错分惩罚重、间隔窄、易过拟合；C 小 → 容忍错分、间隔宽、易欠拟合。

对偶与核技巧。拉格朗日对偶把约束转为对 α 的对偶问题（KKT 条件下多数 $\alpha_i=0$，只剩支持向量），且样本只以内积 $x_i^\top x_j$ 出现——用核函数 $K(x_i,x_j)$ 直接替换内积，等价于隐式映射到高维再线性分（不显式构造映射）。常用核：

核形式适用
线性核$x_i^\top x_j$特征多、样本大、本就近似线性可分（文本）
多项式核$(\gamma x_i^\top x_j + r)^d$需要交互特征，d 大易过拟合
RBF/高斯核$\exp(-\gamma\|x_i-x_j\|^2)$默认首选；γ 大 → 方差小易过拟合

SMO：每次只优化两个 α（固定其余）、解析求解，是实用求解器。回归版 SVR 用 ε-不敏感损失（管道内的点不计损失）。NN 时代 SVM 的实用场景收窄，但概念题永远在考。

二、考点说明

SVM 是「概念密度最高」的一页，选择题全从这里出：① 支持向量的定义与解的稀疏性；② C 与 γ 各自调大意味着什么（C 大过拟合、γ 大过拟合——双重"大就过拟合"最易混）；③ 为什么要对偶（内积形式 → 核技巧可行）；④ 核函数合法性（Mercer 条件：半正定）；⑤ SVM vs LR 表格对比；⑥ 为什么 SVM 对缺失/大规模数据不友好（核矩阵 O(n²)）。

概念自测点击选项即时判分。

单选1. 关于支持向量，正确的说法是（  ）

A. 所有训练样本都参与决定最终超平面
B. 支持向量是被分错的样本
C. 支持向量是位于间隔边界（或越界）上、使约束取等号的样本，最终解只由它们决定
D. 支持向量就是距离超平面最远的样本
答案 C。hinge 损失在间隔外为 0，对应对偶里 α=0，删除这些样本模型不变——这是 SVM 解稀疏的来源。来源：面试高频改编。

单选2. 软间隔 SVM 中把惩罚系数 C 调得非常大，最可能发生的是（  ）

A. 几乎不允许错分，间隔被压得很窄，训练集拟合好但容易过拟合
B. 间隔变宽，模型更平滑
C. 等价于把 w 的 L2 惩罚加强
D. 核函数自动退化为线性核
答案 A。C 大 → ξ 代价高 → 硬间隔化。B/D 无关联；加强 $\|w\|$ 惩罚是调小 C。来源：牛客经典题。

多选3. 关于对偶问题与核技巧，正确的有（  ）

A. 对偶形式里样本只以内积 $x_i^\top x_j$ 出现，这使核函数替换内积成为可能
B. 核函数 $K(x_i,x_j)$ 等价于把样本隐式映射到高维空间后做内积，不必显式写出映射 φ
C. 任何对称函数都可以当核函数用
D. 对偶解中大多数 $\alpha_i=0$，只有支持向量对应 α 非零
答案 ABD。合法核需满足 Mercer 条件（ Gram 矩阵半正定），对称不够，C 错。来源：面试高频改编。

三、示例题目

单选1. SVM 与逻辑回归对比，错误的是（  ）

A. SVM 用 hinge 损失、LR 用（对数）交叉熵损失
B. LR 天然输出概率，SVM 输出的是决策值，要另接 Platt scaling 才有概率
C. 两者都能加核，且在大规模样本（10⁷ 级）下核 SVM 训练比 LR 快
D. 两者都是凸优化问题，全局最优有保证
答案 C。C 是错误说法：核 SVM 要计算并存储核矩阵，O(n²) 的内存与训练开销，大规模样本反而慢，此时用线性 SVM 或 LR。A/B/D 均正确。来源：面试高频改编。

四、易错点小结

① C 和 γ 都调大都会过拟合，但作用位置不同（C 管错分代价、γ 管 RBF 局部性）；② 支持向量不一定被分对——间隔边界上的正确样本与越界的样本都算；③ 核技巧 = 高维内积的省算力写法，不是「降维」；④ 缺失值要处理（SVM 无原生机制），特征要标准化（距离/内积敏感）；⑤ hinge 损失的「稀疏」与 L1 的「稀疏」是两回事：前者指参与训练的样本少，后者指特征权重为 0。
