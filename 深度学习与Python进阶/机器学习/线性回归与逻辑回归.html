线性/逻辑回归与正则化

适用岗位：AI/算法、数据分析、后端笔试 ｜ 关联页：评价指标 ｜ 更新：2026-09-30
要点速记：线性回归拟合连续值（MSE 损失，闭式解或梯度下降）；逻辑回归 = 线性模型 + sigmoid 做二分类，损失是交叉熵不是 MSE，梯度统一为 $X^\top(p-y)/m$。正则化：L2（Ridge，平滑、有闭式解）压权重，L1（Lasso，稀疏）做特征选择。面试钉子户：LR 为什么不用 MSE——非凸 + 饱和区梯度消失。

一、知识点梳理

线性回归：模型 $\hat{y} = w^\top x + b$，损失用均方误差 $L=\frac{1}{m}\sum(\hat{y}_i-y_i)^2$。两条求解路：

  • 闭式解（正规方程）$w=(X^\top X)^{-1}X^\top y$——$X^\top X$ 不可逆时（特征共线、n<d）要加 $\lambda I$ 变成岭回归；O(d³)，特征多时算不动。
  • 梯度下降——特征要标准化，否则不同量纲导致等高线椭圆极扁，收敛慢。

逻辑回归：在线性输出上加 sigmoid $p=\sigma(z)=\dfrac{1}{1+e^{-z}}$，把任意实数压到 (0,1) 当概率。从伯努利似然出发，最大化对数似然等价于最小化交叉熵：

$$L=-\frac{1}{m}\sum_{i=1}^{m}\Big[y_i\log p_i+(1-y_i)\log(1-p_i)\Big]$$

其对 w 的梯度出奇地简洁：

$$\frac{\partial L}{\partial w}=\frac{1}{m}X^\top(p-y)$$

（与线性回归 + MSE 的梯度形式一致，记忆点）。决策边界 $w^\top x+b=0$ 仍是线性的——LR 是线性分类器，非线性要靠特征变换。它输出的是概率、损失处处可导且凸，这是相对 MSE 的关键优势。

正则化：

方法惩罚项效果一句话记忆
L2 / Ridge$+\lambda\|w\|_2^2$权重整体缩小、解平滑稳定圆约束，权重衰减；$X^\top X+\lambda I$ 恒可逆
L1 / Lasso$+\lambda\|w\|_1$部分权重精确为 0菱形约束顶点在轴上 → 稀疏，可做特征选择
弹性网两者加权兼顾特征多且相关时用

$\lambda$ 越大惩罚越重 → 权重越小、模型越简单；过头就是欠拟合。LR 实现里（如 sklearn）正则系数常写成倒数 C=1/λ。

二、考点说明

这是 ML 笔试/面试的第一梯队高频：① 为什么 LR 用交叉熵不用 MSE（非凸 + $\sigma'$ 饱和让梯度消失）；② L1 为什么稀疏（几何顶点 / 次梯度在 0 处不归零）；③ LR 要不要特征标准化（梯度下降要，共线特征配合 L2）；④ 手推交叉熵梯度（$X^\top(p-y)/m$，写得出来直接过）；⑤ 生成式 vs 判别式的对比里 LR 是判别式代表（朴素贝叶斯是生成式）。

概念自测点击选项即时判分。

单选1. 逻辑回归不用 MSE 而用交叉熵做损失，主要原因是（  ）

A. MSE 计算量更大
B. MSE 无法对 w 求导
C. MSE + sigmoid 是非凸函数（有局部极小），且 p 接近 0/1 时 σ′≈0 导致梯度消失；交叉熵是凸的且梯度含 1/p 因子抵消饱和
D. MSE 只能用于回归问题，语法上不允许
答案 C。交叉熵梯度 $p-y$ 不含 σ′，sigmoid 饱和时仍能正常更新；MSE 梯度多乘 σ′，错分严重（饱和区）时反而几乎不更新。来源：面试高频改编。

单选2. L1 正则化能得到稀疏解（部分权重恰为 0），从几何上看是因为（  ）

A. L1 的惩罚值比 L2 小
B. L1 约束域是菱形（有棱角），最优解倾向落在坐标轴的顶点上，对应某些权重为 0；L2 约束域是圆，最优解一般不在轴上
C. L1 只能用于线性回归，L2 只能用于逻辑回归
D. L1 使损失函数变成凸函数而原来不是
答案 B。棱角顶点是 L1 稀疏性的经典几何解释；等高线最先碰到约束域的位置多在顶点。来源：面试高频改编。

多选3. 关于正则化，说法正确的有（  ）

A. 特征共线导致 $X^\top X$ 不可逆时，加 L2 后 $X^\top X+\lambda I$ 可逆，闭式解稳定
B. L1 可顺带做特征选择
C. $\lambda$ 越大，训练误差一定越小
D. 正则化是在经验风险上加模型复杂度惩罚，对应结构风险最小化
答案 ABD。$\lambda$ 大 → 模型被压简单 → 训练误差通常上升，验证误差先降后升，C 错。来源：牛客经典题。

三、示例题目

计算1. 单个样本：特征 $x=1$、标签 $y=1$，参数 $w=0,\ b=0$，学习率 $\eta=0.1$。求一步梯度下降后 w 更新为多少？

解答

$p=\sigma(0)=0.5$；梯度 $\partial L/\partial w=(p-y)\cdot x=(0.5-1)\times 1=-0.5$；更新 $w \leftarrow 0-0.1\times(-0.5)=0.5$。来源：AI 岗笔试高频。

计算2. 样本标签 y=1，模型输出 p=0.3。求交叉熵损失 $-\log p$ 的值与梯度方向（p 应变大还是变小）。

解答

$L=-\ln 0.3\approx 1.204$。对正样本梯度 $p-y=0.3-1=-0.7$，参数沿负梯度更新使 $w^\top x$ 增大、p 变大、损失下降。p 越接近 0 错得越狠，$-\ln p\to\infty$ 惩罚陡增。来源：AI 岗笔试高频。

口述3. 手推 LR 交叉熵对 w 的梯度，并说出为什么这个形式「好」。

解答

$L=-[y\log p+(1-y)\log(1-p)]$，$\partial L/\partial z = -y/p + (1-y)/(1-p)$，而 $\partial z/\partial w = x$；代入 $\sigma'(z)=p(1-p)$ 链式化简后 $\partial L/\partial w=(p-y)x$。m 个样本取平均即 $X^\top(p-y)/m$。好处：① 形式与线性回归一致好记；② 不含 $\sigma'$，sigmoid 饱和时梯度不消失。来源：面试高频改编。

四、易错点小结

① 「LR 是线性模型」指决策边界线性，不指输出线性；② L1 稀疏 ≠ L1 惩罚小，是几何顶点效应；③ 正则化惩罚的是 w 不含 b（sklearn 同款约定）；④ λ 越大越欠拟合，sklearn 的 C=1/λ 越大越不惩罚，两个方向别背反；⑤ 标准化只在用梯度下降/距离/正则的模型前做，纯闭式解不影响结果（只影响数值稳定）。
