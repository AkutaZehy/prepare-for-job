评价指标与样本不平衡

适用岗位：AI/算法、数据分析、测开笔试 ｜ 关联页：LR 与正则化、经典模型补遗 ｜ 更新：2026-09-30
要点速记：Precision=查准（报出来的有多少是对的），Recall=查全（该找的找回来多少），F1 是调和平均。ROC 曲线以 TPR-FPR 画、AUC 与阈值无关，概率解释 = 随机取一正一负、正样本得分更高的概率。类别不平衡时 ROC 偏乐观，看 PR 曲线；accuracy 在 99:1 时是骗人的。不平衡应对四件套：重采样（SMOTE）、类别权重、阈值移动、focal loss。手撕 AUC 见手撕子夹的 手撕 AUC 页。

一、知识点梳理

混淆矩阵（二分类，正类是关注类）：

预测正预测负
真实正TPFN（漏报）
真实负FP（误报）TN

$$P=\frac{TP}{TP+FP}\qquad R=\frac{TP}{TP+FN}\qquad F1=\frac{2PR}{P+R}\qquad Acc=\frac{TP+TN}{全部}$$

P 与 R 天然此消彼长（调阈值），按业务取舍：垃圾邮件重 P（宁漏勿误杀），癌症筛查/风控欺诈重 R（宁误杀勿漏）。多分类用 macro（各类等权）/micro（按样本）/weighted 平均。

ROC 与 AUC：横轴 FPR=FP/(FP+TN)，纵轴 TPR=Recall。把验证集按模型得分降序逐点画出来。AUC 的概率解释：随机抽一个正样本和一个负样本，正样本得分更高的概率；0.5 = 随机猜，1 = 完美。AUC 不依赖阈值，只看得分排序，所以跨模型、跨阈值可比。

PR vs ROC：不平衡数据（正类极少）下，FP 被海量 TN 稀释、FPR 变化迟钝 → ROC/AUC 偏乐观；PR 曲线对「正类抓得准不准」更敏感，此时应看 PR-AP（average precision）。

样本不平衡的应对：

路线做法注意
重采样少数类过采样（SMOTE 插值造样本）/ 多数类欠采样只在训练集做，验证/测试集保持原分布
代价敏感类别权重 / 损失加权sklearn 的 class_weight='balanced'
阈值移动训练不动，预测阈值从 0.5 下调零成本，按业务点选阈值
专用损失Focal Loss（降易分样本权重）目标检测标配

回归指标一句带过：MAE（稳健）/ MSE（罚大错）/ RMSE / $R^2$；排序与检测岗位再看 mAP/NDCG。

二、考点说明

评价类题目是测开/AI 岗笔试的必送分题，但年年有人栽：① 给混淆矩阵算 P/R/F1（手算，别背反分子分母）；② 99:1 场景 accuracy 的陷阱；③ AUC 的两种解释（概率解释 / 排序不变性）与「阈值无关」；④ 不平衡时选 PR 还是 ROC；⑤ 重采样只能在训练集做的泄漏常识；⑥ 「召回率上升 precision 一定下降吗」——阈值单调动下是趋势，但不是数学必然，答「通常此消彼长」。

概念自测点击选项即时判分。

单选1. 欺诈检测数据 10000 条，欺诈 100 条。模型把所有样本都判为「正常」，则（  ）

A. accuracy=99%，但欺诈召回率=0%，模型毫无价值——不平衡场景必须看 P/R/F1 或 AUC/PR
B. accuracy=99%，模型已经很好
C. precision=99%，模型很好
D. AUC=0.99，模型很好
答案 A。TP=0、FN=100 → R=0；FP=0、TN=9900 → Acc=99%。精确率 0/0 无定义，AUC 由全同分模型=0.5。来源：面试高频改编。

单选2. AUC=0.8 的含义，最准确的解释是（  ）

A. 准确率 80%
B. 召回率 80%
C. 随机取一正一负两个样本，正样本预测分更高的概率是 0.8（等价于按得分排序把正样本排在负样本前面的能力）
D. 前 80% 的高分样本都是正样本
答案 C。这就是 AUC 的概率（Mann-Whitney U）解释，与阈值无关。D 混淆了 precision@k。来源：牛客经典题。

多选3. 处理类别不平衡，做法正确的有（  ）

A. SMOTE 过采样只在训练集上做，验证/测试集保持原始分布
B. 训练时给少数类更大损失权重（class_weight）
C. 先把测试集过采样到 1:1，再报告 F1
D. 业务允许时直接下调判决阈值（阈值移动），训练过程可以不动
答案 ABD。测试集必须反映真实分布，动测试集=自欺欺人，指标失真，C 错。来源：面试高频改编。

三、示例题目

计算1. 混淆矩阵：TP=40，FP=10，FN=20，TN=30。求 Precision、Recall、F1（两位小数）。

解答

$P=40/(40+10)=0.80$；$R=40/(40+20)\approx 0.67$；$F1=2\times0.8\times0.6667/(0.8+0.6667)\approx 0.73$。口算技巧：F1 介于 P 与 R 之间且偏向小者（调和平均）。来源：牛客经典题。

计算2. 某模型得分排序（降序）及真实标签：正、正、负、正、负。求 AUC。

解答

逐对计数：3 正 2 负共 6 对。排名 1、2、4 的正样本与排名 3、5 的负样本组成对：(1,3)✓ (1,5)✓ (2,3)✓ (2,5)✓ (4,3)✗（负在前）(4,5)✓ → 5/6 ≈ 0.833。正负得分并列时各记 0.5（平均秩处理）。来源：AI 岗笔试高频。

口述3. 正负样本 1:1000，你的老板问「模型效果怎么样」，你报哪些指标、为什么不报 accuracy？如果要部署，阈值怎么定？

解答

报：PR 曲线与 AP、AUC（排序能力）、在业务选定阈值下的 P/R/F1；召回率必须单报。不报 accuracy：全猜负类就有 99.9%，无信息量。阈值按业务代价定——漏报成本高就把阈值压低换召回，误杀成本高则相反；也可直接报「达到目标召回 90% 时精确率是多少」。来源：面试高频改编。

四、易错点小结

① P 的分母是「预测正」（TP+FP），R 的分母是「真实正」（TP+FN），背混就全错；② AUC 与阈值无关但与类别分布的排序关系有关，不平衡场景 PR 更诚实；③ ROC 曲线是「逐阈值扫」出来的，不是逐样本画的（逐样本降序是速算技巧）；④ SMOTE 在测试集上做 = 数据泄漏；⑤ F1 是调和平均，会被小值拖死，不会偏向大值；⑥ macro-F1 对少数类友好，micro-F1 大类说了算——不平衡报告用 macro。
