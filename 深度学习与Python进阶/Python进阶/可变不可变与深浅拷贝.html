可变不可变与深浅拷贝

适用岗位：AI 开发、测开(Python)、通用软开 ｜ 形态：概念 + 输出判断（笔试重灾区） ｜ 更新：2026-09-30
要点速记："不可变"指对象内容不可改，变量名随时可以重新绑定；默认参数在 def 时求值一次——可变默认值被所有调用共享，正确写法是 None 哨兵；copy.copy 只复制最外层容器、内层共享引用，copy.deepcopy 递归复制到最内层；a[:]、list(a)、a*1 都是浅拷贝；[[0]*3]*2 的两"行"是同一个 list；is 比身份、== 比值。

一、知识点梳理

可变与不可变类型清单

类别类型含义
不可变int、float、str、tuple、frozenset、bytes对象创建后内容不能原地修改，任何"修改"都产生新对象
可变list、dict、set、bytearray、自定义对象可以原地修改（append、pop、下标赋值…），id 不变内容变
  • "不可变"约束的是对象，不是变量名：a = 1; a = 2 不是把 1 改成 2，而是 a 重新绑定到新对象，旧对象等回收。
  • 不可变类型可哈希（能做 dict 的 key、set 的元素）；可变类型不可哈希。
  • tuple 的坑：tuple 本身不可变，但元素可以是可变 list——t = (1, [2, 3]); t[1].append(4) 完全合法。
Python 
a = "hello"
b = a
print(a is b)        # True：b 绑定到同一个对象
a = a + "!"          # str 不可变：拼接生成新对象，a 重新绑定
print(a is b)        # False：b 还指向旧对象

lst = [1, 2, 3]
lst2 = lst
lst2.append(4)       # list 可变：原地修改，id 不变
print(lst)           # [1, 2, 3, 4] —— lst 一起"变"了，本来就是同一个对象

函数传参：传的是对象引用

  • Python 的参数传递是"传对象引用"（共享传参）：把实参对象的引用按值复制给形参。
  • 效果：函数内对可变对象原地修改（append/pop/下标赋值）→ 调用方可见；函数内对参数重新赋值 → 只改本地绑定，调用方无感。
  • 防御姿势：不想让函数动调用方的数据，入口先 copy.copy() 一份再改。
Python 
def modify(lst):
    lst.append(4)        # 原地修改：调用方可见

def rebind(lst):
    lst = [9, 9, 9]      # 重新绑定：只改本地变量

a = [1, 2, 3]
modify(a); print(a)      # [1, 2, 3, 4]
rebind(a); print(a)      # [1, 2, 3] —— 没变

默认参数陷阱（Python 笔试第一高频）

  • 默认值表达式在 def 执行时求值一次，绑定在函数对象上（f.__defaults__ 可见），不是每次调用重新求值。
  • 默认值是不可变对象（None、int、str）没事；是可变对象（list、dict）就所有调用共享同一个对象。
Python 
def add_item(x, bag=[]):        # 陷阱：默认 list 只创建一次
    bag.append(x)
    return bag

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  ← 不是 [2]！两次调用共享同一个 list
print(add_item(3))   # [1, 2, 3]

def add_item_ok(x, bag=None):   # 正确写法：None 哨兵
    if bag is None:
        bag = []                # 每次调用新建
    bag.append(x)
    return bag

浅拷贝 vs 深拷贝

  • copy.copy(x)（浅拷贝）：新建最外层容器，元素原样放引用 → 内层可变对象共享。
  • copy.deepcopy(x)（深拷贝）：递归复制到最内层，内层也独立；用记忆表防循环引用，不可变元素直接共享（安全，因为改不动）。
  • 切片 a[:]、list(a)、a*1、dict(a)、{**a} 都是浅拷贝；copy.copy 对不可变对象直接返回原对象。
Python 
import copy
src = [1, [2, 3]]
sh = copy.copy(src)        # 浅拷贝
dp = copy.deepcopy(src)    # 深拷贝

src[0] = 100               # 改外层元素
print(sh[0])               # 1   —— 浅拷贝的外层是独立容器
print(dp[0])               # 1

src[1].append(4)           # 改内层（可变）元素
print(sh[1])               # [2, 3, 4] —— 内层共享引用，跟着变
print(dp[1])               # [2, 3]    —— 内层也复制了，不受影响
伪代码 
浅拷贝 copy(x):
    新建空容器 C
    for 每个元素 e in x:
        C.add(e)             # 只放引用，不复制内层
    return C                 # 外壳独立，内层共享

深拷贝 deepcopy(x):
    若 x 不可变: return x                     # 不可变对象直接共享，改不动
    若 x 已拷贝过: return 记忆表里的副本        # 防循环引用
    新建空容器 C；记忆表[x] = C
    for 每个元素 e in x:
        C.add(deepcopy(e))   # 递归到最内层
    return C                 # 逐层独立

[[0]*3]*2 的坑

Python 
grid = [[0] * 3] * 2        # 外层的两个元素是【同一个】内层 list 的引用
grid[0][0] = 1
print(grid)                 # [[1, 0, 0], [1, 0, 0]] ← 改一行，两行全变
print(grid[0] is grid[1])   # True —— 陷阱根源

grid_ok = [[0] * 3 for _ in range(2)]   # 正确：每次循环新建内层 list
grid_ok[0][0] = 1
print(grid_ok)              # [[1, 0, 0], [0, 0, 0]]

# 注意区分：一维 [0] * 3 没事——三个 0 是同一个 int，但 int 不可变改不动；
# 二维 [[...]] * 2 复制的是 list 引用，list 可变，就出事了。

is vs ==，小整数缓存与字符串驻留

  • is 比"身份"（id() 是否相同），== 比"值"（调 __eq__）。判断 None 用 is None（PEP 8）。
  • CPython 小整数缓存 [-5, 256]：区间内的 int 预先建好，任何位置拿到的是同一对象。这是实现细节，面试可以提，但不能写进业务依赖。
  • 字符串驻留：标识符样式的字面量、编译期常量会驻留共享；运行期拼接出来的串不保证。
  • 出题的严谨姿势：同一代码对象内的常量只存一份（同一函数里 257 is 257 → True）；跨函数/跨语句的大整数是不同对象。所以 257 陷阱题要写成下面"跨函数"的形式才能稳定复现，别写成同一行字面量。
Python 
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True：值相等
print(a is b)   # False：两个不同对象

x = 100
y = 100
print(x is y)   # True：[-5, 256] 小整数缓存（CPython 实现细节）

def f(): return 257
def g(): return 257
print(f() == g())   # True
print(f() is g())   # False：257 超出缓存，两个函数各自持有自己的常量对象

def same():
    p = 257
    q = 257
    return p is q    # True：同一代码对象的常量只存一份

Java 对照（一句话）：Java 只有值传递——传对象时复制的是"引用的拷贝"，方法内能通过它修改对象内容（效果同 Python 的原地修改），但重新赋值改不动调用方的变量（效果同 rebind），两种语言的结论一致。

Java 
static void reassign(int[] arr) {
    arr = new int[]{9, 9, 9};   // 改的是引用的拷贝
}
public static void main(String[] args) {
    int[] a = {1, 2, 3};
    reassign(a);
    System.out.println(a[0]);   // 1 —— 调用方无感
}

三、示例题目（点击选项即时判分）

输出判断1. 以下代码输出（  ）

def f(x, bag=[]):
    bag.append(x)
    return bag

print(f(1))
print(f(2))
A. [1] 和 [2]，默认值每次调用都重新创建
B. [1] 和 [1, 2]，默认 list 在 def 时创建一次，所有调用共享
C. [2] 和 [2]，每次调用覆盖默认值
D. 抛出 TypeError
答案 B。默认值表达式在 def 执行时求值一次并挂在函数对象上，两次调用往同一个 list 里 append。正确写法是 None 哨兵：def f(x, bag=None): if bag is None: bag = []。来源：牛客经典题。

输出判断2. 以下代码输出（  ）

g = [[0] * 3] * 2
g[0][0] = 1
print(g)
A. [[1, 0, 0], [0, 0, 0]]
B. [[1, 0, 0], [1, 0, 0]]，两行是同一个 list 的引用
C. [[0, 0, 0], [0, 0, 0]]，赋值不生效
D. 抛出 TypeError
答案 B。[[0]*3]*2 里外层列表的两个元素指向同一个内层 list（g[0] is g[1] 为 True），改"一行"两行全变。正确写法：[[0]*3 for _ in range(2)]，每次循环新建内层 list。来源：面试高频改编。

输出判断3. 以下代码输出（  ）

import copy
src = [1, [2, 3]]
sh = copy.copy(src)
src[1].append(4)
print(src[1] is sh[1])
print(sh)
A. True 和 [1, [2, 3, 4]]：浅拷贝只复制外壳，内层共享引用
B. False 和 [1, [2, 3]]：浅拷贝会复制内层
C. True 和 [1, [2, 3]]：内层共享但 append 不可见
D. False 和 [1, [2, 3, 4]]
答案 A。copy.copy 新建了最外层容器，但元素是原样放引用，src[1] 与 sh[1] 是同一个对象（is 为 True），append 原地修改两边同时可见。换成 copy.deepcopy 才会得到 False 和 [1, [2, 3]]。来源：牛客经典题。

输出判断4. 以下代码输出（  ）

def f(): return 257
def g(): return 257

print(f() == g(), f() is g())
A. True True
B. True False
C. False True
D. False False
答案 B。257 超出 CPython 小整数缓存 [-5, 256]，两个函数是不同代码对象、各自持有自己的常量 257，is 为 False；== 比值恒为 True。严谨性提醒：同一代码对象内的常量只存一份（同一函数里 p = 257; q = 257 则 p is q 为 True），所以 257 陷阱题要写成跨函数形式才稳定复现；且缓存与驻留都是实现细节，不可依赖。来源：面试高频改编。

多选5. 下列属于不可变（immutable）类型的有（  ）

A. tuple
B. list
C. str
D. frozenset
答案 ACD。不可变家族：int、float、str、tuple、frozenset、bytes；list、dict、set、bytearray 是可变的。记忆钩子：不可变类型可哈希，能进 set、当 dict 的 key——list/dict/set 都不行。注意 tuple 只是自身不可变，内嵌的 list 仍可改。来源：牛客经典题。

面试口述6. Python 函数传参是传值还是传引用？可变对象在函数内被修改，调用方会受影响吗？

参考回答都不是经典意义上的传值/传引用，准确说法是"传对象引用"（共享传参）：把实参对象的引用按值复制给形参。两个效果：① 函数内对可变对象原地修改（append、pop、下标赋值），调用方看得见，因为两边是同一个对象；② 函数内对参数重新赋值（x = [...])，只改本地绑定，调用方无感。不可变对象在函数内"修改"本质是重新绑定，同样不影响外部。对照 Java：Java 只有值传递，对象传的是引用的拷贝，效果与 Python 一致——能改内容、改不动绑定。加分点：可变默认参数陷阱是同一机制的衍生坑；不想暴露内部数据就入口先浅拷贝。

四、易错点小结

① 判断"改没改到共享对象"：先分清是原地修改（append、pop、下标赋值）还是重新绑定（=、+ 拼接产生新对象）。② 看到 def f(x=[]) 直接在心里替换成 None 哨兵写法。③ 一维 [0]*3 没事（元素不可变），二维 [[0]*3]*2 就炸（外层复制的是 list 引用）——乘法复制引用，不复制对象。④ is 只用于 None 判断和身份调试，值比较一律 ==；a[:] / list(a) / a*1 都是浅拷贝，嵌套结构要 deepcopy。⑤ 小整数缓存 [-5, 256] 与字符串驻留是 CPython 实现细节，出题可以考、业务不能依赖，且 257 类陷阱要用跨函数写法才严谨。⑥ tuple 不可变 ≠ 内容全不可变：内嵌 list 仍可原地改。
