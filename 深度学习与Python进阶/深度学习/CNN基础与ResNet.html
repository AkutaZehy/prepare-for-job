CNN 基础与 ResNet

适用岗位：AI/软开通用（笔试计算必考） ｜ 形态：公式 + 手算 + 对比表 ｜ 更新：2026-09-30
要点速记：输出尺寸 $O=\lfloor(W-K+2P)/S\rfloor+1$（整除向下取整）；参数量 $K^2 C_{in}C_{out}+C_{out}$（别忘 bias）；两层 3×3 = 感受野 5×5 但参数更省；1×1 卷积只动通道不动空间；ResNet 解的是退化问题（训练误差随深度升高，不是过拟合），恒等映射 $H(x)=F(x)+x$ 让最差情况退化为恒等，梯度经 +1 直通支路回浅层。

一、知识点梳理

1. 卷积三件套与输出尺寸：卷积核 K（局部连接 + 权重共享）、步长 S（顺手下采样）、填充 P（保尺寸、保边缘信息）。输出尺寸公式（必背，整除向下取整）：

$$O=\left\lfloor\frac{W-K+2P}{S}\right\rfloor+1$$

手算例（ResNet stem 的真实数字）：输入 224×224，7×7 卷积 stride=2、padding=3：$O=\lfloor(224-7+6)/2\rfloor+1=112$；再接 3×3 最大池化 stride=2、padding=1：$O=\lfloor(112-3+2)/2\rfloor+1=56$。

def conv_out(W, K, P, S):
    return (W - K + 2*P) // S + 1     # 注意：整除向下取整

conv_out(224, 7, 3, 2)   # 112   ResNet stem 第一层
conv_out(112, 3, 1, 2)   # 56

2. 参数量与感受野

  • 卷积层参数量：$K\times K\times C_{in}\times C_{out}+C_{out}$（偏置别忘）。例：3×3、64→128 含偏置 = 9×64×128 + 128 = 73,856。
  • 感受野：一个激活值能"看到"的输入区域。逐层递推 $RF_l=RF_{l-1}+(K_l-1)\times\prod_{i<l}S_i$；stride=1 时两层 3×3 → 5×5，三层 → 7×7。
  • VGG 的经验：两个 3×3 堆叠替代一个 5×5——感受野相同，参数从 $25C^2$ 降到 $18C^2$，还多一次非线性。

3. 池化与 1×1 卷积：max/avg 池化无参数，做下采样 + 小平移鲁棒（常用 2×2、S=2）。1×1 卷积不看空间、只在通道维做线性组合（可加激活）：升降维省参数（GoogLeNet 的 Inception、ResNet 的 bottleneck 都靠它）、跨通道信息融合，且不改变 H、W。

4. 经典演进一句话：LeNet（1998，手写数字）→ AlexNet（2012，ReLU + Dropout + GPU，深度学习复兴起点）→ VGG（2014，全 3×3 堆深）→ GoogLeNet（2014，Inception 多尺度分支 + 1×1 降维）→ ResNet（2015，残差学习，152 层可训）。

5. ResNet（ResNet 论文，arXiv 2015 / CVPR 2016，He 等）

  • 退化问题（degradation）：plain 网络加深后，连训练误差都更高（论文实验：56 层 vs 20 层）——不是过拟合（过拟合是训练低测试高），是优化变难了。
  • 恒等映射：让层学残差 $H(x)=F(x)+x$。最差情况下把 $F$ 学成 0，块退化为恒等映射——加深至少无害；学"修正量"比直接重造恒等映射容易得多。
  • 梯度视角：$\dfrac{\partial H}{\partial x}=\dfrac{\partial F}{\partial x}+1$，常数 1 的直通支路让梯度可几乎无衰减地流回浅层，缓解梯度消失。
  • 两种残差块：
残差块结构用在特点
Basic Block3×3 → 3×3（通道不变）ResNet-18 / 34结构简单，参数多
Bottleneck1×1 降维（C/4）→ 3×3 → 1×1 升维ResNet-50 / 101 / 152两端 1×1 省 3×3 的参数与 FLOPs

维度不匹配（通道数变化 / 步长 2）时，shortcut 上加 1×1 卷积做投影对齐（论文的 option B）。

二、考点说明

笔试计算必考面试八股

  • 计算三模板：输出尺寸（给 K/S/P 手算）、参数量（含 bias）、感受野（多层 + stride 累积）——笔试出镜率最高的三个。
  • 概念区分：过拟合 vs 退化（训练误差谁高）、池化 vs 卷积（有无参数）、1×1 卷积的作用（动通道不动空间）。
  • 面试三连问：退化问题是什么、恒等映射为什么可行、bottleneck 里 1×1 在干嘛。

三、示例题目（点击选项即时判分）

计算1. 输入 224×224 的 RGB 图像，依次经过：① 7×7 卷积，stride=2，padding=3，输出通道 64；② 3×3 最大池化，stride=2，padding=1。写出每一步输出尺寸的计算过程与最终特征图尺寸。

先自己算，再展开对答案① $O_1=\lfloor(224-7+2\times3)/2\rfloor+1=\lfloor223/2\rfloor+1=111+1=112$ → 112×112×64；② $O_2=\lfloor(112-3+2\times1)/2\rfloor+1=\lfloor111/2\rfloor+1=55+1=56$ → 56×56×64。注意两点：分子整除向下取整（223/2=111.5 取 111）；这就是 ResNet stem 的 224→112→56，背熟当模板。来源：AI 岗笔试高频。

单选2. 一个 3×3 卷积层，输入通道 64、输出通道 128，含偏置的参数量是（  ）

A. 73,856
B. 73,728
C. 204,928
D. 18,464
答案 A。参数量 = $K^2\cdot C_{in}\cdot C_{out}+C_{out}$ = 9×64×128 + 128 = 73,728 + 128。B 忘了偏置；C 是同规格 5×5 卷积的参数量（25×64×128 + 128 = 204,928）——这正是"两个 3×3 堆叠省参数"的对比数字；D 数量级不对。顺带记感受野：两层该结构（stride=1）感受野 5×5。来源：牛客经典题。

多选3. 关于 ResNet 的残差连接，正确的有（  ）

A. 解决深层 plain 网络的退化问题：加深后训练误差反而升高的现象
B. 最差情况下多余层学成 F(x)=0，块退化为恒等映射，加深至少无害
C. 彻底消除了梯度消失与梯度爆炸，深层网络不再需要任何其他技巧
D. 反向传播时梯度可经恒等支路直达浅层，∂H/∂x = ∂F/∂x + 1 中的常数 1 保证梯度直通
答案 ABD。退化是优化问题不是过拟合——升的是训练误差（A 正是题眼）。C 错在"彻底/不再需要"：残差缓解梯度消失，梯度爆炸仍需裁剪，BN、合理初始化照常要配。来源：面试高频改编。

面试口述4. 残差连接为什么让深网络好训练了？

参考回答三层答案：① 优化视角——恒等映射兜底：深层只需学残差修正 $F(x)$，学不动就趋近 0，块退化为恒等，深度至少无害，解决"加深反而更差"的退化问题；② 梯度视角——$H(x)=x+F(x)$ 的 $\partial H/\partial x=1+\partial F/\partial x$，常数 1 的直通支路让梯度可几乎无损地回传浅层，缓解连乘衰减；③ 集成视角（加分）——带残差的网络近似许多浅层子网络的隐式集成（Veit 等 2016）。来源：面试高频改编。

四、易错点小结

① 输出尺寸整除向下取整，别四舍五入；② 参数量别忘 bias，感受野要把沿途 stride 累乘进去；③ 池化层无参数，1×1 卷积不改变 H、W 只动通道；④ ResNet 解决的是退化（优化问题）不是过拟合；⑤ He 初始化与 ReLU 配套正是 ResNet 论文的组合——见 训练三件套页。
