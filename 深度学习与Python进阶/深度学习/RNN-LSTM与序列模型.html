RNN/LSTM 与序列模型

适用岗位：AI/Agent 开发（NLP 前置知识） ｜ 形态：公式 + 图示 + 八股 ｜ 更新：2026-09-30
要点速记：RNN 梯度问题的根源是 BPTT 的连乘项 $\prod W_{hh}^\top\mathrm{diag}(\tanh')$——小于 1 指数消失、大于 1 指数爆炸；裁剪治爆炸、结构改造治消失；LSTM 靠三门一态，细胞态加法更新 $C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$ 使 $\partial C_t/\partial C_{t-1}=f_t$，f≈1 时梯度近恒等直传（高速通道）；GRU 两门更省参数；seq2seq 定长向量是瓶颈 → attention 兜底 → Transformer 干脆去掉循环。

一、知识点梳理

1. RNN 展开与 BPTT：每步用同一组权重（权重共享）：

$$h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b),\qquad y_t=W_{hy}h_t$$

沿时间展开后是一张"权重共享的深层网络"，训练用 BPTT（沿时间反向传播）——梯度要沿时间步一步步往回乘。

2. 梯度消失/爆炸的根源：连乘项

$$\frac{\partial h_t}{\partial h_k}=\prod_{i=k+1}^{t}W_{hh}^{\top}\,\mathrm{diag}\big(\tanh'(\cdot)\big)$$

$T-k$ 项连乘：谱半径小于 1 → 指数消失（远距离依赖学不到），大于 1 → 指数爆炸；$\tanh'\le 1$ 又压一手。梯度裁剪一句：爆炸用范数裁剪（超过阈值就等比缩放，Pascanu 2013），消失裁剪救不了，只能改结构——这就是 LSTM 的动机。

3. LSTM 三门一态（LSTM 论文 1997，Hochreiter & Schmidhuber）

$$f_t=\sigma(W_f[h_{t-1},x_t]),\quad i_t=\sigma(W_i[h_{t-1},x_t]),\quad \tilde C_t=\tanh(W_C[h_{t-1},x_t])$$

$$C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t,\qquad o_t=\sigma(W_o[h_{t-1},x_t]),\qquad h_t=o_t\odot\tanh(C_t)$$

  • 遗忘门 $f_t$：旧记忆 $C_{t-1}$ 的保留比例；
  • 输入门 $i_t$：新记忆 $\tilde C_t$ 的写入量；
  • 输出门 $o_t$：$h_t$ 输出多少（不影响细胞态）；
  • 细胞态 $C_t$：长期记忆主干，加法更新。
x(t), h(t-1) ─┬─ σ ──→ f(t) 遗忘门：C(t-1) 保留多少
              ├─ σ ──→ i(t) 输入门：新记忆写入多少
              ├─ tanh → C~(t) 候选记忆
              └─ σ ──→ o(t) 输出门：h(t) 输出多少

C(t-1) ──×f(t)──→ ⊕ ──→ C(t) ──tanh──→ ⊙ ──→ h(t)
                   ↑                    ↑
C~(t) ───×i(t)─────┘        o(t) ────────┘
（C 的更新是加法：∂C(t)/∂C(t-1) = f(t)，f≈1 时梯度近似恒等直传）

4. 为什么细胞态是梯度高速通道：$C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$ 中只有第一项依赖 $C_{t-1}$，且系数就是 $f_t$——$\dfrac{\partial C_t}{\partial C_{t-1}}=f_t$，没有 $W_{hh}$ 和 $\tanh'$ 的反复缩放。$f_t$ 是网络自己学的：需要长期记忆时输出接近 1，梯度就近似恒等地流过许多时间步（恒定误差传送带）。对比 RNN：每步乘 $W_{hh}^\top\mathrm{diag}(\tanh')$，连乘指数衰减。这与 ResNet 的恒等映射是同一思想（加法高速通道），LSTM 早了 18 年。

5. GRU 简化（Cho 等 2014）：两个门——更新门 $z_t$（融合遗忘与输入，$1-z_t$ 对偶分配）、重置门 $r_t$；不区分细胞态与隐态：$h_t=(1-z_t)\odot h_{t-1}+z_t\odot\tilde h_t$。矩阵 3 组 vs LSTM 4 组，参数少约 1/4，多数任务效果与 LSTM 相当。

6. 双向与多层：BiRNN 把前向、后向隐态拼接，$t$ 时刻可见全句——分类/序列标注强，但不能用于自回归生成与实时流（要用未来）。多层堆叠：上层吃下层的隐态序列，逐层抽象。

7. seq2seq 瓶颈 → attention → Transformer：encoder 把变长序列压成定长向量 $c$，长句信息全挤在一个向量里（瓶颈，Sutskever 2014）；attention（Bahdanau 2014）让 decoder 每步对 encoder 全部隐态加权取用，缓解瓶颈；再进一步把循环也去掉、全靠注意力并行——Transformer（Vaswani 2017），详见 Self-Attention与Transformer 页。

连乘项与裁剪（伪代码）

h = torch.tanh(Wx @ x_t + Wh @ h_prev + b)   # 每步乘一次 Wh 与 tanh'(·)
# ∂h_t/∂h_k = ∏ Wh^T · diag(tanh')  —— T-k 项连乘 → 指数消失/爆炸
torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0)   # 裁剪治爆炸

二、考点说明

面试必问笔试选择演进叙事

  • LSTM 三门分工、细胞态为什么缓解梯度消失——NLP/AI 岗八股必问，答法要能落到 $\partial C_t/\partial C_{t-1}=f_t$。
  • RNN 梯度消失/爆炸的数学根源（连乘项）与对策分工（裁剪治爆炸、结构治消失）。
  • RNN/LSTM/GRU 对比：门数、参数量、各自适用；双向 RNN 为什么不能做生成。
  • 演进叙事：seq2seq 瓶颈 → attention → Transformer，一句话讲清动机链（衔接 Self-Attention 页）。

三、示例题目（点击选项即时判分）

单选1. LSTM 中，决定上一时刻细胞态 $C_{t-1}$ 有多少被保留进当前细胞态 $C_t$ 的是（  ）

A. 输入门
B. 遗忘门
C. 输出门
D. tanh 候选层
答案 B。$C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$：$f_t$（遗忘门）管保留、$i_t$（输入门）管写入、$o_t$（输出门）只管 $h_t$ 的输出、不碰细胞态。三个门分工一句话：留多少、写多少、吐多少。来源：面试高频改编。

单选2. RNN 长程依赖难学的直接数学根源是（  ）

A. 参数量太少，模型容量不足
B. 输入序列没有做归一化
C. BPTT 沿时间的梯度是连乘项 $\prod W_{hh}^\top\mathrm{diag}(\tanh')$，模长小于 1 指数消失、大于 1 指数爆炸
D. 损失函数不可微
答案 C。每展开一步梯度就乘一次 $W_{hh}^\top$ 与 $\tanh'(\cdot)$（≤1），$T-k$ 项连乘按模长指数缩放。A 是容量问题、B 是工程问题，都不是长程依赖的结构性根源；爆炸用裁剪治，消失要改结构（LSTM）。来源：AI 岗笔试高频。

多选3. 关于 RNN、LSTM、GRU 的对比，正确的有（  ）

A. LSTM 细胞态用加法更新 $C_t=f\odot C_{t-1}+i\odot\tilde C$，梯度可近似恒等地沿时间回传
B. GRU 用更新门与重置门两个门，矩阵 3 组 vs LSTM 4 组，参数更少，效果常与 LSTM 相当
C. LSTM 彻底解决了梯度消失和梯度爆炸问题
D. 双向 RNN 在 t 时刻的表示包含未来信息，不适合自回归逐 token 生成
答案 ABD。C 错：LSTM 缓解的是消失（加法通道），爆炸依然存在（连乘结构还在），常规仍配梯度裁剪；双向 RNN 适合理解类任务，生成类不行（D 成立的原因）。来源：牛客经典题。

面试口述4. 细胞态为什么能缓解梯度消失？

参考回答关键在"加法更新"。$C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$ 中只有第一项依赖 $C_{t-1}$，系数就是 $f_t$——$\partial C_t/\partial C_{t-1}=f_t$，没有 $W_{hh}$ 和 $\tanh'$ 的反复缩放。$f_t$ 是网络自己学的：需要长期记忆时输出接近 1，梯度近似恒等地流过许多时间步（LSTM 论文 1997 称之为恒定误差传送带）。对比 RNN：$\partial h_t/\partial h_{t-1}=W_{hh}^\top\mathrm{diag}(\tanh')$，连乘指数衰减。加分点：这与 ResNet 恒等映射是同一思想（加法高速通道），但 LSTM 早了 18 年；且 $f_t$ 可门控，"哪些时间步保梯度"是学出来的。来源：面试高频改编。

四、易错点小结

① LSTM 4 组权重（f/i/C/o）、GRU 3 组，数参数题常考；② 输出门不影响 $C_t$，只管 $h_t$；③ 梯度裁剪治爆炸不治消失，别答反；④ 双向 ≠ 生成；⑤ attention 对 RNN 的替代逻辑接 Self-Attention与Transformer 页，两页配对着复习。
