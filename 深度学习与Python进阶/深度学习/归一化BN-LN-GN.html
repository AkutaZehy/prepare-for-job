归一化：BN / LN / GN

适用岗位：CV/NLP 通用（面试必问 BN 三连） ｜ 形态：公式 + 图示 + 对比表 ｜ 更新：2026-09-30
要点速记：四种归一化只差"沿哪些维度求 μ、σ²"——BN 跨（N, H×W）逐通道、LN 跨（C, H×W）逐样本、GN 组内（C/G, H×W）、IN 只跨空间（H×W）；BN 训练用 batch 统计量、推理用滑动平均（训练/推理不一致的根源）；batch 小换 GN/SyncBN；Transformer 用 LN 因为变长序列 padding + batch=1 推理，BN 无从统计。γ、β 是可学习仿射参数，μ、σ² 是统计量，两套别混。

一、知识点梳理

1. 为什么归一化：控制每层输入的均值/方差，让训练对初始化和学习率不那么敏感。BN 论文（Ioffe & Szegedy 2015）的动机是 internal covariate shift，后来的研究（Santurkar 等 2018）更多把收益归因于"平滑了损失曲面"。所有归一化都是同一个骨架，只是统计维度不同：

$$\hat x=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}},\qquad y=\gamma\,\hat x+\beta$$

γ、β 是可学习的仿射参数；μ、σ² 是统计量（BN 来自 batch/滑动平均，LN/GN/IN 来自当前样本自身）——两套参数别混。

2. 四种归一化：方向示意（输入特征图 N×C×H×W）

输入特征 (N, C, H, W)    N=批大小  C=通道  H×W=空间分辨率
 ├─ BN：每个通道跨 N 与 H×W 求统计 → 逐通道一条 μ/σ²
 ├─ LN：每个样本跨 C 与 H×W 求统计 → 逐样本一条，与 batch 无关
 ├─ GN：每个样本分 G 组，组内跨 C/G 与 H×W → 小 batch 折中
 └─ IN：每个样本每通道仅跨 H×W 求统计 → 风格迁移常用
flowchart LR
    X["输入特征图 (N, C, H, W)"] --> BN["BN：逐通道，跨 N 与 H×W 求统计量"]
    X --> LN["LN：逐样本，跨 C 与 H×W 求统计量"]
    X --> GN["GN：逐样本分组，组内跨 C/G 与 H×W"]
    X --> IN["IN：逐样本逐通道，仅跨 H×W"]
方法统计量沿哪些维度依赖 batch典型场景
BN每个通道：N 与 H×W是（训练时）CV 大 batch（ResNet 系）
LN每个样本：C 与 H×W否Transformer / 序列模型
GN每个样本分 G 组：组内 C/G 与 H×W否检测/分割小 batch（每卡 1~2 张图）
IN每个样本每个通道：仅 H×W否风格迁移

记忆抓手：把四个维度 (N,C,H,W) 摊开看——跨 N 求统计的只有 BN；跨全部 C 的是 LN；跨部分 C（分组）的是 GN；不跨 C 只跨空间的是 IN。

3. BN 的训练/推理差异：训练时用当前 batch 的 $\mu_{\mathcal B},\sigma^2_{\mathcal B}$ 归一化，同时用滑动平均维护 running_mean / running_var（PyTorch 默认 momentum=0.1，即新批统计量占 0.1 权重）；推理时 μ、σ² 固定为滑动平均值，不再看输入 batch。推理必须这样：线上可能 batch=1，且要求同样输入得到确定输出。

4. BN 放激活前还是后：主流写法是 卷积/线性层 → BN → 激活（BN 论文的原始顺序），让进入激活函数的值分布稳定；也有放激活后的变体，面试答"主流在激活前"即可。

5. batch 小时 BN 为什么失效、怎么办：BN 的 μ、σ² 是 batch 内估计，batch=1~2 时噪声巨大——训练抖动、滑动平均也估不准。对策：换 GN（组内统计，Wu & He 2018）、SyncBN（跨卡汇总统计量，等效大 batch）、LN，或干脆加大 batch。

6. 为什么 Transformer 用 LN 不用 BN：① 变长序列 + padding，batch 维统计被 pad 污染；② 自回归推理一次只有一个样本（batch=1），BN 的 batch 统计无从谈起；③ LN 逐样本自足，与 batch 组成无关。另外现代架构多用 pre-LN（归一化放进残差分支），梯度更稳——见 Self-Attention与Transformer 页。

7. BN 与 dropout 叠加的坑：dropout 随机置零会改变训练时激活的方差，BN 的滑动平均学到的是"带 dropout"的分布，推理时没有 dropout → 统计错配（variance shift）。常见处理：顺序上先 BN 后 dropout、主干里少用 dropout（Transformer 只在 attention/FFN 内部保留小比例）、或二选一。

二、考点说明

面试必问笔试选择工程调参

  • BN 三连问：训练/推理为什么不一致、推理用什么统计量、为什么放激活前——CV 岗出现率极高。
  • 维度题：给 (N,C,H,W) 问 BN/LN/GN/IN 各沿哪些维求统计，笔试常考。
  • 场景题：小 batch（检测/分割）BN 失效怎么办；Transformer 为什么用 LN。
  • 工程题：BN 与 dropout 叠加的方差偏移、微调时 freeze BN 的取舍。

三、示例题目（点击选项即时判分）

单选1. 训练好的 CNN 带 BN 层，部署时每次只输入 1 张图（batch=1），BN 层的行为是（  ）

A. 用当前这 1 张图估计均值方差再归一化
B. 使用训练期间维护的滑动平均 μ、σ²，输出与 batch 大小无关
C. 跳过归一化，直接输出 γ、β
D. 必须凑满与训练同样大小的 batch，否则报错
答案 B。推理阶段 μ、σ² 固定为滑动平均，与 batch 大小无关——这正是 BN"训练/推理不一致"的根源。单样本估统计量（A）方差无意义；归一化照做（C 错）；batch=1 完全合法（D 错）。来源：面试高频改编。

单选2. Transformer/序列模型普遍用 LayerNorm 而不是 BatchNorm，最核心的原因是（  ）

A. LN 的可学习参数更少，显著省显存
B. LN 能消除梯度消失
C. LN 逐样本沿特征维归一化，不依赖 batch 统计，变长序列 padding 与 batch=1 推理下统计仍然稳定
D. BN 在推理阶段无法使用
答案 C。三个理由：变长序列 + padding 污染 batch 统计、自回归推理 batch=1、LN 逐样本自足。D 错——BN 推理用滑动平均，能用，只是不适合序列场景；A 参数量差异微乎其微，不是主因；B 归一化不背"消除梯度消失"的锅。CV 大 batch 下 BN 通常更好且带轻微正则效果。来源：AI 岗笔试高频。

多选3. 输入特征图为 (N, C, H, W)，关于各归一化方法统计量的计算维度，正确的有（  ）

A. BN 对每个通道，沿 N 与 H×W 求均值方差
B. LN 对每个样本，沿 C 与 H×W 求均值方差
C. IN 对每个样本，沿 C、H、W 全部维度求均值方差
D. GN 对每个样本的每个分组，沿组内通道 C/G 与 H×W 求均值方差
答案 ABD。C 描述的其实是 LN；IN 是逐样本逐通道、只沿空间 H×W，风格迁移常用。记忆抓手：跨 N 的只有 BN，跨全部 C 的是 LN，跨部分 C 的是 GN，不跨 C 的是 IN。来源：牛客经典题。

面试口述4. BN 为什么训练和推理行为不一致？这种不一致带来过什么实际问题？

参考回答训练时 μ、σ² 来自当前 batch（同时以滑动平均维护 running 统计量）；推理时固定用 running 统计量。为什么必须：推理 batch 可能是 1、要求输出确定、且线上数据分布与训练 batch 组成不同。实际问题：① train/val 表现差距异常时，除了真实过拟合还要怀疑统计错配；② 与 dropout 叠加产生方差偏移——dropout 改变训练时激活方差，BN 滑动平均学到的不是推理分布；③ 微调检测/分割模型时 BN 统计要不要跟着更新（freeze BN）是个真实取舍。加分点：SyncBN/GN 的动机、PyTorch momentum=0.1 的含义。来源：面试高频改编。

四、易错点小结

① γ、β 是可学习仿射参数，μ、σ² 是统计量；BN 的统计量训练（batch）与推理（滑动平均）是两套；② "LN 没有参数"是错的——LN 也有 γ、β（逐特征），只是没有滑动统计；③ BN 主流放激活前（conv → BN → ReLU）；④ batch 小别硬扛 BN——GN/SyncBN/LN；⑤ 优化器与 warmup 见 训练三件套页，pre-LN/post-LN 见 Self-Attention 页。
