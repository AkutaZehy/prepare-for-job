训练实操：过拟合排查 / loss 不降

适用岗位：全部调参岗（工程排障高频） ｜ 形态：矩阵 + 清单 + 口述模板 ｜ 更新：2026-09-30
要点速记：先看 train/val 曲线 gap——train 低 val 高=过拟合，双高=欠拟合（先排 bug），train 高 val 低=怀疑泄漏/指标错；黄金测试是单 batch 过拟合：几十个样本压不到 0 就是通路 bug；loss 不降按"数据 → lr → 归一化 → 初始化 → 梯度"顺序查；nan/inf 先分"第一步就 nan"（lr/数据/初始化）与"中途 nan"（log(0)、除零、fp16 上溢）。

一、知识点梳理

1. 过拟合/欠拟合诊断：train/val 曲线 gap 矩阵（先排除实现 bug，再谈拟合状态）

train lossval loss诊断首选动作
低低健康拟合可以收工，继续压 val 或扩任务
低高过拟合早停、数据增强、L2/dropout、减容量、加数据
高高欠拟合加容量/训更久、降正则、检查 lr 与特征
高低先查 bugval 太容易或预处理泄漏进 val、分布不一致、指标实现错

2. 正则工具箱

  • L2 / 权重衰减：惩罚大权重，让函数更平滑（AdamW 的解耦写法见训练三件套页）。
  • Dropout：训练时按 p 随机置零激活，推理关闭；现代实现是 inverted dropout——训练时已按 $1/(1-p)$ 缩放，推理原样输出。
  • 数据增强：翻转/裁剪/mixup 等，等于"免费扩充训练集"，是 CV 首选正则。
  • 早停：val 曲线回头就停，保留最优权重——零成本，先上这个。
  • Label smoothing 一句：把 one-hot 换成 $1-\varepsilon$ 与 $\varepsilon$ 均分，压分类头的过度自信（Inception-v3 论文 2016 使用）。

3. loss 不降排查清单（按这个顺序）

  • ① 数据与标签：错位、类别塌缩、增强把标签改坏——黄金测试：挑几十个样本单 batch 训练，看能否把 loss 压到接近 0（能过拟合说明模型、损失、反传通路都通）。
  • ② 学习率：太大震荡不收敛、太小纹丝不动——扫 1e-2 / 1e-3 / 1e-4 三点，看曲线形态。
  • ③ 归一化：输入有没有标准化、网络里 BN/LN 漏没漏（选型见 归一化页）。
  • ④ 初始化：全零/方差不对 → 激活塌 0 或爆炸；死 ReLU 的信号是激活里 0 的比例畸高（背景见 训练三件套页）。
  • ⑤ 梯度检查：数值梯度对照，看各层 grad 范数是否健康（全 0、或层间悬殊几个量级都有问题）。
  • ⑥ 实现 bug：loss 没进计算图、忘 optimizer.step()/zero_grad()、train/eval 模式没切、数据没 shuffle。

4. loss=nan/inf 排查：先分两类——第一步就 nan：lr 太大、数据自带 nan/inf、初始化炸；中途 nan：lr 偏大慢慢飞、log(0)（交叉熵输入没过 sigmoid/softmax 或概率未 clamp 加 ε）、除零（全 pad 的 batch、归一化分母 0）、fp16 上溢（半精度可表示上限约 6.55×10⁴，混合精度必须配动态 loss scaling / GradScaler）。定位方法：从能跑通的最小配置（单样本 + fp32 + 小 lr）逐项加回来，用 torch.autograd.set_detect_anomaly(True) 定位出问题的算子。

5. 学习率调度一句：warmup 起步 + 之后阶梯衰减 / 余弦退火，val 平台期降 lr（ReduceLROnPlateau）——调度解决"不同阶段要不同步长"，不解决 bug。

loss 不降快速体检（PyTorch 伪代码）

x = (x - x.mean(0)) / (x.std(0) + 1e-8)   # 1) 输入标准化了吗
assert torch.isfinite(x).all()            # 2) 特征里有没有 nan/inf
loss = F.cross_entropy(logits, y)         # 3) 标签范围 0..C-1、dtype 对齐
torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0)   # 4) 先裁剪防飞

二、考点说明

工程口述高频笔试选择

  • 给曲线场景问诊断与动作：四种 gap 组合要能条件反射。
  • nan/inf 原因多选与定位流程：fp16 上溢、log(0)、除零、lr 大。
  • 面试口述题："loss 不降你怎么查"——考的是有序的排查框架，不是罗列可能原因；"单 batch 过拟合测试"是必说的加分句。
  • 正则工具箱各治什么：过拟合用正则，欠拟合降正则/加容量，别开错药。

三、示例题目（点击选项即时判分）

单选1. 训练曲线上 train loss 已降到 0.05，val loss 在第 20 个 epoch 后开始回升，当前 val loss 0.80。最合理的判断与动作是（  ）

A. 欠拟合，应该训练更多 epoch
B. 过拟合，用早停 / 数据增强 / 加重正则
C. 学习率太小，应该调大 10 倍
D. 模型容量太小，应该加深网络
答案 B。train 低 + val 回升是教科书式过拟合；加深网络、练更久、调大 lr 都只会更糟。工程顺序：先早停止损，再加正则/增强，有条件就加数据。来源：面试高频改编。

单选2. train loss 与 val loss 都停在高位不再下降，加大 epoch 无效；但用几十个样本做单 batch 过拟合测试能把 loss 压到接近 0。最可能的问题是（  ）

A. 欠拟合或训练配置不当（容量/lr/正则过强），因为单 batch 能过拟合说明梯度与标签通路正常
B. 数据通路有 bug，标签错了
C. 过拟合，应该加 dropout
D. val 集有数据泄漏
答案 A。"单 batch 过拟合测试"通过 = 模型、损失、反传、标签对齐都没问题（能记住训练样本），剩下就是容量不足/lr 不合适/正则过强的欠拟合区。B 与测试结果矛盾；C 与"train 也高"矛盾——过拟合是 train 低 val 高；D 恰好相反（泄漏让 val 假性变好，val 会低不是高）。来源：牛客经典题。

多选3. 训练中途 loss 变成 nan，可能的原因有（  ）

A. 学习率过大，参数一步更新飞到 inf
B. 交叉熵输入概率为 0，log(0) 未做 clamp / 加 ε
C. 使用 fp16 混合精度但没配 loss scaling，激活/梯度上溢
D. dropout 的 p 设为 0.5 导致数值不稳定
答案 ABC。fp16 可表示上限约 6.55×10⁴，超了就是 inf，混合精度要配动态 loss scaling；除零（全 pad batch、归一化分母）与数据自带 nan 也常见。p=0.5 是常规超参，不是 nan 来源（D 错）。定位：最小复现 + set_detect_anomaly + 逐项 clamp。来源：AI 岗笔试高频。

面试口述4. 拿到一个从零开始训练的模型，loss 不降，说出你的排查顺序。

参考回答按顺序来：① 先看数据——抽样肉眼对齐输入与标签、看类别分布；② 黄金测试——单个小 batch 过拟合，压不到 0 就是通路 bug（loss 实现/标签映射/训练循环）；③ 扫学习率（1e-2/1e-3/1e-4 三点，看曲线是纹丝不动、震荡还是飞）；④ 查输入归一化与网络内归一化（BN/LN）漏没漏；⑤ 查初始化与激活健康度（激活/梯度直方图、死 ReLU 比例）；⑥ 梯度检查、裁剪与 nan 监控；⑦ 还不行就最小化复现——砍深度、砍数据，二分定位。加分点：主动说出"先单 batch 过拟合"这个黄金测试，以及"先 fp32 单样本跑通，再加精度与并行"。来源：面试高频改编。

四、易错点小结

① train 低 val 高才叫过拟合，双高是欠拟合（先排 bug），别背反；② 单 batch 过拟合测试是排查第一刀——能过拟合再谈调参，不能过拟合先修 bug；③ nan 先分"第一步就 nan"（lr/数据/初始化）与"中途 nan"（log(0)/除零/fp16）；④ 早停看 val 曲线不看 train；⑤ 优化器/warmup/初始化细节见 训练三件套页，归一化选型见 归一化页。
