Self-Attention 与 Transformer

适用岗位：AI/Agent 开发（你课题主线，面试深挖区） ｜ 形态：公式 + 面试问法 + 手撕衔接 ｜ 更新：2026-09-30
要点速记：$\text{Attention}(Q,K,V)=\text{softmax}(QK^\top/\sqrt{d_k})V$；除 $\sqrt{d_k}$ 防点积方差过大致 softmax 饱和；multi-head=多个子空间并行投影；自回归解码用 causal mask；复杂度 $O(n^2 d)$；KV Cache 让每步只算新 token 的 K/V。手撕完整 ACM 版见「深度学习手撕编程题/手撕多头注意力」。

一、知识点梳理

整体架构：Encoder 与 Decoder 各由 N 层堆叠；每层 = 注意力子层 + 前馈子层（FFN：两层全夹激活），每个子层外套残差连接 + LayerNorm。Encoder 自注意力双向可见；Decoder 的自注意力带 causal mask，交叉注意力（cross-attention）的 Q 来自 Decoder、K/V 来自 Encoder 输出。

Q、K、V 的直觉：输入 $X$ 经三个投影矩阵得到 $Q=XW_Q,\ K=XW_K,\ V=XW_V$。Q=当前词的"查询"，K=每个词的"索引标签"，V=每个词的"内容"；查询与所有键做点积衡量相关度，相关度加权内容求和，得到融合上下文的新表示。

缩放公式：

$$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

  • 为什么除 $\sqrt{d_k}$：$q,k$ 各分量独立同分布、均值 0 方差 1 时，点积 $q\cdot k=\sum_{i=1}^{d_k}q_ik_i$ 的方差为 $d_k$——维度越大点积绝对值越大，softmax 落到两端饱和、梯度趋零。除以 $\sqrt{d_k}$ 把方差拉回 1。
  • Multi-Head：把 $d_{model}$ 切成 $h$ 份（每头 $d_k=d_{model}/h$），各头独立做注意力再拼接线性变换。意义：不同的头在不同表示子空间学不同关系模式（语法/指代/位置等），总算力近似不变（每头维度变小），还能并行。总参数 = 4 个 $d_{model}\times d_{model}$ 投影（WQ/WK/WV/WO）。
  • 三种 mask：① padding mask——把补齐位（pad）的注意力得分设成 $-\infty$，batch 评估/训练都要；② causal mask（下三角）——Decoder 自注意力禁止看见未来 token；③ 编码中给某些位置置 $-\infty$ 的自定义 mask。实现上都是"softmax 前加 $-\infty$"。
  • 位置编码：注意力本身对顺序不敏感（置换等变），必须注入位置信息。正弦/余弦（原论文，支持相对位置外推）、可学习（BERT/GPT-2）、RoPE 旋转位置编码（LLaMA 系主流，对相对位置友好、外推性好）。BERT 用可学习，GPT-2 用可学习，LLaMA/Qwen 用 RoPE。
  • 复杂度：注意力矩阵 $n\times n$，总复杂度 $O(n^2 d)$、显存 $O(n^2)$——长文本的瓶颈；FFN 部分 $O(nd^2)$。由此衍生 FlashAttention（IO 感知精确计算）、线性注意力等优化方向。
  • KV Cache：自回归推理时历史 token 的 K、V 不会变，缓存起来，每步只算新 token 的 Q/K/V 并与缓存拼接做注意力——把每步从"重算全部前缀"降为"只算增量"，代价是显存随上下文线性增长。衍生 GQA（分组查询，少缓存 K/V 头）、MQA。
  • pre-LN vs post-LN：原论文 post-LN（先子层后归一）训练不稳需 warmup；现代大模型几乎都用 pre-LN（归一放进残差分支），梯度更稳。

三、示例题目（点击选项即时判分）

单选1. 缩放点积注意力中对 $QK^\top$ 除以 $\sqrt{d_k}$ 的原因是（  ）

A. 防止参数过多导致过拟合
B. 维度大时点积方差随 $d_k$ 线性增大，softmax 进入饱和区、梯度变小
C. 使注意力矩阵变成单位矩阵
D. 为了与位置编码的量纲对齐
答案 B。$q\cdot k=\sum q_ik_i$，各分量独立同分布时方差为 $d_k$；除以 $\sqrt{d_k}$ 归一回方差 1，softmax 远离饱和。来源：经典面试题（Attention Is All You Need 论文 3.2.1 节）。

单选2. 序列长度 n、表示维度 d，单层 self-attention 的时间复杂度是（  ）

A. O(n d)
B. O(n log n · d)
C. O(n² d)
D. O(n d²)
答案 C。注意力得分矩阵计算 $QK^\top$ 是 $(n\times d)\times(d\times n)$，即 $O(n^2 d)$；再加 $\times V$ 同阶。D 的 $O(nd^2)$ 是 FFN 的量级——面试常追问"长文本瓶颈在哪个矩阵"，答 $n\times n$ 注意力矩阵。来源：笔试高频（AI 岗）。

多选3. 关于 multi-head attention，正确的有（  ）

A. 每个头在独立的低维子空间学习不同的关系模式
B. 各头可完全并行，总计算量与单头大体相当
C. 头数 h 必须等于 d_model，否则无法拼接
D. 各头输出拼接后还要经过输出投影矩阵 WO
答案 ABD。每头 $d_k=d_{model}/h$，拼接回 $d_{model}$ 后过 WO；C 错，h 整除 d_model 即可（常见 h×d_k=512×8、768×12）。来源：面试高频改编。

单选4. GPT 类自回归模型在 Decoder 自注意力中使用 causal mask，其作用是（  ）

A. 把位置 i 对位置 j>i 的注意力得分置为 $-\infty$，训练时防止"偷看未来"，与推理逐步生成保持一致
B. 把填充 padding 位置的得分置零，防止无效 token 参与计算
C. 让注意力只关注当前 token 自身
D. 用于稳定 LayerNorm 的统计量
答案 A。causal（下三角）mask 服务自回归一致性；B 描述的是 padding mask——两种 mask 是不同目的，面试常故意混着问。来源：AI 岗笔试高频。

面试口述5. KV Cache 为什么能加速自回归推理？代价是什么？

参考回答自回归生成第 t 个 token 时，只有新 token 的 Q/K/V 需要新算，而前 t−1 个 token 的 K/V 永远不变——把它们缓存下来与增量拼接做注意力，避免每步对全部前缀重算 K/V 与注意力，单步复杂度从对整段重算降为只算增量。代价：显存随上下文长度线性增长（n_tokens × n_kv_heads × d_head × 层数 × 2 × 精度字节数），所以长上下文衍生出 GQA/MQA（减少 K/V 头数）、PagedAttention（vLLM 显存分页管理）。加分：能报出 GQA 是"多个 Q 头共享一组 K/V 头"。

四、手撕衔接：单头 Attention（numpy 最小版）

Python/numpy 
import numpy as np

def softmax(x, axis=-1):                    # 数值稳定：减最大值
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, mask=None):          # Q,K,V: (n, d_k)
    scores = Q @ K.T / np.sqrt(Q.shape[-1]) # (n, n)
    if mask is not None:
        scores = np.where(mask, scores, -1e9)
    return softmax(scores) @ V              # (n, d_v)
多头版（split heads → 各头算 → 拼接 → WO 投影）与可判题的 ACM 完整程序见「深度学习手撕编程题/手撕多头注意力」，两页配对着重复习。
