手撕 softmax 与交叉熵（ACM 模式）

适用岗位：AI/Agent 开发（笔试手撕第一题级高频） ｜ 形态：ACM 判题题 + 概念自测 ｜ 更新：2026-09-30
要点速记：数值稳定 softmax = 先减最大值再 exp（平移不变，防 $e^{1000}$ 上溢）；交叉熵 $L=-\log p_y$；softmax+CE 联合求导一步到位 $\dfrac{\partial L}{\partial \mathbf z}=\mathbf p-\mathbf y_{\text{onehot}}$——面试手撕就是"减 max、log 正确类、梯度 p−y"三句话。

一、题目与 IO 约定

题面：给定 n 个 logits 与一个 0 起始的正确类下标 y，计算数值稳定的 softmax 概率分布与交叉熵损失 $L=-\log p_y$。概率与 loss 均保留 4 位小数。

$$p_i=\frac{e^{z_i-\max_j z_j}}{\sum_j e^{z_j-\max_j z_j}},\qquad L=-\log p_y$$

输入格式：第一行 n；第二行 n 个实数 logits；第三行整数 y（0 起始）。 样例 1： 
3
1 2 3
2
输出： 
0.0900 0.2447 0.6652
0.4076
样例 2（稳定性对照，输出必须与样例 1 完全一致）： 
3
1000 1001 1002
2
输出： 
0.0900 0.2447 0.6652
0.4076

样例核算：减去 max=3 后 exp 参数为 $e^{-2}=0.1353$、$e^{-1}=0.3679$、$e^{0}=1$，和 1.5032，归一化得 0.0900 / 0.2447 / 0.6652；loss $=-\ln 0.6652=0.4076$。样例 2 若直接 exp(1002)：Python math.exp 抛 OverflowError，numpy 得 inf，inf/inf=nan 全变 nan；减 max 后参数落在 {−2,−1,0}，输出与样例 1 逐位一致（本页样例均经本机实跑核对）。

二、思路与伪代码

读 logits, y
m = max(logits)                          # 平移不改变 softmax 值
p_i = exp(z_i - m) / sum_j exp(z_j - m)
loss = -log(p_y)
输出 p 各项(4位小数) 与 loss(4位小数)

推导：softmax+CE 联合梯度为什么是 p − y。$L=-\log p_y$，而 $\dfrac{\partial p_y}{\partial z_i}=p_y(\delta_{iy}-p_i)$，链式法则一步：

$$\frac{\partial L}{\partial z_i}=-\frac{1}{p_y}\cdot p_y(\delta_{iy}-p_i)=p_i-\delta_{iy}\;\;\Rightarrow\;\;\frac{\partial L}{\partial \mathbf z}=\mathbf p-\mathbf y_{\text{onehot}}$$

前向把 p 留下来，反向一行写完——这正是框架把 softmax 与 CE 合并成 cross_entropy(logits, y) 一个算子的原因：分开算既多存中间量，又要各自处理数值稳定。梯度正确性已用数值差分实测核对（三点 logit 上差分值与 p−y 逐项一致）。

数值不稳定反例对照（写进思路）：naive 版直接 exp([1000,1001,1002])——本机实测 Python math.exp 抛 OverflowError: math range error；numpy 给 [inf, inf, inf]，inf/inf → [nan nan nan]。稳定版减 1002 后与 [1,2,3] 输出逐位一致。判题系统常用 ±1000 量级的 logit 专卡 naive 实现。

概念自测（点击选项判分）

单选1. 数值稳定的 softmax 先减去最大值再 exp，原因是（  ）

A. 减去常数可以校准概率的系统性偏移
B. softmax(x)=softmax(x−c)，减 max 不改变数学结果、只把 exp 参数压到 ≤0 防上溢
C. 减 max 能同时加速 exp 的计算
D. 不减 max 会产生无法收敛的梯度
答案 B。softmax 对输入整体平移不变，减任意常数结果不变；减 max 纯粹是防 $e^{大数}$ 上溢的工程手段，最坏参数从 +1000 变成 ≤0。小概率下溢成 0 一般可接受，配合 log 时夹 eps。来源：AI 岗笔试高频。

多选2. 关于 softmax 与交叉熵的联合使用，正确的有（  ）

A. 联合梯度 ∂L/∂z = p − y_onehot，反向只需要前向算出的 p
B. 对正确类 logit 的梯度 p_y − 1 ≤ 0，训练会推高正确类得分
C. 多分类下"对每个类各做一个 sigmoid 再算 CE"与 softmax+CE 等价
D. one-hot 标签下 CE 退化为 −log p_y
答案 ABD。C 错：多个独立 sigmoid 互不归一，是多标签场景的用法；互斥多分类必须 softmax+CE。A 即本页推导；B 由 p_y ≤ 1 直接得到；D 因非正确类标签为 0、对应项消失。来源：面试高频改编。

三、ACM 完整代码

Python（ACM 完整程序） 
import sys
import math

def softmax_ce(logits, y):
    m = max(logits)                          # 1) 减最大值防溢出
    e = [math.exp(v - m) for v in logits]
    s = sum(e)
    p = [v / s for v in e]                   # 2) 归一化
    loss = -math.log(p[y])                   # 3) 交叉熵 = -log 正确类概率
    return p, loss

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it))
    logits = [float(next(it)) for _ in range(n)]
    y = int(next(it))
    p, loss = softmax_ce(logits, y)
    print(" ".join(f"{v:.4f}" for v in p))
    print(f"{loss:.4f}")

main()
PyTorch（面试白板版，无 IO） 
import torch
import torch.nn.functional as F

p = F.softmax(logits, dim=-1)                    # 框架内部已减 max
loss = F.cross_entropy(logits, torch.tensor([y]))  # = log_softmax + nll_loss
# 手写反向一步: grad_logits = p - one_hot(y)

四、易错点小结

① 减 max 要用整组最大值，别只减当前元素；② loss 取 log 的对象是"正确类概率"，y 忘了减 1（1 起始下标）是最常见的越界错；③ 反向梯度是 p − y_onehot，不是再套一层 p(1−p)；④ 输出格式：概率一行空格分隔、loss 单独一行，统一 f"{v:.4f}"；⑤ 极端 logit（±1000）是判题人用来卡 naive softmax 的常规手段，手撕时先说"我会减 max"再动手。
