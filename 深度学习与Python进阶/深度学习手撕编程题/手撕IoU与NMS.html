手撕 IoU 与 NMS（ACM 模式）

适用岗位：AI/Agent 开发（检测方向笔试必会） ｜ 形态：ACM 判题题×2 + 概念自测 ｜ 更新：2026-09-30
要点速记：$\text{IoU}=\dfrac{\text{交}}{\text{并}}=\dfrac{\text{交}}{S_A+S_B-\text{交}}$，负的交宽/交高取 0；NMS = 按分数降序贪心保留，候选与任一已保留框 IoU 大于阈值才抑制（恰等于阈值保留是本页约定）。两个必踩边界：负交集、恰等阈值。

一、题目与 IO 约定

题 A（IoU）：输入两行，每行 x1 y1 x2 y2，求交并比，4 位小数。约定坐标满足 x1<x2、y1<y2；两框不重叠 IoU=0；并集面积为 0（两框均退化成零面积）也输出 0.0000。

输入： 
0 0 2 2
1 1 3 3
输出： 
0.1429

核算：交集 $[1,2]\times[1,2]$ 面积 1，并集 = 4+4−1 = 7，IoU = 1/7 ≈ 0.1429。（题 B 要用的对照：(0,0,2,2) 与 (0,0,2,1)：交 2、并 4+2−2=4 → 0.5000。）

题 B（NMS）：第一行 n thr；随后 n 行 x1 y1 x2 y2 score。约定：按分数降序处理（同分按输入序号升序）；候选框与任一已保留框 IoU > thr 才被抑制（恰等于 thr 保留）；输出保留框的原始输入序号（按分数降序排列）。

输入： 
4 0.5
0 0 2 2 0.60
0 0 2 2 0.90
2 2 4 4 0.80
0 0 2 1 0.70
输出： 
1 2 3

核算（两个边界全踩到）：按分数排序 1(0.90)→2(0.80)→3(0.70)→0(0.60)。保留 1；框 2 与 1 不相交（IoU=0）保留；框 3 与 1 的 IoU = 2/4 = 0.5 恰等于阈值 → 按约定保留；框 0 与 1 完全重合 IoU=1>0.5 被抑制——注意 0 号框在输入里最先出现但分数最低，NMS 按分数处理、不按输入顺序。另一组对照（实测）：`3 0.3` 加 (0,0,10,10,0.5)/(1,1,11,11,0.9)/(20,20,30,30,0.8) → 框 0 与 1 的 IoU = 81/119 ≈ 0.6807 > 0.3 被抑制，输出 `1 2`。

二、思路与伪代码

# 题 A: IoU
iw = min(x2a, x2b) - max(x1a, x1b);  ih 同理
inter = max(0, iw) * max(0, ih)          # 负交集取 0
union = Sa + Sb - inter                  # 并 = A + B - 交
IoU = inter / union                      # union==0 特判输出 0

# 题 B: NMS
按 score 降序排序(同分输入序号小者先)
keep = []
for 框 in 排序结果:
    若 与 keep 中所有框的 IoU <= thr: keep.append(该框)
输出 keep(原始序号)

思路：NMS 贪心的直觉——分数最高的框最可信，先占位；任何与它重叠超阈值的框大概率是同一目标的重复检测，压掉不亏。复杂度 O(n²) 次 IoU，工程上可先按坐标粗筛（桶/网格）加速；密集目标误删可用 soft-NMS（不硬删，按 IoU 给分数降权）缓解。面试常接着问"IoU 为 0 的两个框一定不相交吗"——按本题交宽/交高取 0 的定义，边界相接（如 [0,2] 与 [2,4]）交面积也是 0，故"IoU=0"包含"仅边界相接"。

单选1. 框 A=(0,0,2,2) 与 B=(1,1,3,3) 的 IoU 是（  ）

A. 1/4
B. 1/7
C. 1/8
D. 1/3
答案 B。交集 [1,2]×[1,2] 面积 1，并集 = 4+4−1 = 7，IoU = 1/7 ≈ 0.1429。牢记"并 = A + B − 交"，直接把两面积相加会错选 C 的 1/8。来源：AI 岗笔试高频。

多选2. 关于 NMS，正确的有（  ）

A. 按分数从高到低处理，与框在输入中出现的先后顺序无关
B. 与已保留框 IoU 恰等于阈值时是否抑制取决于约定，常见约定是大于才抑制
C. IoU = 交面积 / (A 面积 + B 面积 − 交面积)
D. NMS 保留的框数一定等于目标类别数
答案 ABC。D 错：保留数由"有多少个互不重叠超过阈值的高分框"决定，与类别数无关（多类场景通常每类各自做 NMS）。B 即本页题 B 的约定；A 对应"分数低但先出现"的陷阱用例。来源：AI 岗笔试高频。

三、ACM 完整代码

题 A · Python（ACM 完整程序） 
import sys

def iou(a, b):
    iw = min(a[2], b[2]) - max(a[0], b[0])   # 交的宽
    ih = min(a[3], b[3]) - max(a[1], b[1])   # 交的高
    inter = max(0, iw) * max(0, ih)          # 不重叠时取 0
    union = (a[2]-a[0]) * (a[3]-a[1]) + (b[2]-b[0]) * (b[3]-b[1]) - inter
    return inter / union if union > 0 else 0.0   # 特判: 并集为 0

def main():
    data = sys.stdin.read().split()
    a = [float(v) for v in data[:4]]
    b = [float(v) for v in data[4:8]]
    print(f"{iou(a, b):.4f}")

main()
题 B · Python（ACM 完整程序） 
import sys

def iou(a, b):
    iw = min(a[2], b[2]) - max(a[0], b[0])
    ih = min(a[3], b[3]) - max(a[1], b[1])
    inter = max(0, iw) * max(0, ih)
    union = (a[2]-a[0]) * (a[3]-a[1]) + (b[2]-b[0]) * (b[3]-b[1]) - inter
    return inter / union if union > 0 else 0.0

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n, thr = int(next(it)), float(next(it))
    boxes = [[float(next(it)) for _ in range(5)] for _ in range(n)]
    # 按分数降序, 同分按输入序号升序
    order = sorted(range(n), key=lambda i: (-boxes[i][4], i))
    keep = []
    for i in order:
        if all(iou(boxes[i], boxes[j]) <= thr for j in keep):  # > 阈值才抑制
            keep.append(i)
    print(" ".join(map(str, keep)))

main()

四、易错点小结

① 交集的 max(0,·) 忘写，会把不相交框算出负交集；② "并 = A+B−交"别写成 A+B；③ NMS 排序键是分数不是输入序号（同分才看序号，约定要写清）；④ 抑制条件是 > 阈值还是 ≥ 阈值各题面不同，自己另立约定必挂对拍——本题面明确"> 才抑制、恰等保留"；⑤ 输出的是原始输入序号（按分数降序排列），不是排序后的位置。
