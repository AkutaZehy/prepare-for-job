手撕 INT8 量化（ACM 模式）

适用岗位：AI/Agent 开发（推理部署方向高频） ｜ 形态：ACM 判题题×2 + 概念自测 ｜ 更新：2026-09-30
要点速记：对称 INT8：$\text{scale}=\max|x|/127$，零点固定 0；非对称：$\text{scale}=(\max-\min)/255$，$\text{zp}=\text{clip}(\text{round}(-\min/\text{scale}),0,255)$ 记录"浮点 0 的位置"。反量化统一 $\hat x=(q-\text{zp})\cdot\text{scale}$——推理端只需要 scale 和 zero_point 两个标量。

一、题目与 IO 约定

题 A（对称量化 INT8）：第一行 n；第二行 n 个实数。约定 $\text{scale}=\max|x|/127$，$q=\text{clip}(\text{round}(x/\text{scale}),-127,127)$，反量化 $\hat x=q\cdot\text{scale}$。舍入用 Python 的 round（银行家舍入，.5 取偶）。输出三行：scale（4 位小数）；n 个量化值（整数、空格分隔）；反量化最大绝对误差（4 位小数）。

输入： 
4
-1.0 0 0.5 2.0
输出（实测）： 
0.0157
-64 0 32 127
0.0079

核算（可手算）：scale $=2.0/127\approx0.0157$；$x/\text{scale}=[-63.5,\ 0,\ 31.75,\ 127]$。round 按银行家舍入：round(−63.5) 取偶得 −64、31.75 → 32。误差 = $\max|q\cdot\text{scale}-x|$：$|{-64}\cdot\frac{2}{127}+1|=\frac{1}{127}\approx0.0079$、$|32\cdot\frac{2}{127}-0.5|\approx0.0039$、其余为 0，最大 0.0079。

题 B（非对称量化 INT8）：同输入格式。约定 $\text{scale}=(\max-\min)/255$，$\text{zp}=\text{clip}(\text{round}(-\min/\text{scale}),0,255)$，$q=\text{clip}(\text{round}(x/\text{scale})+\text{zp},0,255)$，反量化 $\hat x=(q-\text{zp})\cdot\text{scale}$。输出三行：scale（4 位小数）与 zero_point（整数）同行；n 个量化值；最大绝对误差。

输入： 
3
-1.0 0.5 2.5
输出（实测）： 
0.0137 73
0 109 255
0.0059

核算：scale $=3.5/255\approx0.0137$；$-\min/\text{scale}=255/3.5\approx72.857\to\text{zp}=73$。$x/\text{scale}\approx[-72.86,\ 36.43,\ 182.14]$，round 后加 zp、裁剪到 [0,255] 得 [0, 109, 255]。误差：$|0-73|\cdot\text{scale}$ 对应 $\approx0.0020$、$|36\cdot 3.5/255-0.5|\approx0.0059$、$|182\cdot 3.5/255-2.5|\approx0.0020$，最大 0.0059。

二、思路与伪代码

对称:   scale = max|x|/127;  zp = 0
        q    = clip(round(x/scale), -127, 127)
非对称: scale = (max-min)/255
        zp   = clip(round(-min/scale), 0, 255)
        q    = clip(round(x/scale) + zp, 0, 255)
反量化: x̂ = (q - zp) * scale;  误差 = max|x̂ - x|

思路：为什么推理端只要 scale 和 zero_point。反量化只是一次线性变换 $\hat x=(q-\text{zp})\cdot\text{scale}$：scale 编码"一个 int8 步长值多少浮点"，zero_point 编码"浮点 0 落在哪个 int8 值上"。推理时卷积/矩阵乘直接在 int8 上做、累加成 int32，最后统一反量化一次；权重只需存量化整数 q 加这两个标量，原始浮点矩阵可以扔掉——显存与带宽立省约 4 倍。对称 vs 非对称怎么选：分布关于 0 大致对称（多数权重层）用对称，省掉 zp 运算；ReLU 后激活落在 $[0,+\infty)$ 这类偏分布用非对称，否则负半轴 127 个档位全浪费、等效步长翻倍、误差变大。

概念自测（点击选项判分）

单选1. 对一组实数做对称 INT8 量化，scale 应取（  ）

A. max|x| / 127
B. max|x| / 255
C. (max − min) / 127
D. max|x| / 128
答案 A。int8 有符号范围取 [−127, 127]（工程上弃用 −128，让零点严格对称），把 |x| 的最大值映到 127 即 scale = max|x|/127；B 是 uint8 的分母；C 把整个跨度塞进有符号范围会浪费负半轴。来源：面试高频改编。

多选2. 关于 INT8 量化，正确的有（  ）

A. 非对称量化用 zero_point 记录浮点 0 的位置，适合 ReLU 后的偏分布激活
B. 反量化 x̂ = (q − zero_point) × scale，对称量化可视为 zero_point = 0 的特例
C. 推理端只需 scale 与 zero_point 两个标量即可完成 int8 到浮点的还原
D. 量化后模型精度理论上不变，只是体积变小
答案 ABC。D 错：量化是有损压缩，档位有限必然引入误差（本页实测误差 0.0079 / 0.0059 就是损失），校准不当还会明显掉点。C 即思路节结论——int8 推理 = 整数权重 + 两个标量参数。来源：AI 岗笔试高频。

三、ACM 完整代码

题 A · Python（ACM 完整程序） 
import sys

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it))
    xs = [float(next(it)) for _ in range(n)]
    scale = max(abs(x) for x in xs) / 127.0        # 对称: scale = max|x| / 127
    q = [max(-127, min(127, round(x / scale))) for x in xs]
    err = max(abs(q[i] * scale - xs[i]) for i in range(n))
    print(f"{scale:.4f}")
    print(" ".join(map(str, q)))
    print(f"{err:.4f}")

main()
题 B · Python（ACM 完整程序） 
import sys

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it))
    xs = [float(next(it)) for _ in range(n)]
    lo, hi = min(xs), max(xs)
    scale = (hi - lo) / 255.0                      # 非对称: scale = (max-min) / 255
    zp = max(0, min(255, round(-lo / scale)))      # zero_point: 浮点 0 的位置
    q = [max(0, min(255, round(x / scale) + zp)) for x in xs]
    err = max(abs((q[i] - zp) * scale - xs[i]) for i in range(n))
    print(f"{scale:.4f} {zp}")
    print(" ".join(map(str, q)))
    print(f"{err:.4f}")

main()

四、易错点小结

① clip 范围：对称 [−127, 127]（弃 −128 保零点对称）、非对称 [0, 255]；顺序是先 round、再加 zp、最后 clip，顺序错会溢出；② Python 的 round 是银行家舍入（round(−63.5)=−64），Java 的 Math.round 是半进一——.5 边界的量化值可能差 1，判题卡边界时按平台语言来（本页样例即含 −63.5 这个边界并实测）；③ 全零张量对称量化 scale=0 会除零，工程约定取极小值如 1e-8；④ 误差拿"反量化后的值"对比原值，别拿 q 本身算；⑤ per-tensor vs per-channel：卷积权重常按输出通道各自求 scale，精度更高，手撕题一般只考 per-tensor。
