手撕 KMeans（ACM 模式）

适用岗位：AI/Agent 开发（机器学习岗笔试常客） ｜ 形态：ACM 判题题 + 概念自测 ｜ 更新：2026-09-30
要点速记：Lloyd 两步循环——分配（每点找最近质心）→ 更新（质心 = 簇内均值），目标 $\sum_i \lVert x_i-\mu_{c_i}\rVert^2$ 每轮不增 → 必收敛（但只是局部最优）。判题去随机：初始质心约定 = 前 k 个输入点。

一、题目与 IO 约定

题面：给定 n 个二维点与簇数 k，约定初始质心为前 k 个输入点（编号 0..k−1 按输入顺序），执行 Lloyd 迭代至质心不再变化（或达 100 轮上限），输出最终 k 个质心，各 4 位小数、按质心编号每行一个。

约定（边界特判写明）：① 距离用平方欧氏距离比较（不开方，大小关系不变）；② 并列最近时归编号小的簇；③ 某簇为空时该簇质心保持上一轮不变；④ 收敛判定 = 更新后质心与上一轮完全相等。

输入格式：第一行 n k；随后 n 行每行 x y。 样例 1（两团明显的点）： 
6 2
0 0
1 0
0 1
10 10
11 10
10 11
输出： 
0.3333 0.3333
10.3333 10.3333
样例 2（质心被拉走，多迭代一轮）： 
4 2
0 0
1 1
5 5
6 6
输出： 
0.5000 0.5000
5.5000 5.5000

样例核算：样例 1 初始质心 (0,0)/(1,0)，第 1 轮前 3 点归簇 0、后 3 点归簇 1，更新得 $(\tfrac13,\tfrac13)$、$(\tfrac{31}{3},\tfrac{31}{3})$；第 2 轮分配不变 → 质心不变 → 收敛。样例 2 初始 (0,0)/(1,1) 时 (5,5)、(6,6) 离 (1,1) 更近（32<50），第 1 轮更新后 c1=(4,4)；第 2 轮 (1,1) 改投 c0（2<18），再更新得 (0.5,0.5)、(5.5,5.5)；第 3 轮分配不变收敛。两组均为本机实跑输出。

二、思路与伪代码

质心 = 前 k 个点
重复至多 100 轮:
    分配: 每点 -> 最近质心(平方距离, 并列取编号小者)
    更新: 每簇新质心 = 簇内点均值; 空簇沿用旧质心
    若 新质心 == 旧质心: 收敛, 退出
输出 k 个质心(4位小数, 按编号一行一个)

思路：KMeans 优化簇内平方误差和（SSE/inertia）$\sum_i \lVert x_i-\mu_{c_i}\rVert^2$。Lloyd 两步各自单调不增地压低它：固定质心时"就近分配"是每个点独立的最优；固定分配时"均值"是簇内平方和的最小解（对 μ 求导置零恰为均值）。SSE 有下界、单调不增 → 必收敛，但只保证局部最优，初始质心影响极大 → 工程上用 k-means++：下一个初始质心按"到已有质心的平方距离"加权采样，让初始质心尽量互相远离。

概念自测（点击选项判分）

单选1. KMeans（Lloyd 迭代）直接优化的目标函数是（  ）

A. 样本到所属质心的欧氏距离平方和（SSE）
B. 样本间平均成对距离
C. 各簇质心之间的距离和最大化
D. 轮廓系数
答案 A。"就近分配 + 均值更新"两步各自单调不增地压低簇内平方误差和（inertia）；C 只是聚类的间接效果，D 是评估指标而非训练目标。来源：面试高频改编。

多选2. 关于 KMeans 的性质与工程实践，正确的有（  ）

A. 只能保证收敛到局部最优，结果依赖初始质心
B. k-means++ 按"到已有质心的平方距离"加权选初始质心，改善聚类质量
C. 特征量纲差异大时先标准化，否则距离被大尺度特征主导
D. 簇数 k 不需要预设，KMeans 会自动学出来
答案 ABC。D 错：k 是超参数，需手动设定（肘部法/轮廓系数辅助选择）。另两个常考边界：空簇要特殊处理（沿用旧质心或拆分最分散的簇）、KMeans 假设球形等方差簇，条形/非凸簇看 DBSCAN 或高斯混合。来源：AI 岗笔试高频。

三、ACM 完整代码

Python（ACM 完整程序） 
import sys

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n, k = int(next(it)), int(next(it))
    pts = [(float(next(it)), float(next(it))) for _ in range(n)]
    cents = pts[:k]                          # 约定: 前 k 个点作初始质心
    for _ in range(100):                     # 轮数上限
        labels = []
        for (x, y) in pts:                   # 分配: 最近质心(平方距离)
            best, bd = 0, float('inf')
            for j, (cx, cy) in enumerate(cents):
                d = (x - cx) ** 2 + (y - cy) ** 2
                if d < bd:                   # 严格小于 => 并列取编号小者
                    best, bd = j, d
            labels.append(best)
        new = []
        for j in range(k):                   # 更新: 簇内均值, 空簇沿用旧质心
            mem = [pts[i] for i in range(n) if labels[i] == j]
            if mem:
                new.append((sum(a for a, _ in mem) / len(mem),
                            sum(b for _, b in mem) / len(mem)))
            else:
                new.append(cents[j])
        if new == cents:                     # 质心不再变化 => 收敛
            break
        cents = new
    for cx, cy in cents:
        print(f"{cx:.4f} {cy:.4f}")

main()

四、易错点小结

① 初始质心必须严格按题目约定取（本题=前 k 个点），自己随机初始化在对拍平台上必错；② 距离比较用平方距离省 sqrt，输出质心时也别手滑开方；③ 空簇不处理会除零——len(mem) 前先判空；④ 收敛判定直接比"新质心 == 旧质心"最稳；⑤ 输出按初始质心编号顺序，一行一个、4 位小数。
