手撕 TopK 堆与洗牌（ACM 模式）

适用岗位：全部后端/AI 岗（堆与采样通吃） ｜ 形态：ACM 判题题×2 + 概念自测 ｜ 更新：2026-09-30
要点速记：TopK 用 size-k 最小堆 $O(n\log k)$，堆顶是"守门员"；Fisher-Yates 洗牌第 i 步在 $[0,i]$ 均匀取 j 才无偏。判题去随机：swap 序列由输入给定，程序只负责执行；蓄水池采样思想见思路节（口述不判题）。

一、题目与 IO 约定

题 A（TopK）：第一行 n k；第二行 n 个整数。输出一行：前 k 大的数，升序，空格分隔（按名次计数，不去重）。

样例 1 输入： 
6 2
3 2 1 5 6 4
输出： 
5 6
样例 2 输入（含重复与负数）： 
5 3
10 -5 3 3 0
输出： 
3 3 10

核算：堆里始终只留当前最大的 k 个。样例 1 扫描中 1 进不了堆（≤守门员 2）、5 挤掉 2、6 挤掉 3，末态堆 {5,6} 升序输出。样例 2 前 k 大为 3 3 10——两个 3 都算名次（第 2 大与第 3 大），TopK 不去重。以上均经本机实跑核对，另与全排序对拍 6 组（含全等值 [7,7,7,7]、单元素、全负数）全部一致。

题 B（确定性洗牌）：第一行 n；第二行 n 个整数；第三行 m；随后 m 行每行两个下标 i j（0 起始）。按输入顺序依次执行 swap(a[i], a[j])，输出最终数组一行。（Fisher-Yates 的每一步本质就是一次交换；把"随机数"作为输入喂进来，判题即完全确定。题目保证 0 ≤ i, j < n。）

样例 1 输入： 
5
1 2 3 4 5
2
4 2
1 3
输出： 
1 4 5 2 3

核算：swap(a[4],a[2]) → `1 2 5 4 3`；swap(a[1],a[3]) → `1 4 5 2 3`。手算与实跑一致。

二、思路与伪代码

# 题 A: size-k 最小堆, 堆顶 = 当前第 k 大(守门员)
h = 前 k 个元素建最小堆
for x in 剩余元素:
    若 x > 堆顶: heapreplace(弹堆顶, 压 x)
输出 sorted(h)          # 升序恰为前 k 大

# 题 B: 执行输入给定的 swap 序列
for 每步 (i, j): swap(a[i], a[j])
输出 a

思路（蓄水池采样口述，不判题）：数据流长度未知、只许单遍时，维护大小 k 的"蓄水池"：前 k 个元素直接入库；第 i 个元素（i 从 1 数起）以 $k/i$ 的概率随机替换库中一个位置。归纳可证每个元素最终在库中的概率都是 $k/n$。面试追问"为什么是 k/i"：新元素入库后，原有某元素被保留的概率 $= \frac{k}{i}\cdot(1-\frac1k) + (1-\frac{k}{i}) = \frac{i-1}{i}$，从初始 1 连乘到 n 恰为 $k/n$——与 TopK 的"守门员"同源：用固定空间对抗未知总量。

Fisher-Yates 无偏性：第 1 步 i=n−1 在 n 个位置等概率选 j，第 2 步在剩下 n−1 个位置……每个排列出现概率都是 $1/n!$。经典错误写法是"每步在 [0, n−1] 全范围选 j"，路径数 $n^n$ 无法均匀映射到 $n!$ 个排列，结果系统性有偏。本题把随机性交给输入、程序只做确定性执行。

概念自测（点击选项判分）

单选1. n 很大、k 很小时取前 k 大，时间复杂度最优的主流做法是（  ）

A. 全体排序，O(n log n)
B. 维护 size-k 最小堆扫一遍，O(n log k)
C. 维护 size-k 最大堆扫一遍，O(n log k)
D. 冒泡选 k 轮，O(nk)
答案 B。最小堆堆顶是 k 个里的最小值（守门员），新元素与它比较后决定进出，n 次 O(log k) 操作；C 错在最大堆堆顶是最大值，当不了守门员；k ≪ n 时 O(n log k) 显著优于 O(n log n)。来源：LeetCode 经典题（ACM 改编）。

多选2. 关于堆与洗牌/采样，正确的有（  ）

A. Python 的 heapq 是最小堆，heappush/heappop 均 O(log n)
B. Fisher-Yates 洗牌无偏的前提是第 i 步在下标 [0, i] 内均匀取 j
C. 蓄水池采样单遍扫描即可保证每个元素以 k/n 的概率入选
D. "每个元素与全范围随机一个位置交换一次"的洗牌写法同样均匀无偏
答案 ABC。D 是经典偏差写法：在 [0, n−1] 全范围随机交换，n^n 条路径无法均匀对应 n! 个排列，部分排列概率系统性偏高。另外 heapreplace 一次完成"弹堆顶+压新值"，比 heappop 再 heappush 少一次 O(log k)。来源：面试高频改编。

三、ACM 完整代码

题 A · Python（ACM 完整程序） 
import sys
import heapq

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n, k = int(next(it)), int(next(it))
    a = [int(next(it)) for _ in range(n)]
    h = a[:k]                    # size-k 最小堆, 堆顶是 k 个里最小的(守门员)
    heapq.heapify(h)
    for x in a[k:]:
        if x > h[0]:             # 打败守门员才进堆
            heapq.heapreplace(h, x)   # 弹堆顶+压新值, 一次完成
    print(" ".join(map(str, sorted(h))))   # 别忘了: 堆内乱序, 输出前排序

main()
题 B · Python（ACM 完整程序） 
import sys

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it))
    a = [int(next(it)) for _ in range(n)]
    m = int(next(it))
    for _ in range(m):
        i, j = int(next(it)), int(next(it))
        a[i], a[j] = a[j], a[i]      # Fisher-Yates 每步的本质: 一次交换
    print(" ".join(map(str, a)))

main()

四、易错点小结

① 输出是升序的前 k 大，堆里是乱序的，最后必须 sorted；② "前 k 大"按名次含重复值，别写去重；③ heapreplace（先弹后压）与 heappushpop（先压后弹）方向相反，用错会丢元素；④ 洗牌题下标 0 起始还是 1 起始看题面，执行顺序严格按输入、不可并行化简；⑤ k 可以等于 n（堆=全量，等价全排序），边界也要能跑。
