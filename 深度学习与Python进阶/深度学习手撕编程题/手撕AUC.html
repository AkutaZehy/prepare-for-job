手撕 AUC（ACM 模式）

适用岗位：AI/Agent 开发（搜广推笔试必考） ｜ 形态：ACM 判题题 + 概念自测 ｜ 更新：2026-09-30
要点速记：AUC 的概率含义 = 随机取一正一负、正样本得分更高的概率。排序法一步出：按分数排名（并列取平均秩），$\text{AUC}=\dfrac{R_+ - \frac{n_+(n_+ +1)}{2}}{n_+ \, n_-}$，$R_+$ 为正样本秩和。坑点全在并列分数的平均秩上。

一、题目与 IO 约定

题面：给 n 个样本的预测分 prob 与真实标签 label（0/1），用排序法求 AUC，4 位小数。约定：分数并列取平均秩；题目保证至少 1 个正样本与 1 个负样本（n+·n− > 0，无需额外特判）。

$$\text{AUC}=\frac{R_+ - \dfrac{n_+\,(n_+ +1)}{2}}{n_+ \cdot n_-}$$

其中 $R_+$ 为按预测分升序排名（秩从 1 起、并列取平均秩）后正样本的秩和；$\frac{n_+(n_+ +1)}{2}$ 是正样本秩的固有底数（排名 1..n+ 的最小可能秩和），减掉后剩下的正是"正样本排在负样本前面"的净得分。

输入格式：第一行 n；随后 n 行每行 prob label。 样例 1（无并列）： 
4
0.9 1
0.7 1
0.4 0
0.2 0
输出： 
1.0000
样例 2（含并列分数）： 
5
0.8 1
0.8 0
0.3 1
0.3 0
0.6 1
输出： 
0.5000

样例核算 1（手算 Mann-Whitney 计数）：4 个正负对 0.9>0.4、0.9>0.2、0.7>0.4、0.7>0.2 全胜 → 4/4 = 1。秩法：升序秩 0.2→1、0.4→2、0.7→3、0.9→4，$R_+=3+4=7$，AUC $=(7-\frac{2\cdot3}{2})/4=1$ ✓。

样例核算 2：升序秩——两个 0.3 共享 $(1+2)/2=1.5$，0.6→3，两个 0.8 共享 $(4+5)/2=4.5$；$R_+=4.5+1.5+3=9$，AUC $=(9-\frac{3\cdot4}{2})/(3\cdot2)=0.5$。逐对核对：0.8p vs 0.8n 平手记 0.5、胜 0.3n；0.6p 负 0.8n、胜 0.3n；0.3p 平 0.3n、负 0.8n → $(0.5+1+0+1+0+0.5)/6=0.5$ ✓。两个实现交叉核对一致（另加 2 组用例实测同样吻合）。

二、思路与伪代码

升序排序, 并列分数共用平均秩 -> rank[]
R+ = 正样本 rank 之和
AUC = (R+ - n+*(n+ + 1)/2) / (n+ * n-)
输出 4 位小数

思路：为什么并列要取平均秩。并列的一对 (正, 负) 本该各记 0.5 分；把并列组的秩取平均后再套秩和公式，恰好等价于逐对"胜记 1 / 平记 0.5 / 负记 0"的 Mann-Whitney 统计量——这就是平均秩的来历。对拍：另写 O(n²) 逐对计数版作独立实现，排序法与逐对法在本页两个样例及额外用例上完全一致（实测 1.0000 / 0.5000 / 0.7500 / 0.3750 四组全部吻合）。复杂度：排序法 O(n log n) 是判题主打，逐对法 O(n²) 只配当对拍器。

概念自测（点击选项判分）

单选1. AUC 的概率含义是（  ）

A. 预测正确的样本占比（准确率）
B. 正样本占全部样本的比例
C. 随机取一正一负两个样本，正样本预测分高于负样本的概率
D. 正样本中被召回的比例（召回率）
答案 C。AUC = ROC 曲线下面积，等价于"随机正样本得分 > 随机负样本得分"的概率：全排对是 1、随机瞎排是 0.5。B/D 是先验与召回，与排序质量无关。来源：AI 岗笔试高频。

多选2. 用排序法计算 AUC，正确的有（  ）

A. 分数并列的样本取平均秩后再套秩和公式
B. 公式 (R₊ − n₊(n₊+1)/2) / (n₊·n₋) 中 R₊ 是正样本秩和（升序秩、从 1 起）
C. AUC 对分类阈值不敏感，类别不平衡场景比准确率稳
D. 负样本远多于正样本时 AUC 一定小于 0.5
答案 ABC。D 错：AUC 只看正负两类内部的相对排序，与两类数量比例无关（小于 0.5 是"排反了"，不是"不均衡"）。B 的减法项是排名 1..n₊ 的固有秩和，不减会把正样本自己的名次误算成得分。来源：面试高频改编。

三、ACM 完整代码

Python（ACM 完整程序，排序法） 
import sys

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it))
    rs = [(float(next(it)), int(next(it))) for _ in range(n)]
    npos = sum(l for _, l in rs)
    nneg = n - npos
    # 1) 升序排序, 并列分数取平均秩
    order = sorted(range(n), key=lambda i: rs[i][0])
    rank = [0.0] * n
    i = 0
    while i < n:
        j = i
        while j < n and rs[order[j]][0] == rs[order[i]][0]:
            j += 1
        avg = (i + 1 + j) / 2.0          # 秩 i+1 .. j 的平均值
        for t in range(i, j):
            rank[order[t]] = avg
        i = j
    # 2) AUC = (正样本秩和 - 固有底数) / (n+ * n-)
    r_sum = sum(rank[i] for i in range(n) if rs[i][1] == 1)
    auc = (r_sum - npos * (npos + 1) / 2.0) / (npos * nneg)
    print(f"{auc:.4f}")

main()
逐对计数（O(n²) 对拍/白板版，无 IO） 
def auc_pairs(rs):                       # rs: [(prob, label)]
    npos = sum(l for _, l in rs)
    nneg = len(rs) - npos
    s = 0.0
    for p1, l1 in rs:
        if l1 != 1:
            continue
        for p2, l2 in rs:
            if l2 != 0:
                continue
            if p1 > p2:                  # 胜记 1
                s += 1.0
            elif p1 == p2:               # 平记 0.5
                s += 0.5
    return s / (npos * nneg)

四、易错点小结

① 秩从 1 开始不是 0；② 并列检测在排序后比相邻分数是否相等（输入同字面解析出的浮点相等是安全的）；③ 别忘了减固有底数 $\frac{n_+(n_+ +1)}{2}$，否则结果系统性偏大；④ n₊ 或 n₋ 为 0 时 AUC 无定义——题面保证不出现，但工程代码要留除零保护；⑤ 想验证自己写对没有：拿 O(n²) 逐对版对拍，两版不一致必是平均秩处理错了。
