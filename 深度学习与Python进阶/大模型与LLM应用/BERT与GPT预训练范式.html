BERT vs GPT 与预训练范式

适用岗位：AI/Agent 开发（八股必问） ｜ 形态：三分架构 + 双对比表 ｜ 更新：2026-09-30
要点速记：架构三分——BERT 双向 Encoder + MLM（挑 15%，挑中按 80/10/10 处理）+ NSP（RoBERTa 去掉）；GPT 单向 Decoder + 因果 LM（每个 token 都算 loss）；T5 两头都占。LLM 时代 decoder-only 胜出四点：监督信号稠密、scaling 顺手、任务统一成生成、KV cache 推理友好。下游范式从"预训练 → 微调"变成"预训练 → 提示/指令"。

一、知识点梳理

架构三分：都是 Transformer（注意力细节见 Self-Attention 与 Transformer），差别在"用哪一半、怎么预训练"：

维度Encoder-onlyDecoder-onlyEncoder-Decoder
代表BERT（2018）GPT 系（GPT-2/3 及主流 LLM）T5（2019）、BART
注意力可见性双向，每个位置看全句单向，causal mask 只看左侧编码双向 + 解码单向
预训练目标MLM（+NSP）因果语言模型（逐 token 续写）span 复原，统一成 text-to-text
擅长任务理解类：分类、NER、句对匹配生成类：对话、续写、指令跟随翻译、摘要等 seq2seq
当下地位小模型理解类任务仍常用LLM 时代主流场景收缩但未消失

BERT：双向 + MLM——随机挑选 15% 的 token 参与预测（loss 只算这些位置），挑中的 15% 内部再按 80/10/10 处理：80% 换 [MASK]、10% 换随机词、10% 保持原词。混入随机词与原词，是为了不让模型"只认识 [MASK] 位置"、并缓解预训练与微调的输入分布不一致。另有 NSP（判断 B 是否为 A 的真实下文，真下文/随机句各半）——RoBERTa（2019）同算力对比证明去掉 NSP 不掉点，同时把静态 mask 改成动态复制、加大数据与训练时长。

# BERT 的 MLM 采样（2018 原论文设定）
chosen = random.sample(all_positions, int(0.15 * n))  # 只挑 15% 参与
for pos in chosen:                                    # 15% 内部再三分
    r = random.random()
    if   r < 0.8: tokens[pos] = "[MASK]"              # 80% 换掩码
    elif r < 0.9: tokens[pos] = random_vocab_word()   # 10% 换随机词
    # 其余 10% 保持原词；loss 只在这 15% 的位置上计算

GPT：单向因果 LM——causal mask 下逐 token 预测下一个词，整条序列每个位置都产生监督信号，与人类写作/生成的方式天然一致。

为什么 LLM 时代 decoder-only 胜出（面试按四点答）：

  • 监督信号稠密：因果 LM 每个 token 一份 loss；MLM 每 100 个 token 只有约 15 份——同样算力，因果 LM 吃到的训练信号多得多。
  • scaling 顺手：目标单一、无需任务专属设计，堆数据堆参数一路放大；GPT-3（2020，175B）展示 few-shot / in-context learning 能力随规模涌现。
  • zero-shot 任务统一成生成：所有任务都写成"给提示、续写答案"，不用加任务头；配指令微调（InstructGPT，2022）后成为通用交互形态。
  • KV cache 推理友好：单向结构下历史 token 的 K/V 永不变，增量解码天然成立（见 推理加速：KV Cache/量化/vLLM）；双向 Encoder 没有这个红利。

范式差异：微调 → 提示：

维度BERT 时代GPT 时代
下游适配加任务头 + 全量微调prompt / 指令，免训练或轻量微调
任务切换一任务一份微调权重换提示词即可，一个模型通吃
交互形态输入进、分类值/标注出一切皆文本生成

训练截止后的新知识，靠微调注入成本高、时效差——生产上事实类知识普遍改配 RAG（见 RAG 从原理到落地）。

二、考点说明

笔试选择面试必问AI 岗八股

  • 架构三分默写：给场景选架构（文本分类 → Encoder-only；翻译摘要 → Encoder-Decoder；对话生成 → Decoder-only）。
  • MLM 两层比例（15% 挑选 → 80/10/10）与"为什么混入随机词/原词"。
  • "为什么现在都做 decoder-only"——AI 岗面试出现率极高，按四点答全。
  • RoBERTa 相对 BERT 改了什么：去 NSP、动态 mask、更多数据更长训练。

三、示例题目（点击选项即时判分）

单选1. BERT 预训练中，被随机挑选的 15% token 按什么策略处理？（  ）

A. 全部替换为 [MASK]，微调时自然恢复
B. 80% 替换为 [MASK]、10% 替换为随机词、10% 保持原词
C. 80% 保持原词、10% 替换为 [MASK]、10% 替换为随机词
D. 50% 替换为 [MASK]、50% 保持原词
答案 B。若全换 [MASK]，微调阶段见不到 [MASK]，预训练与微调的输入分布不一致；混入 10% 随机词与 10% 原词，迫使模型对每个位置的表示都可靠，不能只在 [MASK] 处发力。注意两层比例：15% 是"挑选多少"，80/10/10 是"挑中后怎么改"。来源：AI 岗笔试高频。

单选2. 关于 BERT 与 GPT 的注意力可见性，正确的是（  ）

A. BERT 双向可见（每个位置看全句），GPT 单向（只看左侧上下文）
B. BERT 单向，GPT 双向
C. 两者都双向，差别只在层数与参数量
D. BERT 预训练时单向、微调时才双向
答案 A。BERT 是 Encoder-only，MLM 目标不需要因果约束，自注意力双向；GPT 是 Decoder-only，causal mask 保证只见左侧、与逐 token 生成一致。可见性差异也解释了"BERT 天生不适合自回归生成、GPT 不适合直接输出整句表示做分类"。来源：面试高频改编。

多选3. 关于 BERT 式与 GPT 式两代范式，正确的有（  ）

A. BERT 时代下游适配靠"加任务头 + 微调"，每个任务存一份微调权重
B. GPT 时代把各类任务统一成文本生成，同一个模型靠 prompt/指令切换任务
C. decoder-only 的因果 LM 让每个 token 都产生监督信号，训练信号比 MLM 稠密
D. MLM 让全部 token 都参与 loss，所以 BERT 的预训练信号其实更稠密
答案 ABC。D 错——MLM 只在被挑中的约 15% 位置计算 loss，这正是因果 LM 同算力下信号更稠密的对照面。A、B 是两种范式（微调 vs 提示）的核心差异，也是面试里"两代范式差在哪"的标准答案。来源：面试高频改编。

面试口述4. 为什么现在的主流大模型几乎都选 decoder-only 架构？

参考回答按四点答：① 监督信号稠密——因果 LM 每个 token 都算 loss，MLM 只有 15% 的位置有信号，同算力下因果 LM 效率高；② scaling 顺手——目标单一，堆数据堆参数即可，GPT-3（2020）已展示 few-shot 能力随规模涌现；③ 任务统一成生成——zero-shot/few-shot 用提示切换任务，不需要加任务头重训，InstructGPT（2022）的指令微调让它成为通用交互形态；④ KV cache 推理友好——单向注意力下历史 token 的 K/V 不变，增量解码天然成立，双向结构没这个红利。加分：提到 T5 的 Encoder-Decoder 在翻译类仍有优势，但通用性与工程简单性不敌 decoder-only。来源：面试高频改编。

面试口述5. NSP 是什么？RoBERTa（2019）为什么把它去掉了？

参考回答NSP（Next Sentence Prediction）：预训练时给两句 A、B，B 有 50% 概率是 A 的真实下文、50% 是随机句，做二分类，意图学句间关系。RoBERTa 用更大语料、更长训练、动态 mask（同一序列复制多份、mask 每轮不同）重做对比，发现去掉 NSP 不掉点——句间关系能力主要靠 MLM 隐式学到，NSP 任务太简单、信号弱还占算力。表述注意：这是"同算力下 NSP 无益"的结论，不是"NSP 必然有害"。来源：牛客经典题。

四、易错点小结

① 15% 是"挑选比例"、80/10/10 是"挑中后怎么改"，两层比例答混即错；② BERT 双向 ≠ 不能做生成，是与因果生成方式不匹配；③ "RoBERTa 去掉 NSP"是同算力对比结论，别绝对化成"NSP 必然有害"；④ "decoder-only 胜出"要答出信号密度、scaling、任务统一、KV cache 四点，只说"效果更好"不得分；⑤ T5/BART 是 Encoder-Decoder，别归进 decoder-only；⑥ BERT 微调范式 vs GPT 提示范式的差别在"下游适配方式"，不在"谁更强"——理解类小任务 BERT 仍能打。
