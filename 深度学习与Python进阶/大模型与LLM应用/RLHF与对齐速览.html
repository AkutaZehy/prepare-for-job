RLHF 与对齐速览

适用岗位：AI/Agent 开发（对齐八股） ｜ 形态：三阶段流程 + 公式 + 对比表 ｜ 更新：2026-09-30
要点速记：预训练只会续写所以"不听话"；InstructGPT（2022）三阶段 = SFT 指令微调 → 训练奖励模型 RM（人类排序对，Bradley-Terry）→ PPO 优化（KL 惩罚防跑飞）；DPO（2023）跳过 RM 与在线采样，把偏好对变成分类损失；对齐有代价（对齐税 / 创造力下降 / sycophancy 谄媚）；幻觉源于"像真的 ≠ 是真的"，事实类问题用 RAG 缓解。

一、知识点梳理

预训练模型为什么不会"听话"：预训练目标只有一个——预测下一个 token（续写）。问它"怎么炸鸡蛋"，它可能接着生成"那怎么煮鸡蛋？怎么蒸鸡蛋？"（示意）——因为在语料里这是最顺的续写。会补全 ≠ 会服从指令，更 ≠ 有帮助、无害、诚实。把"会续写"变成"会对话"，就是对齐（alignment）要解决的事。

InstructGPT（2022）三阶段：

预训练模型（只会续写）
  ↓
① SFT 指令微调（人工示范，学会按指令作答的格式）
  ↓
② 训练奖励模型 RM（同一 prompt 多个输出 → 人工排序）
  ↓
③ PPO 优化（RM 打分 + KL 惩罚锚住参考模型）
  ↓
对齐后的对话模型
flowchart LR
    S0[预训练模型 只会续写] --> S1[① SFT 指令微调]
    S1 --> S2[② 训练奖励模型 RM]
    S2 --> S3[③ PPO 优化 KL 惩罚]
    S3 --> OUT[对齐后的对话模型]
  • ① SFT 指令微调：用标注员写的"指令 → 高质量回答"示范做监督微调，先学会"按指令作答的格式"。
  • ② 训练奖励模型 RM：同一 prompt 采样多个输出，人工排序；用成对偏好训练一个打分模型。Bradley-Terry 一句：把偏好对变成概率 $P(y_w\succ y_l)=\sigma\big(r(y_w)-r(y_l)\big)$，从排序学出标量奖励 $r(\cdot)$。
  • ③ PPO 优化：以 RM 为奖励信号做强化学习更新 SFT 模型，同时加 KL 惩罚。工程上这一步要同时挂着策略、参考、RM、价值四个模型——又贵又难训的原因之一。

KL 惩罚的作用：实际奖励 = $r(x,y)-\beta\,\mathrm{KL}\big(\pi_\theta\,\|\,\pi_{\text{ref}}\big)$。RM 只是人类偏好的代理目标，会被钻空子——策略可能输出 RM 打分高但空洞、模板化的文本（reward hacking）；KL 项把策略拴在参考模型附近，防止语言能力与多样性崩掉。

DPO（Direct Preference Optimization，2023）：从 RLHF 目标推出闭式解——奖励可以用策略与参考模型的对数概率比表示（隐式奖励 $\beta\log\frac{\pi_\theta}{\pi_{\text{ref}}}$），于是不需要单独训 RM、不需要在线采样与 PPO 循环，直接在偏好对上做类似分类的损失：

$$\mathcal{L}_{\text{DPO}} = -\,\mathbb{E}\left[\log \sigma\!\left(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]$$

工程上更稳、更省资源；拿掉的是"RM + 在线采样"两件重装备，偏好数据本身仍然必需。

RLHF（PPO 版）vs DPO：

维度RLHF（PPO 版）DPO（2023）
奖励模型要显式训练 RM不需要（隐式奖励）
采样方式在线采样 + PPO 训练循环离线偏好对，监督学习式
训练稳定性超参敏感、工程重类分类损失，稳、省资源
共同点都需要人类偏好数据；都受对齐税、谄媚等问题影响

对齐的代价：① 对齐税——部分基准能力下降；② 输出趋于保守、模板化，创造力与多样性下降；③ sycophancy（谄媚）——为了迎合评价/偏好倾向顺着用户说（RM 从人类偏好里学出来的副作用）。

幻觉来源与缓解：来源——① 预训练目标奖励"像真的续写"而非"是真的"，流畅 ≠ 正确；② 知识截止，训练数据没有的事可能硬编；③ RM 可能偏好自信流利的表述，变相鼓励编造。缓解——事实类问题用 RAG 限定"仅依据检索片段作答"并可溯源，见 RAG 从原理到落地；配合"允许说不知道"的指令与引用标注。

二、考点说明

面试必问八股速览AI 岗笔试

  • 三阶段顺序与各阶段的数据形态（示范 / 排序对 / RM 打分的在线采样）。
  • KL 惩罚与 reward hacking——答出"代理目标会被钻空子"是亮点。
  • RLHF vs DPO 差异（RM、采样、稳定性）与共同点（都要偏好数据）。
  • 对齐的副作用：对齐税、创造力下降、谄媚。
  • 追问：为什么 SFT 之后还要 RLHF（SFT 学格式模仿，RLHF 学"哪个更好"的排序粒度）；幻觉与 RAG 的关系。

三、示例题目（点击选项即时判分）

单选1. InstructGPT（2022）对齐三阶段的正确顺序是（  ）

A. SFT 指令微调 → 训练奖励模型 RM → PPO 强化学习优化
B. 训练 RM → SFT → PPO
C. PPO → SFT → RM
D. RM → PPO → SFT
答案 A。先用人工示范 SFT 学会"按指令作答的格式"；再对同一 prompt 的多个输出做人工排序训练 RM；最后 PPO 以 RM 为奖励信号优化、KL 惩罚锚住 SFT 参考模型。逻辑链是"会答 → 会打分 → 会变好"，顺序背反即错。来源：牛客经典题。

单选2. RLHF 的 PPO 阶段加入 KL 惩罚的主要目的是（  ）

A. 防止策略为刷高奖励而偏离参考模型太远（reward hacking），保住语言能力与多样性
B. 让奖励模型的打分更准确
C. 减少训练显存占用
D. 增大探索随机性，加快收敛
答案 A。RM 只是人类偏好的代理目标，存在被钻空子的空间——策略可能输出 RM 打分高但空洞模板化的文本；实际奖励改为 $r-\beta\cdot\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$，把策略拴在参考模型附近。B 错——KL 惩罚管的是策略，管不了 RM 本身的质量。来源：面试高频改编。

多选3. 关于 RLHF（PPO 版）与 DPO（2023）的对比，正确的有（  ）

A. DPO 不需要单独训练一个奖励模型
B. DPO 不需要训练中的在线采样与 PPO 循环，把偏好对变成分类式损失直接优化
C. DPO 仍然需要成对的偏好数据（chosen / rejected）
D. DPO 训练时需要在线采样新输出并用 RM 打分
答案 ABC。DPO 的两件"省"正是 A、B——把奖励写成 $\beta\log(\pi_\theta/\pi_{\text{ref}})$ 的隐式形式，离线偏好对上直接优化；但偏好数据照旧要人工标注（C）。D 与 A 矛盾且正是 DPO 省掉的东西。来源：AI 岗笔试高频。

面试口述4. 为什么需要训练一个奖励模型，而不直接用规则打分？

参考回答"回答得好"是开放域的主观判断——帮助性、真实性、语气——很难写成可枚举的规则；规则只能覆盖表面模式（长度、关键词），很快被策略钻空子（reward hacking）。RM 从大量人类偏好排序中压缩出一个可泛化的标量打分函数（Bradley-Terry：把排序对变成 $P(y_w\succ y_l)=\sigma(r(y_w)-r(y_l))$），把"人觉得哪个好"规模化地变成可优化的信号——这是人类判断接入训练的桥梁。加分：RM 也只是代理目标，所以要配 KL 惩罚防跑飞；DPO 则干脆绕开显式 RM。来源：面试高频改编。

面试口述5. 大模型的幻觉从哪来？工程上怎么缓解？

参考回答来源有三：① 预训练目标是"像真的续写"而非"是真的"——流畅 ≠ 正确；② 知识截止——训练数据之后的事它可能硬编；③ 解码随机性 + RLHF 的 RM 可能偏好"自信流利"的表述，变相鼓励编造。缓解：事实类问题首选 RAG——检索相关片段拼进 Prompt、限定模型"仅依据资料作答"并可标注引用溯源，详见同子夹「RAG 从原理到落地」页；辅以"允许说不知道"的指令、要求给出处、降低 temperature 等手段。要点：幻觉的根子在训练目标与数据，RLHF 与 RAG 是缓解不是根除。来源：AI 岗笔试高频。

四、易错点小结

① 顺序别背反：SFT 在前（学格式）、RM 在中（学打分）、PPO 在后（用打分优化）；② KL 惩罚是"防跑飞/防刷分"，不是"防过拟合"；③ DPO 不是"无监督对齐"——偏好数据照旧要标，它省的是 RM 与在线采样；④ 谄媚（sycophancy）是对齐的已知副作用，别把它当成"模型有礼貌"；⑤ "SFT 之后为什么还要 RLHF"：SFT 只会模仿示范，RLHF 提供比示范更细的"哪个更好"的排序信号；⑥ 幻觉题记得把矛头指向预训练目标，再落到 RAG 缓解——只答"编造"不得分。
