LoRA 与参数高效微调

适用岗位：AI/Agent 开发（微调岗必问） ｜ 形态：公式 + 显存账 + 选型对比表 ｜ 更新：2026-09-30
要点速记：全参微调显存 = 权重 + 梯度 + 优化器状态（混合精度 AdamW 约 16 字节/参数，7B ≈ 112GB 起步）；LoRA（2021）= 低秩 $\Delta W=BA$，A 降维随机初始化、B 升维零初始化，只训 A/B，推理前合并零额外延迟，缩放系数 α/r；QLoRA（2023）= 4bit nf4 底座 + LoRA + 双重量化；PEFT 取舍：Adapter 串行加延迟、Prefix/Prompt 占上下文、LoRA 兼顾；r 按任务差距选，常见 8~64。

一、知识点梳理

全参微调的痛点：显存三件套——训练显存 ≈ 权重 + 梯度 + 优化器状态（外加激活值）。混合精度 + AdamW 的经验账本（每参数字节数）：fp16 权重 2 + fp16 梯度 2 + fp32 主权重 4 + fp32 动量 4 + fp32 方差 4 ≈ 16 字节/参数。7B 模型：fp16 推理只要 14GB，全参微调 ≈ 112GB 起步——这就是"推理随便跑、微调爆显存"的根源。此外全参微调还贵在：每任务存一份全量权重、易灾难性遗忘、数据与时间成本高。

LoRA（2021）：低秩假设——微调带来的权重变化 $\Delta W$ 秩很低，可拆成两个小矩阵的乘积，与原权重并联：

$$h = W_0x + \frac{\alpha}{r}\,BAx,\qquad A\in\mathbb{R}^{r\times d_{in}},\ B\in\mathbb{R}^{d_{out}\times r},\ r\ll\min(d_{in},d_{out})$$

  • 初始化（高频考点）：A 降维、高斯初始化；B 升维、全零初始化 → 起点 $\Delta W=BA=0$，训练从预训练行为出发。若 A、B 都全零，两者梯度恒为 0，永远训不动。
  • 只训 A/B：可训参数 $r\times(d_{in}+d_{out})$，通常只有全量的零点几个百分点；W₀ 全程冻结、不进优化器——省掉的正是"梯度 + 优化器状态"两大头。
  • α 与 r 的关系：$\alpha/r$ 是 LoRA 分支的缩放系数，实践常取 α=r 或 α=2r；调 α 等效调 ΔW 的"音量"，改 r 时 α 要同步对齐，否则等于偷偷改了分支强度。
  • 推理零延迟：部署前把 $\frac{\alpha}{r}BA$ 合并进 W₀，得到同形状普通矩阵，计算图与原模型完全一致。
W0 = base_layer.W                        # 冻结，不进优化器
A = randn(r, d_in)                       # 降维：高斯初始化
B = zeros(d_out, r)                      # 升维：零初始化 → 初始 ΔW=0
h = W0 @ x + (alpha / r) * B @ (A @ x)   # 前向：并联低秩分支
训练：只更新 A、B（W0 不动）
部署：W = W0 + (alpha / r) * B @ A        # 合并后同形同速，零额外延迟

QLoRA（2023）：把"底座"压到 4bit 再挂 LoRA——① 4bit NormalFloat（nf4）量化冻结底座（贴合正态分布的分位数格式）；② 双重量化（对量化常数本身再量化）再省一点；③ 分页优化器应对显存峰值。其上的 LoRA 分支仍以高精度（bf16）训练。论文演示了单张 48GB GPU 微调 65B 模型、任务效果保持 16bit 全参微调水平。

PEFT 对比（易混对比必背）：

方法改动位置推理开销备注
全参微调所有权重无显存 = 权重+梯度+优化器状态，最贵；每任务一份全量权重
Adapter（2019）层间串行插入瓶颈模块有额外延迟最早的 PEFT 之一；推理时多过一层算子
Prefix / Prompt tuning（2021）可训虚拟 token 放进上下文无模块延迟挤占上下文窗口、容量有限、对初始化与层数敏感
LoRA（2021）权重旁挂低秩并联分支零（可合并）不占上下文、不加延迟、可按任务挂载多份，当前事实标准

r 怎么选：任务与预训练分布差距越大，需要"改写"的方向越多，r 取越大；常见起步 8~64。小任务小 r 往往够用，盲目加大 r 收益递减还费显存。多任务可为每个任务配独立 LoRA，切换即挂载。

别忘了选型对照：知识频繁更新、要溯源 → 上 RAG（见 RAG 从原理到落地）；改风格、塑行为 → 微调（LoRA 是默认形态）。

二、考点说明

面试必问显存计算AI 岗八股

  • 显存三件套账本（权重/梯度/优化器状态）与 16 字节/参数估算——答出这个就赢一半。
  • LoRA 初始化：为什么 B=0、A 高斯；A、B 都全零为什么训不动。
  • PEFT 三兄弟取舍：Adapter 串行延迟、Prefix/Prompt 占上下文、LoRA 兼顾。
  • QLoRA 三件套：nf4、双重量化、分页优化器——一句话"4bit 底座 + LoRA"。
  • 追问：r 与 α 怎么定、多任务怎么管理多份 LoRA（按需挂载/合并）。

三、示例题目（点击选项即时判分）

单选1. LoRA 中 A、B 两个矩阵的初始化方式与原因是（  ）

A. A 随机高斯、B 全零，使起点 ΔW=BA=0，从预训练行为出发训练
B. A 全零、B 随机高斯，使起点 ΔW=0
C. 两者都全零，最大程度保证 ΔW=0
D. 两者都随机高斯，加快收敛
答案 A。B=0 让起点 ΔW=0，同时 A≠0 保证 B 的梯度非零、训练能流动；若两者都全零，$\partial L/\partial B\propto A$、$\partial L/\partial A\propto B$ 全为 0，参数永远不动。B 随机 + A 全零则 A 的梯度被 B 卡住、B 的梯度随 A=0 归零，同样训不动。来源：面试高频改编。

单选2. 7B 模型 fp16 推理只要约 14GB 显存，但全参微调在 80GB 的卡上也常爆显存，主要原因是（  ）

A. 推理时权重被压缩，训练时膨胀回 fp32
B. 训练还要存梯度与优化器状态：混合精度 AdamW 按约 16 字节/参数估算，7B ≈ 112GB（未含激活）
C. 训练数据必须整体常驻显存
D. 反向传播需要把所有激活值永久保存到训练结束
答案 B。账本：fp16 权重 2 + fp16 梯度 2 + fp32 主权重 4 + fp32 动量 4 + fp32 方差 4 ≈ 16 字节/参数——优化器状态与 fp32 主权重是大头，这正是 LoRA"冻结底座、只训小分支"能省显存的原理。D 的激活值可用梯度检查点压缩，不是主因。来源：AI 岗笔试高频。

多选3. 关于主流 PEFT 方法，正确的有（  ）

A. Adapter 在层间串行插入小模块，推理必须额外经过它们，带来延迟
B. Prefix / Prompt tuning 把可训向量放进上下文，占用序列窗口且对超参敏感
C. LoRA 的 ΔW=BA 与原权重并联，训练后可合并进权重，推理零额外延迟
D. LoRA 需要复制一份预训练权重并全程更新它
答案 ABC。D 错——LoRA 冻结 W₀，只训 A、B，连权重副本都不需要；它省的正是全参微调里最贵的梯度与优化器状态。三方法记忆口径：Adapter 串行加延迟、Prefix/Prompt 占上下文、LoRA 兼顾。来源：面试高频改编。

计算4. 权重 W 形状为 4096×4096，用 LoRA 取 r=8：可训参数多少个？占全量微调参数的百分之几？

先自己算，再展开对答案LoRA 可训参数 = $r\times(d_{in}+d_{out})$ = 8×(4096+4096) = 65,536；全量 = 4096×4096 = 16,777,216；占比 ≈ 0.39%。易错：不是 r×r，也不是只算一个矩阵——A、B 两块都要算。7B 模型按同样比例，可训参数通常只有全量的零点几个百分点。来源：牛客经典题。

面试口述5. 为什么说 LoRA 推理零额外延迟？代价是什么？

参考回答训练时 ΔW=BA 与 W₀ 并联是为了省显存的形态；部署前把 (α/r)·BA 合并进 W₀，得到一个与原权重同形状的普通矩阵——推理计算图和原模型完全一样，没有新增算子或模块，所以零额外延迟。对比：Adapter 是串行模块，推理必须多过一层，省不掉。代价：① 合并后一个底座只能对应一份 LoRA 权重，多任务要么存多份合并权重、要么不合并按需挂载（挂载时有轻微开销）；② 低秩是近似，r 太小可能容量不足；③ 与量化叠加（QLoRA）时合并要先把底座反量化到高精度。来源：面试高频改编。

四、易错点小结

① A/B 方向与初始化别记反：A 降维随机、B 升维全零；都全零则梯度恒 0 训不动；② LoRA 省的是"梯度 + 优化器状态"，底座权重本身仍在显存——把底座也压下去的是 QLoRA；③ QLoRA ≠ 把 LoRA 矩阵也量化成 4bit，LoRA 分支仍高精度训练；④ 合并发生在部署前，训练中不合并；改 r 时 α 要同步对齐缩放，否则等效改了分支强度；⑤ "r 越大越好"是误区：按任务与预训练的差距选，常见 8~64 起步；⑥ PEFT 选型题抓关键词：串行（Adapter）/ 占上下文（Prefix、Prompt）/ 并联可合并（LoRA）。
