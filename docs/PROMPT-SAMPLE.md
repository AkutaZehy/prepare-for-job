# 批量铺量 Prompt 样例

本仓库每个知识点页批次都由结构相同的 prompt 驱动 AI 子代理产出。这里放一份**原样保留**的真实样例（408 数据结构批次，7 页），供复现流程参考。样例中的本机绝对路径已统一替换为 `<仓库根>` 占位。

一份可用的铺量 prompt 固定五段：**① 先读哪些样板**（金标准页路径，要求完整读完再动笔）→ **② 硬规则**（逐字复制项、DOM 契约、转义、来源白名单、自查项）→ **③ 逐页大纲**（文件名 + title + 知识点要点 + 每页题目配比）→ **④ 禁项**（不改已有文件、不碰底账、不跑 git）→ **⑤ 交付汇报格式**（逐页自报 + 自由裁量点清单）。

---

以下是样例全文：

> 你在为本地学习站点 `<仓库根>` 铺量 408 数据结构 7 页。这是纯新建 HTML 的任务，全程只新建下面列出的 7 个文件，绝不修改任何已有文件，不碰 PAGES.md / build_checklist.py / checklist.js / index.html，不执行任何 git 命令。
>
> ## 第一步：读三个样板（必须先完整读完再动笔）
> 1. `<仓库根>/README.md` —— 项目总规范（页面结构、图示规范、来源标注）。
> 2. `<仓库根>/408基础/计算机网络/TCP三次握手与四次挥手.html` —— 页面骨架金标准：`<style>` 整块、卡片四节（k=知识点梳理 / p=考点说明 / q=示例题目 / s=解答说明）、div.recap 要点速记、判分 `<script>` 整块、多选 data-multi + opt-submit 结构，全部从这里逐字复制。
> 3. `<仓库根>/408基础/数据结构/二叉树性质遍历与哈夫曼.html` —— 同子类已验收样例，标题措辞、计算题（div.q + details）写法、mermaid 配对写法向它看齐。
>
> ## 硬规则
> - 每页 `<title>` 格式：`<知识点名> · 408基础/数据结构`，必须有 " · "（构建脚本靠它提标题）。
> - `<style>` 块和判分 `<script>` 块从 TCP 页逐字复制，不许自己重写、不许增删选择器。CSS 里 .opt.picked 必须在 .opt.right/.wrong/.miss 之前（复制原块天然满足，别动顺序）。
> - 单选题：div.quiz + data-answer="X"，选项 div.opt data-k="A"…，解析 div.exp 放最后一个 opt 之后。
> - 多选题：div.quiz data-answer="XY…" data-multi，选项后必须有 div.opt-submit 内含提交按钮，exp 在 opt-submit 之后。
> - 口述题/计算题：div.q + `<details>`（内含解答），不用 .quiz。
> - mermaid 图规范：每张图配对两个块 `<pre class="ascii-fallback">`（纯 ASCII 版）+ `<pre class="mermaid">`（mermaid 源码），页面末尾放 TCP 页那个 `<script type="module">` mermaid 加载块，逐字复制；mermaid 成功则删 ascii 版，失败则删 mermaid 版。每个 mermaid 节点 id 用英文，label 可中文。
> - 代码块内所有 < 和 > 转义为实体（泛型写 `List&lt;Integer&gt;`）。
> - 题目来源只允许这三种标注，逐字使用、不编造年份：`来源：408 统考高频题型（公开真题常考形式）。`、`来源：牛客经典题。`、`来源：面试高频改编。` 每题 exp 或 q 尾部带其一，全页混用，别整页同一个。
> - 每页 5 题左右：单选 2 + 多选 1 + 计算/口述 2；数据结构是计算重灾区，计算题要给完整手算过程（表格或步骤列表）。
> - 示例代码用 Java 为主（能给的都给 Java），需要对照时加 Python 短版。
> - 写完每页自查：title 含 " · "；quiz 数 = data-answer 数 = exp 数；每个 data-multi 配一个 opt-submit+submit；无裸 < > 残留；来源只用了白名单措辞。
>
> ## 7 个文件与内容要点（全部落在 `<仓库根>/408基础/数据结构/` 下）
> 1. 链表与线性表.html —— 顺序表 vs 链表对比（存取/插入删除/空间）、单/双/循环链表、头插尾插建表序列；mermaid graph LR 画单链表插入删改指针变化；Java 代码：单链表反转 + 快慢指针判环，Python 对照。题：头插法建表后序列单选、带尾指针循环单链表判尾条件单选、链表 vs 顺序表优缺点多选、双链表在 p 前插节点的指针操作口述、两类表按序查找/按位插入复杂度对比计算。
> 2. 串与 KMP.html —— 串的定长/堆/块链存储一句带过、朴素匹配 O(nm) 主串指针回退、next 数组定义与手算、KMP O(n+m)、nextval 一句带过。题：给模式串手算 next 数组（完整步骤表）、朴素匹配比较次数计算、KMP 失配时主串指针是否回退单选、KMP 适用场景与性质多选、口述 next[j] 含义与失配行为。
> 3. 图的存储与遍历.html —— 邻接矩阵 vs 邻接表（空间、性质、出入度差异）、DFS 递归栈/BFS 队列、连通分量与生成树、并查集两行带过；mermaid graph 画一个 6 顶点无向图。题：给定邻接表求 DFS 序列单选、BFS 序列与最短跳数计算、邻接矩阵性质多选、非连通图遍历次数计算、口述 DFS vs BFS 空间复杂度差异。
> 4. 最小生成树与最短路.html —— Prim（顶点扩展、O(n²)、稠密图）/Kruskal（边排序+并查集、O(eloge)、稀疏图）、MST 可能不唯一但权值和唯一、Dijkstra 贪心不支持负权边、Floyd O(n³) 可负权边不可负环；mermaid 画 5 顶点加权图。题：给定图求 MST 权值和计算（列 Kruskal 选边顺序）、Dijkstra 迭代表计算、负权边场景单选、MST 性质多选、口述稠密 vs 稀疏图算法选型。
> 5. 拓扑排序与关键路径.html —— AOV 网、拓扑序列存在 ⇔ 无环、同一图拓扑序列不唯一、逆邻接表与逆拓扑；AOE 网：事件最早最晚 ve/vl、活动 e/l、关键路径=最长路径、缩短关键活动不一定缩短工期。题：给定 AOV 网写出所有拓扑序列并数个数、AOE 网关键路径长度与关键活动计算（ve/vl 表）、有环时拓扑排序行为单选、关键活动性质多选、口述求关键路径完整步骤。
> 6. 查找与二叉排序树.html（title 写 `查找：折半/BST/AVL/B 树`，文件名不带冒号）—— 折半查找判定树与最多比较次数、ASL 成功/失败计算、BST 插入删除、AVL 四种旋转触发条件、B 树阶性质。题：折半查找比较过程计算、有序表 ASL 计算、AVL 旋转类型单选、B 树性质多选、口述 BST 中序遍历为何有序。
> 7. 散列查找与冲突处理.html —— 除留余数散列函数（p 取不超过表长的最大素数）、开放定址线性/平方探测、链地址法、装填因子、堆积现象。题：散列函数+线性探测逐个插入并算成功 ASL 的完整计算、装填因子计算、冲突处理方法对比多选、堆积现象单选、口述链地址法优缺点。
>
> ## 交付汇报格式
> 逐页列：文件名 / title 行 / 题目数与题型分布 / mermaid 图数 / 使用的来源措辞统计 / 自查结果。最后列"替你决定了这些"（答案字母分布、例子选取等自由裁量）。

## 样例交付后的验收动作

子代理交卷 ≠ 收货。本批实际的验收流程，供对照：

1. 独立 grep 校验 7 页结构（不采信子代理自报）：title 格式、quiz/data-answer/exp 数量对齐、data-multi 与提交按钮配对、CSS 级联顺序、来源白名单。
2. 数值类题目抽算：next 数组按教材口径核对、Dijkstra 迭代表逐步复算。
3. PAGES.md 底账用脚本勾选（7 项），重跑 `build_checklist.py`，页数从 63 涨到 70。
4. 人工只处理例外：文件名与底账不一致（如"串与 KMP.html"带空格）时以实际文件为准改底账。
