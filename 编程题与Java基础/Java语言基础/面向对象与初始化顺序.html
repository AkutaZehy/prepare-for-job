面向对象与初始化顺序

适用岗位：测开(Java)、通用软开 ｜ 形态：概念 + 输出判断 + 面试口述 ｜ 更新：2026-09-30
要点速记：三大特性一句话——封装=private 字段+公开方法控制访问；继承=extends 复用+单继承；多态=父类引用指向子类对象。重写口诀两同两小一大（方法名参数相同、返回值异常更小、访问权限更大）。初始化顺序：父静态→子静态→父实例块→父构造→子实例块→子构造，静态只执行一次；多态方法看运行时类型、字段看编译时类型。

一、知识点梳理

三大特性，各一句话：封装——字段 private、行为公开，用 getter/setter 控制访问边界；继承——extends 复用并扩展父类，Java 只支持单继承（接口可多实现），构造子类必先构造父类；多态——父类引用指向子类对象，编译看左边（引用类型），运行看右边（实际对象）。

重载 vs 重写（重写口诀：两同两小一大——方法名与参数列表相同；返回值类型与抛出的异常更小或相同；访问权限更大或相同）

对比点重载 Overload重写 Override
位置同一个类里父子类之间
参数列表必须不同必须相同
返回值可以不同相同或更小（子类型）
抛出异常无要求更小或相同，不能抛新的更大 checked 异常
访问权限无要求更大或相同
绑定编译期按参数静态绑定运行期动态绑定

构造器与 this / super：构造器与类同名、没有返回值；this(...) 调本类重载构造器、super(...) 调父类构造器，二者都必须是构造器第一行，因此不能同时出现；不写 super(...) 时编译器自动插入父类无参构造调用——父类没有无参构造而子类又没显式调用，直接编译错。

类初始化顺序（静态部分只在类第一次被使用时执行一次）

  • ① 父类静态变量、静态代码块（同一类内按书写顺序）
  • ② 子类静态变量、静态代码块
  • ③ 父类实例变量、实例代码块
  • ④ 父类构造器
  • ⑤ 子类实例变量、实例代码块
  • ⑥ 子类构造器
  • 第二次 new 同一个类：从 ③ 开始重复，①② 不再执行。
Java 
public class InitOrder {
    static class Parent {
        static { System.out.println("1 父类静态块"); }
        { System.out.println("3 父类实例块"); }
        Parent() { System.out.println("4 父类构造器"); }
    }

    static class Child extends Parent {
        static { System.out.println("2 子类静态块"); }
        { System.out.println("5 子类实例块"); }
        Child() { System.out.println("6 子类构造器"); }
    }

    public static void main(String[] args) {
        new Child();
        System.out.println("--- 第二次 new，静态不再执行 ---");
        new Child();
    }
}
// 输出：1 父类静态块 / 2 子类静态块 / 3 父类实例块 / 4 父类构造器
//       / 5 子类实例块 / 6 子类构造器 / ---分隔线
//       / 3 / 4 / 5 / 6（再来一轮，静态消失）
Java 
class Calc {
    int add(int a, int b) { return a + b; }          // 基准方法
    double add(double a, double b) { return a + b; } // 重载：同名不同参
}

class SciCalc extends Calc {
    @Override
    public int add(int a, int b) { return a + b; }   // 重写：两同（方法名、参数）
    // 两小：返回值 int 不变、不抛更大异常；一大：public 权限不小于父类默认权限
}

多态绑定：方法看运行时类型，字段看编译时类型：实例方法调用是动态绑定——JVM 按对象实际类型在虚方法表里找实现，重写生效；字段和 static 方法是静态绑定——编译期就按引用的静态类型解析好了。所以 Parent p = new Child() 时，p.field 取到的是 Parent 的字段，p.method() 调到的是 Child 的方法。

接口 vs 抽象类：抽象类单继承，可以有构造器、实例字段和任意方法，适合"is-a + 复用模板代码"；接口多实现，成员变量隐式 public static final，JDK8 起可有 default/static 方法、JDK9 起可有 private 方法，适合"定义能力契约、制造多继承效果"。接口有了 default 方法也存不了每个对象各自的实例状态——这是与抽象类的本质区别。

Python 
class Parent:
    def greet(self):
        return "parent"

class Child(Parent):
    def greet(self):          # 重写
        return "child"

p = Child()
print(p.greet())   # child：按对象实际类型查找，天生动态绑定
# Python 没有编译期静态类型，不存在"字段看编译时类型"的陷阱

二、考点说明

笔试选择输出判断面试口述

  • 输出判断：初始化顺序题最经典——给父子类静态块/实例块/构造器问打印顺序，陷阱在"静态只执行一次"。
  • 概念选择：重写"两同两小一大"、final/static/abstract 组合合法性、接口 default 方法（JDK8 分水岭）。
  • 面试口述：多态绑定机制（为什么方法动态绑定、字段静态绑定）、接口与抽象类怎么选。

三、示例题目（点击选项即时判分）

输出判断1. 以下代码，main 中连续执行 new Child(); new Child();，输出是（  ）

class Parent {
    static { System.out.print("A"); }
    { System.out.print("B"); }
    Parent() { System.out.print("C"); }
}
class Child extends Parent {
    static { System.out.print("D"); }
    { System.out.print("E"); }
    Child() { System.out.print("F"); }
}
A. ADBCEFBCEF
B. ADBCEFADBCEF
C. ABCDEFABCDEF
D. DABCEFDABCEF
答案 A。第一次使用 Child：父类静态 → 子类静态（AD，仅此一次）；随后每次 new 走"父实例块→父构造→子实例块→子构造"（BCEF 两轮）。B 错在静态重复执行，D 错在子类静态先于父类。来源：牛客经典题。

单选2. 父类方法签名 protected Number calc(int x) throws IOException，子类重写合法的是（  ）

A. public Integer calc(int x) throws FileNotFoundException
B. private Integer calc(int x)
C. public Integer calc(long x)
D. public Integer calc(int x) throws Exception
答案 A。按"两同两小一大"逐项对：方法名参数相同；返回值 Integer 是 Number 的子类型（更小）、FileNotFoundException 是 IOException 的子类（更小）；public 比 protected 大。B 权限更小；C 参数变了是重载不是重写；D 抛了更大的 checked 异常。来源：面试高频改编。

多选3. 关于 final、static、abstract 修饰符，下列说法正确的有（  ）

A. final 类不能被继承，final 方法不能被重写，final 变量只能赋值一次
B. 抽象类不能实例化，但可以有构造器，供子类通过 super 调用
C. abstract 方法可以同时被 static 或 final 修饰
D. static 方法属于类而不属于实例，不能被重写，子类的同名静态方法只是隐藏
答案 ABD。C 错——abstract 与 final、static、private 天生互斥：abstract 要靠子类实现并参与多态，final 不许重写，static 不走动态绑定。D 正确：子类定义同签名静态方法只是"隐藏"父类版本，调用看编译时类型。来源：JavaGuide 收录题型。

单选4. 关于 JDK8 之后的接口与抽象类，说法正确的是（  ）

A. 接口有了 default 方法，就能像抽象类一样保存每个对象各自的实例状态
B. 接口成员变量隐式 public static final，无法持有实例状态；抽象类可以有实例字段与构造器
C. 一个类只能继承一个抽象类，也只能实现一个接口
D. 接口的 default 方法在 JDK8 之前就已经存在
答案 B。JDK8 起接口才有 default/static 方法（JDK9 起才有 private 方法），但成员变量永远是 public static final 常量，没有实例状态；类可多实现接口、单继承抽象类。选型口诀：共享代码与状态用抽象类，定义能力契约用接口。来源：面试高频改编。

面试口述5. 口述 Java 多态的绑定机制：为什么"方法看运行时类型、字段看编译时类型"？

参考回答分编译期与运行期两步：① 编译期，编译器只认引用的静态（编译时）类型——用它检查方法是否存在、确定方法签名，生成 invokevirtual 指令；字段访问也是在这一步按静态类型解析好写进字节码的。② 运行期，JVM 执行 invokevirtual 时按对象的实际类型去虚方法表里找同签名的实现——这就是动态绑定，重写因此生效。而字段、static 方法、private 方法与构造器不走虚方法表，属于静态绑定。所以结论是"方法看运行时、字段看编译时"。加分点：说出 invokevirtual/invokestatic 区别、虚方法表（vtable）。来源：面试高频改编。

四、易错点小结

① 初始化顺序一句话：父静态→子静态→父实例块→父构造→子实例块→子构造，静态只一次；② 实例块总在构造器方法体之前执行；③ 判断重写合法性按"两同两小一大"逐项对，参数一变就成重载；④ 接口 default/static 是 JDK8 起、private 是 JDK9 起，老资料"接口全是抽象方法"要修正；⑤ static 方法与字段不参与多态，都看编译时类型。
