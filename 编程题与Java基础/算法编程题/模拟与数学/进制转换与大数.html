进制转换与大数运算（ACM 模式）

适用岗位：全部（小中厂 Java/Python 笔试高频，大数题是笔试常客） ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：进制双向——十→k 短除取余反转，k→十按权展开（Horner：res = res*k + digit）；大数三路线——Java BigInteger（add/multiply/divide/mod 一族）、Python int 天生大数、通用字符串竖式模拟（对齐、逐位加、进位、末位判进位）；日期差=统一折算总天数再相减；约瑟夫=递推 f(i)=(f(i-1)+m)%i。

一、题目与 IO 约定

题 1（主打）大数加法：两行各一个非负整数（可达数百位，long 存不下），输出它们的和。来源：牛客经典题。

输入格式（2 行）： 
12345678901234567890
98765432109876543210
输出格式： 
111111111011111111100

题 2 进制转换：一行 n 与 k（n 为十进制非负整数，2 ≤ k ≤ 16），输出 n 的 k 进制表示（10~15 用大写 A~F）。n=0 输出 0。来源：牛客经典题。

输入格式： 
31 16                   # n k
输出格式： 
1F

题 3 日期计算（核心函数）：闰年判断；两日期相差天数。例：2024-02-28 到 2024-03-01 相差 2 天（2024 是闰年，2 月 29 日存在）。来源：牛客经典题。

题 4 约瑟夫环（核心函数）：n 人围圈编号 1..n，从 1 起报数报到 m 出列，下一位从 1 重新报；输出幸存者编号。n=5、m=3 → 4。来源：牛客经典题。

大数题先看位数：≤18 位 long 可接（10¹⁸ 量级），更长的必须 BigInteger / Python int / 字符串模拟；输入是否带前导零看题面，一般保证无前导零。

二、思路

1. 进制转换（双向）：十进制转 k 进制——短除法取余，余数按"低位→高位"依次得到，最后反转；k 进制转十进制——按权展开，用 Horner 式 res = res*k + digit 从左往右一遍扫完（不用真算幂）。负进制（如 −2）笔试少见：套短除框架，余数为负时按题意借位调整（r = (n % k + k) % k 这类处理），见题再套。时间 O(log_k n)。

2. 大数运算（Java vs Python vs 通用竖式）：路线 A——Java BigInteger，add / subtract / multiply / divide / mod 一族（对象不可变，a.add(b) 要接收返回值；比较用 compareTo）；路线 B——Python int 天生无上限，直接算；路线 C——字符串竖式模拟（任何语言通用，面试手写高频）：从末位对齐，逐位相加再加进位，低位先存，最后整体反转；循环条件 i >= 0 || j >= 0 || carry > 0——最后还有进位也要补一位（999+1=1000 就是靠它）。时间 O(位数)。

3. 日期计算：闰年规则——能被 4 整除且不能被 100 整除，或能被 400 整除（2000 闰、1900 不闰、2024 闰）。两日期差：把两个日期分别折算成"从公元 1 年 1 月 1 日起的总天数"（整年 365 + 闰年补偿 + 当年逐月累计 + 日，2 月 29 只影响当年 3 月及以后的累计），再相减；数据小也可以逐日/逐年模拟前进。O(1)。

4. 约瑟夫环：模拟法 O(nm)——数组圈着数，报 m 出列；递推公式 O(n)：编号 0 起始，f(1)=0，f(i) = (f(i-1) + m) % i（幸存者在 i 人圈中的位置 = 在 i−1 人圈中的位置整体左移 m 再取模），答案按题面转 1 起始 +1。验证 n=5、m=3：f = 0 → (0+3)%2=1 → (1+3)%3=1 → (1+3)%4=0 → (0+3)%5=3，+1 得 4，与模拟法一致。

概念自测点击选项即时判分。

A. 3
B. 4
C. 5
D. 1
答案 B。递推 f：0→1→1→0→3（0 起始），+1 得 4；也可模拟：出列顺序 3、1、5、2，剩 4。来源：牛客经典题。

通用字符串竖式模拟版（面试手写这版，任何语言都这么写）：

Java 
// 竖式加法：从末位对齐，逐位加，低位先存，最后整体反转
static String bigAdd(String a, String b) {
    StringBuilder sb = new StringBuilder();
    int i = a.length() - 1, j = b.length() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry > 0) {   // 最后还有进位也要补一位
        int s = carry;
        if (i >= 0) s += a.charAt(i--) - '0';
        if (j >= 0) s += b.charAt(j--) - '0';
        sb.append(s % 10);
        carry = s / 10;
    }
    return sb.reverse().toString();   // 低位先存，反转后输出
}
Python 
def big_add(a, b):
    i, j, carry = len(a) - 1, len(b) - 1, 0
    res = []
    while i >= 0 or j >= 0 or carry:          # 最后还有进位也要补
        da = int(a[i]) if i >= 0 else 0
        db = int(b[j]) if j >= 0 else 0
        s = da + db + carry
        res.append(str(s % 10))
        carry = s // 10
        i -= 1; j -= 1
    return ''.join(reversed(res))             # 低位在前存，最后反转

题 2 进制转换（完整程序）：短除法 + "0123456789ABCDEF" 查表。

Java 
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); long n = (long) in.nval;
        in.nextToken(); int k = (int) in.nval;

        final String tab = "0123456789ABCDEF";
        if (n == 0) { System.out.println(0); return; }   // 边界：0 直接输出
        StringBuilder sb = new StringBuilder();
        while (n > 0) {
            sb.append(tab.charAt((int) (n % k)));   // 短除法取余（低位先出）
            n /= k;
        }
        System.out.println(sb.reverse());           // 余数反转 = 高位到低位
    }
}
Python 
import sys

def to_base(n, k):
    tab = "0123456789ABCDEF"
    if n == 0:
        return "0"                # 边界：0 直接返回
    res = []
    while n > 0:
        res.append(tab[n % k])    # 短除法取余
        n //= k
    return ''.join(reversed(res)) # 低位先出，反转后输出

def to_dec(s, k):
    tab = "0123456789ABCDEF"
    res = 0
    for c in s:
        res = res * k + tab.index(c)   # 按权展开（Horner），反方向自测用
    return res

def main():
    data = sys.stdin.read().split()
    n, k = int(data[0]), int(data[1])
    print(to_base(n, k))

main()

题 3 日期计算 / 题 4 约瑟夫环（核心函数）

Java 
static final int[] DAYS = {31,28,31,30,31,30,31,31,30,31,30,31};

// 闰年：能被 4 整除且不能被 100 整除，或能被 400 整除
static boolean isLeap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
}

// 从公元 1 年 1 月 1 日起算到 y-m-d 的总天数（不含当天）；两日期差 = 两值相减
static long absDays(int y, int m, int d) {
    long n = (y - 1) * 365L + (y - 1) / 4 - (y - 1) / 100 + (y - 1) / 400;  // 整年贡献
    for (int i = 1; i < m; i++) n += DAYS[i - 1];   // 当年已过整月
    if (m > 2 && isLeap(y)) n++;   // 闰年 2 月 29 只影响 3 月及以后
    return n + d - 1;
}
// 自测：absDays(2024,3,1) - absDays(2024,2,28) = 2（闰年有 2 月 29）
//      absDays(2023,3,1) - absDays(2023,2,28) = 1（平年）

// 约瑟夫递推 O(n)：f(1)=0，f(i)=(f(i-1)+m)%i，编号 0 起始
static int joseph(int n, int m) {
    int f = 0;
    for (int i = 2; i <= n; i++) f = (f + m) % i;
    return f + 1;                  // 按题面 1 起始编号输出
}
Python 
DAYS = [31,28,31,30,31,30,31,31,30,31,30,31]

def is_leap(y):
    return (y % 4 == 0 and y % 100 != 0) or y % 400 == 0

def abs_days(y, m, d):
    # 从公元 1 年 1 月 1 日起的总天数；两日期差 = 两值相减
    n = (y - 1) * 365 + (y - 1) // 4 - (y - 1) // 100 + (y - 1) // 400
    n += sum(DAYS[:m - 1])
    if m > 2 and is_leap(y):
        n += 1
    return n + d - 1
# 自测：abs_days(2024,3,1) - abs_days(2024,2,28) = 2

def joseph_sim(n, m):
    people = list(range(n))               # 模拟法 O(nm)，编号 0..n-1
    idx = 0
    while len(people) > 1:
        idx = (idx + m - 1) % len(people) # 数到第 m 个出列
        people.pop(idx)                   # pop 后 idx 恰好指向下一个人
    return people[0] + 1                  # 1 起始

def joseph(n, m):
    f = 0                                 # 递推 O(n)
    for i in range(2, n + 1):
        f = (f + m) % i
    return f + 1                          # n=5, m=3 → 4
进制题考场自测法：转过去再转回来（1F 按 16 进制展开 = 1×16+15 = 31），进出一致才提交。

四、易错点小结

① n=0 边界直接输出 "0"（短除法循环一次都不进，否则输出空串）；② 短除法余数低位先出，最后必须反转；③ 竖式模拟循环条件带 carry，999+1 这类"最高位进位"别丢；④ BigInteger 不可变：a.add(b) 的返回值要接住，比较用 compareTo；⑤ 输入/输出都别带前导零（题面若给 "007" 先 strip，模拟结果开头连续 0 也要 strip，全 0 时留一个 "0"）；⑥ 闰年 2 月 29 只影响当年 3 月及以后的月累计；⑦ 约瑟夫输出按题面编号（0 起还是 1 起），差一个 +1。
