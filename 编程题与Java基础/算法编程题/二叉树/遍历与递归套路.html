二叉树遍历与递归套路（ACM 模式）

原型：LeetCode 104 / 226 / 101 ｜ 适用岗位：全部 ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：ACM 二叉树题标配是层序建树（数据按层序给、空位用 -1 占，队列实现），建完树三大递归遍历各三行。递归套路三问：base case 是什么、左右子树问题怎么定义、拿子问题答案怎么拼出当前层。力扣上树是现成的，ACM 里建树占一半工作量。

一、题目与 IO 约定

主打题（层序建树 + 三种遍历）：给定 n 个整数按层序描述一棵二叉树，-1 表示空节点（结尾不足的槽位视为空）。输出三行：前序、中序、后序遍历序列，数字间空格分隔。

输入格式（2 行）： 
5                       # n
1 2 3 -1 4              # 层序，-1 表示空节点
这棵树：根 1，左孩 2（其左空、右孩 4），右孩 3。 输出格式（3 行）： 
1 2 4 3
2 4 1 3
4 2 3 1
变体提前看：① 有的题空位用字符串 null 而不是 -1，读法换成按词切分；② 输出可能只要一种遍历或层序（层序直接就是建树那趟队列）；③ 结点值可能很大 → 用 long。

二、思路

  • 层序建树：节点按层序排队，用一个队列装「还没填满孩子的父节点」。每读一个值：非 -1 就建节点挂到队头父节点的空位上（左优先），挂满右位就把父节点出队；-1 只占位不入队。注意 Java 里 ArrayDeque 不许 null，占位要入队时用 LinkedList；本页写法是「-1 不入队」，两者都行，关键是每槽位严格消费一个 token。
  • 三种遍历：递归框架 左、根、右 的访问位置不同——前序=进入时访问，中序=左子树回来后访问，后序=两棵子树都回来后访问。时间 O(n)、递归栈 O(h)。
  • 最大深度（LC104）：递归套路最小例子——depth(x) = 1 + max(depth(x.l), depth(x.r))，base case 空树返回 0。
  • 唯一复原：中序 + 前序 / 中序 + 后序可以唯一确定二叉树；前序 + 后序不能（只有一个孩子的节点无法区分左右）。
  • 翻转（LC226）/ 对称（LC101）：翻转=交换左右子树后递归；对称=递归比较「左的左 vs 右的右、左的右 vs 右的左」。

概念自测点击选项即时判分。

单选1. 只给一对遍历序列，不能唯一确定一棵二叉树的是（  ）

A. 中序 + 前序
B. 前序 + 后序
C. 中序 + 后序
D. 中序 + 层序
答案 B。缺了中序就分不出左右。反例：根 1、左孩 2 与根 1、右孩 2 的前序都是 1 2，后序都是 2 1。来源：408 统考高频题型（公开真题常考形式）。

多选2. 关于二叉树递归，说法正确的有（  ）

A. 写递归先把函数定义当黑盒：明确「它对子树算出什么」，再想当前层怎么拼
B. base case（通常 x == null）必须最先写，否则空指针或死递归
C. 二叉树问题都可以做到 O(1) 空间
D. 层序遍历用队列，非递归前序/中序用显式栈
答案 ABD。递归本身就要 O(h) 栈空间，最坏退化成 O(n)（链状树），C 错。来源：面试高频改编。

Java · 主打：层序建树 + 三种遍历 
import java.io.*;
import java.util.*;

public class Main {
    static StringBuilder sbPre = new StringBuilder();
    static StringBuilder sbIn = new StringBuilder();
    static StringBuilder sbPost = new StringBuilder();

    static class Node {
        int v; Node l, r;
        Node(int v) { this.v = v; }
    }

    static Node build(int[] vals, int n) {
        if (n == 0 || vals[0] == -1) return null;
        Node root = new Node(vals[0]);
        Queue<Node> que = new LinkedList<>();
        que.add(root);
        int i = 1;
        while (!que.isEmpty() && i < n) {
            Node p = que.poll();
            if (vals[i] != -1) { p.l = new Node(vals[i]); que.add(p.l); }
            i++;
            if (i >= n) break;
            if (vals[i] != -1) { p.r = new Node(vals[i]); que.add(p.r); }
            i++;
        }
        return root;
    }

    static void dfsPre(Node x)  { if (x == null) return; sbPre.append(x.v).append(' ');  dfsPre(x.l);  dfsPre(x.r); }
    static void dfsIn(Node x)   { if (x == null) return; dfsIn(x.l);  sbIn.append(x.v).append(' ');  dfsIn(x.r); }
    static void dfsPost(Node x) { if (x == null) return; dfsPost(x.l); dfsPost(x.r); sbPost.append(x.v).append(' '); }

    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        int[] vals = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); vals[i] = (int) in.nval; }
        Node root = build(vals, n);
        dfsPre(root); dfsIn(root); dfsPost(root);
        System.out.println(sbPre.toString().trim());
        System.out.println(sbIn.toString().trim());
        System.out.println(sbPost.toString().trim());
    }
}
Python · 主打 
import sys
from collections import deque

class Node:
    __slots__ = ('v', 'l', 'r')
    def __init__(self, v):
        self.v, self.l, self.r = v, None, None

def build(it):
    try:
        v = next(it)
    except StopIteration:
        return None
    root = None if v == -1 else Node(v)
    que = deque([root])
    while que:
        p = que.popleft()
        for attr in ('l', 'r'):
            try:
                v = next(it)
            except StopIteration:
                v = -1
            if v != -1 and p is not None:
                ch = Node(v)
                setattr(p, attr, ch)
                que.append(ch)
    return root

pre, ino, post = [], [], []
def walk(x):
    if x is None:
        return
    pre.append(x.v)
    walk(x.l)
    ino.append(x.v)
    walk(x.r)
    post.append(x.v)

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    root = build(iter(list(map(int, data[1:1 + n]))))
    walk(root)
    print(' '.join(map(str, pre)))
    print(' '.join(map(str, ino)))
    print(' '.join(map(str, post)))

static Node invert(Node x) {              // 返回翻转后的子树根
    if (x == null) return null;
    Node t = invert(x.l);
    x.l = invert(x.r);
    x.r = t;
    return x;
}

static boolean isSym(Node a, Node b) {    // 调用：isSym(root.l, root.r)
    if (a == null || b == null) return a == b;
    return a.v == b.v && isSym(a.l, b.r) && isSym(a.r, b.l);
}

四、易错点小结

① 建树时每个槽位（含 -1）都要消费一个 token，左右漏读一位全树错位；② ArrayDeque 不能装 null，「占位入队」写法必须用 LinkedList；③ 遍历输出用 StringBuilder 拼完再 trim，逐次 System.out.print 会被大数据量卡慢；④ 递归深度 10⁵ 级链状树会 StackOverflow，改显式栈或层序；⑤ 「前序 + 后序定不了树」是笔试选择题钉子户。
