背包与线性 DP（ACM 模式）

适用岗位：全部（小中厂 Java/Python 笔试高频） ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：DP 五步曲——状态定义→转移方程→初始化→遍历顺序→手动模拟验证；线性 DP（爬楼梯/打家劫舍/LCS）是转移方程题；0-1 背包一维滚动数组容量倒序（防同一件重复选），完全背包正序——笔试最爱考的坑。

一、题目与 IO 约定

题 1（主打）0-1 背包：n 件物品（每件至多选一次），背包容量 W；输入 n、W 与每件重量/价值，输出能装下的最大价值。来源：牛客经典题。

输入格式（1 + n 行）： 
4 5                     # n 容量W
1 2                     # 重量 价值
2 4
3 4
4 5
输出格式： 
8

题 2 打家劫舍（LC198）：第一行 n，第二行 n 个非负整数金额；不能偷相邻两家，输出能偷到的最大金额。来源：LeetCode 经典题（ACM 改编）。

输入格式（2 行）： 
5                       # n
2 7 9 3 1               # n 个金额
输出格式： 
12

题 3 爬楼梯（LC70，核心函数）：每次爬 1 或 2 阶，n 阶的爬法数（n=3 → 3：1+1+1、1+2、2+1）。来源：LeetCode 经典题（ACM 改编）。

题 4 最长公共子序列（LC1143，核心函数）：两行字符串，输出 LCS 长度；如 abcde 与 ace → 3。来源：LeetCode 经典题（ACM 改编）。

DP 题先看数据范围定复杂度：n ≤ 10² 随便写；n ≤ 10³~10⁴ 上 O(n²)/O(nW)；10⁵ 以上想线性或贪心。价值累加可能超 int 时换 long。

二、思路

DP 五步曲：① 状态定义（dp[i] / dp[i][j] 的确切含义，一句话说清）；② 转移方程（当前状态由哪些更小的状态推来）；③ 初始化（边界与"不可达"状态）；④ 遍历顺序（保证算 dp[i] 时依赖的状态已算好）；⑤ 手动模拟验证——拿小样例人肉填表（下表就是题 1 样例的手算结果，答案 8 与程序输出一致才算过）。

1. 爬楼梯（LC70）：f(i) = f(i-1) + f(i-2)（最后一步跨 1 或 2 阶），就是斐波那契。f(0)=f(1)=1。时间 O(n)、空间 O(1)。

2. 打家劫舍（LC198）：两个状态——f = 偷当前家的最大收益 = g_prev + a[i]（前一家必须不偷）；g = 不偷当前家 = max(f_prev, g_prev)。答案 max(f, g)。两个滚动变量即可，时间 O(n)、空间 O(1)。变体：环形版拆两条线性。

3. 最长公共子序列（LC1143）：dp[i][j] = a 前 i 个字符与 b 前 j 个字符的 LCS 长度。a[i-1] == b[j-1] 时 dp[i][j] = dp[i-1][j-1] + 1；否则 max(dp[i-1][j], dp[i][j-1])。时间 O(mn)、空间 O(mn)（可滚动优化）。

4. 0-1 背包（一维滚动）：二维 dp[i][j] = max(dp[i-1][j], dp[i-1][j-w] + v) 压成一维后，容量必须倒序遍历。为什么倒序：dp[j] 要用的 dp[j-w] 必须还是"还没考虑第 i 件"的旧值——倒序时 dp[j-w] 本轮尚未更新，正是旧值，每件物品至多选一次；若正序，dp[j-w] 可能已被本轮更新过（已含第 i 件），等于同一件被选两次——那恰好是完全背包的写法。反例：一件 (w=1, v=2)、容量 2，正序算出 dp[2]=4（一件变两件），倒序正确得 2。时间 O(nW)、空间 O(W)。初始化："至多装"全 0；"恰好装满" dp[0]=0 其余 −∞。

概念自测点击选项即时判分。

单选1. 0-1 背包一维滚动数组必须容量倒序遍历，原因是（  ）

A. 倒序能减少循环次数、跑得更快
B. 倒序保证 dp[j-w] 还是上一轮（未考虑本件物品）的旧值，防止同一件被重复选取
C. 倒序是为了处理容量为 0 的边界
D. 正序会数组越界
答案 B。反例：一件 (w=1, v=2)、容量 2，正序得 dp[2]=4（同一件选了两次），倒序正确得 2；正序写法恰恰是完全背包。来源：牛客经典题。

多选2. 关于背包的初始化与遍历方向，正确的有（  ）

A. 求"至多能装的最大价值"：dp 全 0 初始化即可
B. 求"恰好装满的最大价值"：dp[0]=0，其余设为负无穷表示不可达
C. "恰好装满"也可以全 0 初始化，结果一样
D. 一维 0-1 背包容量倒序，完全背包容量正序
答案 ABD。全 0 初始化下"恰好装满"题会把没装满的状态当合法价值混进来，C 错。来源：牛客经典题。

三、ACM 完整代码（可直接粘贴牛客）

题 1 0-1 背包（完整程序）：Java 用 StreamTokenizer 快读（Scanner 在 10⁵+ 数据量会被卡 TLE）；Python 一维滚动。

Java 
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int w = (int) in.nval;
        int[] wt = new int[n], val = new int[n];
        for (int i = 0; i < n; i++) {
            in.nextToken(); wt[i] = (int) in.nval;
            in.nextToken(); val[i] = (int) in.nval;
        }

        int[] dp = new int[w + 1];               // dp[j]：容量 j 能装的最大价值
        for (int i = 0; i < n; i++) {
            for (int j = w; j >= wt[i]; j--) {   // 容量倒序！防同一件被选两次
                dp[j] = Math.max(dp[j], dp[j - wt[i]] + val[i]);
            }
        }
        System.out.println(dp[w]);
    }
}
Python 
import sys

def main():
    data = sys.stdin.read().split()
    n, w = int(data[0]), int(data[1])
    wt, val = [], []
    idx = 2
    for _ in range(n):
        wt.append(int(data[idx])); val.append(int(data[idx + 1]))
        idx += 2

    dp = [0] * (w + 1)
    for i in range(n):
        for j in range(w, wt[i] - 1, -1):   # 容量倒序，防重复选取
            dp[j] = max(dp[j], dp[j - wt[i]] + val[i])
    print(dp[w])

main()

题 2 打家劫舍（完整程序）：双状态滚动变量版。

Java 
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }

        // f=偷当前家的最大收益，g=不偷当前家的最大收益；long 防累加溢出
        long f = 0, g = 0;
        for (int x : a) {
            long nf = g + x;            // 偷当前 → 前一家必须不偷
            long ng = Math.max(f, g);   // 不偷当前 → 前一家偷不偷都行
            f = nf; g = ng;
        }
        System.out.println(Math.max(f, g));
    }
}
Python 
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    f = g = 0                  # f=偷当前家，g=不偷当前家
    for x in a:
        f, g = g + x, max(f, g)   # 元组赋值，右侧先算，天然"滚动"
    print(max(f, g))

main()

题 3 爬楼梯 / 题 4 最长公共子序列（核心函数）

Java 
// LC70：f(i)=f(i-1)+f(i-2)，斐波那契
int climb(int n) {
    int a = 1, b = 1;              // f(0)=f(1)=1
    for (int i = 2; i <= n; i++) {
        int c = a + b; a = b; b = c;
    }
    return b;                      // n=0/1 直接返回 1
}

// LC1143：dp[i][j] = a 前 i 个与 b 前 j 个字符的 LCS 长度
int lcs(char[] a, char[] b) {
    int m = a.length, n = b.length;
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)           // i 从 1 起，对应字符下标 i-1
        for (int j = 1; j <= n; j++)
            if (a[i - 1] == b[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
    return dp[m][n];
}
Python 
def climb(n):
    a, b = 1, 1                    # f(0)=f(1)=1
    for _ in range(n - 1):
        a, b = b, a + b
    return b                       # n=0/1 返回 1

def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):      # i 从 1 起，对应字符下标 i-1
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
完全背包只改一处：容量改正序（dp[j-w] 用的是"已考虑本件"的新值，允许重复选）。多重背包先按二进制拆分转 0-1 背包，面试口述思路即可。

四、易错点小结

① 倒序原因（正序=完全背包）——最高频考点，要能现场说出反例 (w=1,v=2) 容量 2；② "恰好装满" dp[0]=0 其余 −∞，"至多装"全 0，两问别混；③ 字符串/物品编号 i 从 1 起，对应原数组下标 i-1，别错位；④ n、W 到 10⁴~10⁵ 且价值大时换 long；⑤ 第五步手算验证别省——考场上先填 3×3 小表再写代码，写完用样例对答案；⑥ 打家劫舍环形版（首尾相连）拆成"去掉首"与"去掉尾"两条线性做 max；⑦ LCS 注意"子序列可不连续、子串必须连续"，转移方程不同。
