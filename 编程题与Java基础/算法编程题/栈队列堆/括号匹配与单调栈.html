括号匹配与单调栈（ACM 模式）

适用岗位：全部（小中厂 Java/Python 笔试高频） ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：有效括号=栈配对（右括号查栈顶，结束栈必须空）；单调栈三句话——栈存下标、栈内对应值保持递减、遇到更大元素弹栈结算；最小栈=辅助栈同步压"当前最小"，getMin O(1)。

一、题目与 IO 约定

题 1（主打）有效括号（LC20）：每行一个仅含 ( ) [ ] { } 的字符串，逐行判断括号是否全部正确配对，输出 true / false，读到 EOF。来源：LeetCode 经典题（ACM 改编）。

输入格式（多行，每行一个字符串）： 
{[]}
([)]
输出格式（每行一个）： 
true
false

题 2 每日温度（LC739）：第一行 n，第二行 n 个整数表示当日气温；对每个位置输出"等几天会遇到更高气温"，没有更高则 0，空格分隔。来源：LeetCode 经典题（ACM 改编）。

输入格式（2 行）： 
8                       # n
73 74 75 71 69 72 76 73 # n 个气温
输出格式（1 行）： 
1 1 4 2 1 1 0 0

题 3 下一个更大元素 I（LC496，核心函数）：nums1 是 nums2 的子集，对 nums1 每个元素找它在 nums2 中的下一个更大元素，没有则 -1。来源：LeetCode 经典题（ACM 改编）。

题 4 最小栈（LC155，核心类）：设计支持 push / pop / top / getMin 且各操作 O(1) 的栈。来源：LeetCode 经典题（ACM 改编）。

字符串输入用 BufferedReader.readLine / 逐行 sys.stdin（StreamTokenizer 只认数字）；Windows 环境行尾可能带 \r，readLine 后先 trim。

二、思路

1. 有效括号（LC20）：左括号入栈；右括号来时查栈顶——栈空或栈顶不是配对的左括号 → false；遍历结束栈必须为空（还剩左括号没配对也是 false）。配对关系用 Map（右 → 左）一次写好，避免写三个 if。时间 O(n)、空间 O(n)。

2. 每日温度 / 下一个更大元素（LC739/496）——单调栈模板三句话：① 栈存下标（温度题要算"隔几天" = i − j，存下标才算得出）；② 栈内对应值保持严格递减——还没找到"下一个更大"的元素都压在栈里；③ 遇到更大元素就反复弹栈结算——被弹者的"下一个更大"就是当前元素。每个下标至多进栈、出栈各一次，时间 O(n)、空间 O(n)。LC496 先对 nums2 跑一遍单调栈，把"值 → 下一个更大值"存进 Map，再按 nums1 查表。

3. 最小栈（LC155）：辅助栈与主栈同步压"压入后的当前最小值"（mn.push(min(x, mn.top))），pop 同步弹；任意时刻 mn 栈顶 = 主栈当前最小，getMin O(1)。示例：依次压 5、3、7 → mn 为 [5,3,3]，getMin=3；pop 一次 → getMin 仍 3；再 pop → getMin=5。进阶 O(1) 空间版存差值，面试口述思路即可。

三、ACM 完整代码（可直接粘贴牛客）

题 1 有效括号（完整程序）：逐行读、逐行输出。Java 读字符串用 BufferedReader（Scanner 慢，大数据量会被卡 TLE，且 StreamTokenizer 只能读数字）。

Java 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s;
        while ((s = br.readLine()) != null) {   // 每行一个字符串，读到 EOF
            s = s.trim();                        // 防 Windows 行尾 \r
            System.out.println(isValid(s));
        }
    }

    static boolean isValid(String s) {
        // Map 配对写法：右括号做 key，对应的左括号做 value
        Map<Character, Character> pair = new HashMap<>();
        pair.put(')', '(');
        pair.put(']', '[');
        pair.put('}', '{');
        Deque<Character> st = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (!pair.containsKey(c)) {
                st.push(c);                      // 左括号入栈
            } else {
                // 栈空先判；Character 对象用 equals 比，别用 ==
                if (st.isEmpty() || !st.pop().equals(pair.get(c))) return false;
            }
        }
        return st.isEmpty();     // 别忘了：还剩左括号没配对也是 false
    }
}
Python 
import sys

def is_valid(s):
    pair = {')': '(', ']': '[', '}': '{'}   # 右括号 → 左括号
    st = []
    for c in s:
        if c not in pair:
            st.append(c)                    # 左括号入栈
        elif not st or st.pop() != pair[c]:
            return False                    # 栈空或顶上不是配对的左括号
    return not st                           # 还剩左括号也是 false

def main():
    out = []
    for line in sys.stdin:                  # 每行一个字符串，读到 EOF
        s = line.strip()
        if s:
            out.append('true' if is_valid(s) else 'false')
    print('\n'.join(out))

main()

题 2 每日温度（完整程序）

Java 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        int[] t = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); t[i] = (int) in.nval; }

        int[] ans = new int[n];
        Deque<Integer> st = new ArrayDeque<>();   // 栈存"下标"，栈内温度保持递减
        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && t[i] > t[st.peek()]) {
                int j = st.pop();        // i 是 j 右边第一个更大元素
                ans[j] = i - j;          // 弹栈结算：隔 i-j 天
            }
            st.push(i);                  // 没被弹掉的留在栈里等更大的
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++)
            sb.append(ans[i]).append(i == n - 1 ? '\n' : ' ');
        System.out.print(sb);
    }
}
Python 
import sys

def daily(t):
    n = len(t)
    ans = [0] * n
    st = []                       # 栈存下标，栈内对应温度严格递减
    for i, x in enumerate(t):
        while st and x > t[st[-1]]:
            j = st.pop()
            ans[j] = i - j        # i 是 j 右侧第一个更大元素的下标
        st.append(i)
    return ans

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    t = list(map(int, data[1:1 + n]))
    print(' '.join(map(str, daily(t))))

main()

题 3 下一个更大元素 I / 题 4 最小栈（核心函数）

Java 
// LC496：先对 nums2 跑单调栈，把"值 → 下一个更大值"存进 Map，再按 nums1 查表
int[] nextGreater(int[] nums1, int[] nums2) {
    Map<Integer, Integer> ans = new HashMap<>();
    Deque<Integer> st = new ArrayDeque<>();   // 这题按值查 Map，栈里存值即可
    for (int x : nums2) {
        while (!st.isEmpty() && x > st.peek()) ans.put(st.pop(), x);
        st.push(x);
    }
    int[] res = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) res[i] = ans.getOrDefault(nums1[i], -1);
    return res;
}

// LC155 最小栈：辅助栈同步压"当前最小"，各操作 O(1)
class MinStack {
    private Deque<Integer> st = new ArrayDeque<>();   // 主栈
    private Deque<Integer> mn = new ArrayDeque<>();   // mn 栈顶 = 主栈当前最小
    public void push(int x) {
        st.push(x);
        mn.push(mn.isEmpty() ? x : Math.min(x, mn.peek()));
    }
    public void pop() { st.pop(); mn.pop(); }         // 同步弹
    public int top() { return st.peek(); }
    public int getMin() { return mn.peek(); }
}
Python 
def next_greater(nums1, nums2):
    ans, st = {}, []              # 值 → 右边第一个更大值
    for x in nums2:
        while st and x > st[-1]:
            ans[st.pop()] = x
        st.append(x)
    return [ans.get(v, -1) for v in nums1]
    # 例：nums1=[4,1,2]、nums2=[1,2,3,4] → 输出 [-1, 2, 3]

class MinStack:
    def __init__(self):
        self.st, self.mn = [], []     # mn 与 st 同步压"当前最小"

    def push(self, x):
        self.st.append(x)
        self.mn.append(min(x, self.mn[-1]) if self.mn else x)

    def pop(self):
        self.st.pop()
        self.mn.pop()

    def top(self):
        return self.st[-1]

    def getMin(self):
        return self.mn[-1]            # O(1)
判题对 true/false 大小写敏感，按样例输出小写。多组输入改法同前两页：Java while 读 token/行，Python 的 for line in sys.stdin 本身就是逐行多组写法。

四、易错点小结

① 栈空先判再 peek/pop，右括号先到（如 "())"）就是空栈场景；② 遍历完栈非空也是 false（"((" 只剩左括号没配对）；③ Java 泛型栈里是 Character 对象，比较用 equals 别用 ==——小字符恰好命中缓存时 == "看起来对"，换字符就出错；④ 单调栈存下标不存值（每日温度要算距离）；⑤ 弹栈用 while 不是 if（可能连续结算多个）；⑥ 行末空格与行数严格对齐样例；⑦ 输入行先 trim，防 \r 混进字符串。
