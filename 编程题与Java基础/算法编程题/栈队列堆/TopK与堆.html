TopK 与堆（ACM 模式）

原型：LeetCode 215 / 347 ｜ 适用岗位：全部 ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：TopK 两板斧——size-k 小顶堆：只维护当前最大的 k 个，堆顶就是第 k 大，O(n log k)，数据流也能跑（面试首选）；快速选择：partition 均摊 O(n)，但必须一次读入全部。Java 的 PriorityQueue 默认小顶堆；求第 k 大用小顶堆、第 k 小用大顶堆，方向别背反。

一、题目与 IO 约定

主打题（LC215 数组中第 K 个最大元素）：n 个整数，输出第 k 大的数（从小到大排第 k 个位置，即降序第 k 个）。

输入格式（2 行）： 
6 2                     # n k
3 2 1 5 6 4             # n 个整数
输出格式（1 行）： 
5
变体提前看：① 数据规模写 10⁷ 且强调「不能全排序」→ 指定考堆或快速选择；② 数据是流式给出（先给 n、k 再逐个给数）→ 只能 size-k 堆；③ 要求输出前 k 个 → LC347 / 多路归并。

二、思路

  • 全排序：O(n log n)，最省事，n ≤ 10⁶ 且不卡排序时直接用。
  • size-k 小顶堆（主打）：堆里始终只装「目前见过的最大的 k 个」——新数比堆顶大才替换入堆。堆顶即第 k 大。时间 O(n log k)，空间 O(k)，n 很大或流式输入都稳。为什么是小顶堆：堆顶是 k 个里的最小值，充当「入选门槛」，新数得过门槛才进得来。
  • 快速选择：partition 后看基准落点与目标位置的相对关系，只递归一侧，均摊 O(n)、最坏 O(n²)（随机选 pivot 防退化；笔试口头提一句即可）。
  • 前 K 个高频元素（LC347）：哈希计数 → 按（频次降序、数值升序）取前 k。堆解法：size-k 小顶堆按频次比较；数据范围小时桶排序可到 O(n)。
  • 堆的本质：完全二叉树 + 数组存储（0 起始时 i 的孩子在 2i+1、2i+2）。push 上浮、pop 下沉，均 O(log n)；自底向上建堆（heapify）是 O(n) 不是 O(n log n)。

概念自测点击选项即时判分。

单选1. 求数组第 k 大，为什么常用「size 为 k 的小顶堆」而不是大顶堆？（  ）

A. 小顶堆的 push 比 offer 快
B. 大顶堆不能存重复元素
C. 小顶堆只保留最大的 k 个，堆顶是入选门槛，复杂度 O(n log k)，且支持流式数据
D. 大顶堆在小数据量上反而更慢
答案 C。大顶堆全量入堆再弹 k 次是 O(n log n) 且要一次拿全数据；size-k 小顶堆空间 O(k)、时间 O(n log k)，来一个比一个即可。来源：面试高频改编。

多选2. 关于堆与 Java 的 PriorityQueue，正确的有（  ）

A. PriorityQueue 默认是小顶堆，大顶堆要传 Comparator.reverseOrder() 或自定义比较器
B. 堆是完全二叉树，用数组存，0 起始时下标 i 的孩子是 2i+1 与 2i+2
C. 自底向上 heapify 建堆的复杂度是 O(n log n)
D. 一大一小两个堆（对顶堆）可以动态维护中位数，插入 O(log n)、查询 O(1)
答案 ABD。heapify 自底向下逐个下沉，总代价是 O(n)——各层节点数乘下沉高度的求和收敛，C 错。来源：牛客经典题。

三、ACM 完整代码（可直接粘贴牛客）

Java · 主打 LC215（size-k 小顶堆） 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int k = (int) in.nval;
        PriorityQueue<Integer> pq = new PriorityQueue<>();   // 小顶堆：只装最大的 k 个
        for (int i = 0; i < n; i++) {
            in.nextToken(); int v = (int) in.nval;
            if (pq.size() < k) {
                pq.add(v);
            } else if (v > pq.peek()) {          // 过得了门槛才进来
                pq.poll();
                pq.add(v);
            }
        }
        System.out.println(pq.peek());
    }
}
Python · 主打 LC215 
import sys, heapq

def main():
    data = sys.stdin.read().split()
    n, k = int(data[0]), int(data[1])
    a = list(map(int, data[2:2 + n]))
    heap = a[:k]
    heapq.heapify(heap)
    for v in a[k:]:
        if v > heap[0]:
            heapq.heapreplace(heap, v)
    print(heap[0])

Java · 第二题 LC347（前 K 个高频元素，频次降序、同频数值升序） 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int k = (int) in.nval;
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int i = 0; i < n; i++) {
            in.nextToken(); int v = (int) in.nval;
            cnt.merge(v, 1, Integer::sum);
        }
        // 小顶堆：频次小者先被淘汰；同频时数值大者先被淘汰（保小的）
        PriorityQueue<int[]> pq = new PriorityQueue<>(
                (x, y) -> x[1] != y[1] ? Integer.compare(x[1], y[1])
                                       : Integer.compare(y[0], x[0]));
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            pq.add(new int[]{e.getKey(), e.getValue()});
            if (pq.size() > k) pq.poll();
        }
        int[][] keep = pq.toArray(new int[0][]);
        Arrays.sort(keep, (x, y) -> x[1] != y[1] ? Integer.compare(y[1], x[1])
                                                 : Integer.compare(x[0], y[0]));
        StringBuilder sb = new StringBuilder();
        for (int[] p : keep) sb.append(p[0]).append(' ');
        System.out.println(sb.toString().trim());
    }
}
Python · 第二题 LC347 
import sys
from collections import Counter

def main():
    data = sys.stdin.read().split()
    n, k = int(data[0]), int(data[1])
    a = list(map(int, data[2:2 + n]))
    cnt = Counter(a)
    keep = sorted(cnt.items(), key=lambda x: (-x[1], x[0]))[:k]
    print(' '.join(str(v) for v, _ in keep))

Java · 核心函数：手写最小堆（push 上浮 / pop 下沉） 
static class MinHeap {
    int[] h = new int[16];
    int size = 0;

    void push(int v) {
        if (size == h.length) h = Arrays.copyOf(h, size * 2);
        h[size] = v;
        int i = size++;
        while (i > 0 && h[(i - 1) / 2] > h[i]) {        // 比父节点小就上浮
            int p = (i - 1) / 2;
            int t = h[p]; h[p] = h[i]; h[i] = t;
            i = p;
        }
    }

    int pop() {                                          // 调用前保证 size > 0
        int top = h[0];
        h[0] = h[--size];
        int i = 0;
        while (true) {                                   // 与较小的孩子交换，下沉
            int l = 2 * i + 1, r = l + 1, m = i;
            if (l < size && h[l] < h[m]) m = l;
            if (r < size && h[r] < h[m]) m = r;
            if (m == i) break;
            int t = h[i]; h[i] = h[m]; h[m] = t;
            i = m;
        }
        return top;
    }
}

四、易错点小结

① 「第 k 大」= 降序第 k 个 = 升序倒数第 k 个，方向别反；② 堆比较器写 (a, b) -> a[1] - b[1] 在数值跨度大时整型溢出，一律 Integer.compare；③ 流式输入只能用 size-k 堆，快速选择要全量数据；④ Python 手写堆优先 heapq（它的堆是小顶），大顶堆技巧是存负数；⑤ LC347 输出顺序题目会规定（本页约定频次降序、同频数值升序），实际笔试以题面为准。
