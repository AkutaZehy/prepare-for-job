滑动窗口与前缀和（ACM 模式）

原型：LeetCode 209 / 3 / 560 ｜ 适用岗位：全部 ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：对付「连续子数组/子串」的两把刀——滑动窗口（同向双指针，每个元素进窗出窗各一次，O(n)，前提是窗口指标有单调性）和前缀和（prefix[r] − prefix[l] 即区间和，查询 O(1)）。窗口求长短、前缀和求个数，负数出现时窗口失效退回前缀和。

一、题目与 IO 约定

主打题（LC209 长度最小的子数组）：给定 n 个正整数和目标值 target，找出和 ≥ target 的长度最小的连续子数组，输出其长度；不存在输出 0。

输入格式（2 行）： 
6 7                     # n target
2 3 1 2 4 3             # n 个正整数
输出格式（1 行）： 
2
（子数组 [4,3] 和为 7，长度 2）
变体提前看：① 改成「和恰好等于 target」；② 输出子数组本身而不只是长度；③ 元素含负数（窗口失效，见思路节）；④ 字符串版（LC3）输入是一行字符串而不是数字。

二、思路

  • 滑动窗口（LC209）：右端 r 不断进窗累加，一旦窗口和 ≥ target 就反复缩左端并更新最短长度。每个元素最多进窗一次、出窗一次，均摊 O(n)。暴力双层循环 O(n²)，n 到 10⁵ 必超时。
  • 窗口的前提：元素全为正 → 扩窗和单调增、缩窗和单调减，指针不用回头。一旦有负数，缩窗后窗口和可能不降反升，窗口策略失效——改用前缀和 + 单调队列，或前缀和 + 二分。
  • 无重复字符最长子串（LC3）：同一框架，条件换成「窗口内无重复」：记录每个字符最近出现位置，右端撞到重复字符时把左端直接跳到「上次出现位置 + 1」。
  • 和为 k 的子数组个数（LC560）：元素可正可负，窗口不能用。前缀和 + 哈希计数：扫到位置 j 时，以 j 结尾且和为 k 的子数组个数 = 之前前缀和等于 prefix[j] − k 的次数。注意 cnt[0] = 1 的初始化（空前缀），漏了会少算「从头开始」的子数组。

概念自测点击选项即时判分。

单选1. 用滑动窗口求「和 ≥ target 的最短子数组」，能这么滑的前提是（  ）

A. 数组已按升序排好
B. 数组元素全为正数，窗口和随扩窗单调增、随缩窗单调减
C. 数组元素互不相同
D. 只要 target 是正数就行，与元素正负无关
答案 B。单调性保证 l、r 都只往前走不回头。数组含负数时缩窗后窗口和可能反而变大，指针会漏解，此时应改前缀和 + 单调队列/二分。来源：面试高频改编。

多选2. 关于前缀和，说法正确的有（  ）

A. prefix[i] 表示前 i 个元素之和，则区间和 = prefix[r] − prefix[l]，查询 O(1)
B. 「和为 k 的子数组个数」用前缀和 + 哈希表，边扫边查 prefix − k 出现过的次数
C. 数组元素被修改后，前缀和数组照样能 O(1) 完成区间和查询
D. 前缀和预处理本身是 O(n)
答案 ABD。前缀和是静态结构，单点修改会使其后缀全部过期，动态更新要用树状数组/线段树，C 错。来源：牛客经典题。

三、ACM 完整代码（可直接粘贴牛客）

Java · 主打 LC209 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int target = (int) in.nval;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }

        int ans = Integer.MAX_VALUE;
        for (int l = 0, r = 0, sum = 0; r < n; r++) {
            sum += a[r];                       // 右端进窗
            while (sum >= target) {            // 满足条件就尽量缩左端
                ans = Math.min(ans, r - l + 1);
                sum -= a[l++];
            }
        }
        System.out.println(ans == Integer.MAX_VALUE ? 0 : ans);
    }
}

import sys

def main():
    data = sys.stdin.read().split()
    n, target = int(data[0]), int(data[1])
    a = list(map(int, data[2:2 + n]))
    ans = n + 1
    l = s = 0
    for r in range(n):
        s += a[r]
        while s >= target:
            ans = min(ans, r - l + 1)
            s -= a[l]
            l += 1
    print(0 if ans == n + 1 else ans)

Java · 第二题 LC3（字符串读入：readLine，别用数字 tokenizer） 
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = br.readLine().trim();
        int[] last = new int[128];              // 字符 -> 最近出现位置（1 起始，0 = 没出现过）
        int ans = 0;
        for (int l = 0, r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            if (last[c] > l) l = last[c];       // 撞重复：左端直接跳到上次出现之后
            last[c] = r + 1;
            ans = Math.max(ans, r - l + 1);
        }
        System.out.println(ans);
    }
}

Java · 核心函数 LC560（和为 k 的子数组个数，可正可负） 
static long countSub(int[] a, int k) {
    Map<Long, Integer> cnt = new HashMap<>();
    cnt.put(0L, 1);                             // 空前缀，漏掉会少算从头开始的子数组
    long p = 0, res = 0;
    for (int v : a) {
        p += v;
        res += cnt.getOrDefault(p - k, 0);
        cnt.merge(p, 1, Integer::sum);
    }
    return res;
}
Python · 核心函数 LC560 
def count_sub(a, k):
    cnt = {0: 1}
    p = res = 0
    for v in a:
        p += v
        res += cnt.get(p - k, 0)
        cnt[p] = cnt.get(p, 0) + 1
    return res

四、易错点小结

① 缩窗用 while 不是 if（可能要连缩多次）；② LC209 是「≥ target」，写错成 == 直接全错；③ 字符串/网格题用 readLine，前导零和字母用数字 tokenizer 会读错；④ LC560 的 cnt[0] = 1 与前缀和用 long（10⁵ 个 10⁹ 相加会溢 int）；⑤ 复杂度报法说「均摊 O(n)」，依据是每个元素至多进窗、出窗各一次。
