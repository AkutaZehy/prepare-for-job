两数之和（ACM 模式）

原型：LeetCode 1（简单） ｜ 适用岗位：全部 ｜ 本页同时是「算法编程题」ACM 模板样板 ｜ 更新：2026-09-30
要点速记：哈希一次遍历 O(n)：边查 target - a[i] 是否已出现、边把 a[i]→i 存入 map，一个循环搞定；笔试与力扣最大的差异是 IO——本题输入输出约定见下，Java 用 StreamTokenizer 快读，Python 用 sys.stdin，两者都按可粘贴进牛客判题的完整程序写。

一、题目与 IO 约定

题面：给定 n 个整数和一个目标值 target，找出数组中和为 target 的两个整数，输出它们的下标（约定 0 起始、按下标从小到大），数据保证恰好存在一组解。

输入格式（3 行）： 
4                       # n
2 7 11 15               # n 个整数
9                       # target
输出格式（1 行）： 
0 1
笔试常见的 IO 变体提前看一眼，别死背一种：① 多组输入（循环读到 EOF）；② 下标要 1 起始；③ 无解输出 -1 -1 或 -1；④ 数字间逗号分隔（记得 split(",")）。拿到题先读样例再写代码。

二、思路

  • 暴力：双重循环枚举所有数对，O(n²)——n≤10⁴ 能过，10⁵ 以上超时，笔试默认按 10⁵~10⁶ 估算。
  • 哈希一次遍历：遍历时先查 target - a[i] 是否已在 map（在即得解），再把 a[i]→i 存入 map。O(n) 时间 O(n) 空间。先查后存天然处理了"自己配自己"的问题（如 target=8、元素 4 不会匹配到自己）。
  • 变体：三数之和 → 排序 + 固定一个数后双指针；两数之和 II（有序数组）→ 首尾双指针 O(1) 空间。

三、ACM 完整代码（可直接粘贴牛客）

Java 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }
        in.nextToken(); int target = (int) in.nval;

        Map<Integer, Integer> seen = new HashMap<>();
        for (int i = 0; i < n; i++) {
            Integer j = seen.get(target - a[i]);
            if (j != null) { System.out.println(j + " " + i); return; }
            seen.put(a[i], i);
        }
        System.out.println("-1 -1");
    }
}
Python 
import sys

def main():
    data = sys.stdin.read().split()      # 全读进来按空白切，最省心
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    target = int(data[1 + n])

    seen = {}
    for i, v in enumerate(a):
        if target - v in seen:
            print(seen[target - v], i)
            return
        seen[v] = i
    print(-1, -1)

main()
多组输入改法（很多笔试是"循环到 EOF"）：Java 把主逻辑套进 while (in.nextToken() != StreamTokenizer.TT_EOF)；Python 用 for line in sys.stdin: 或分块从 data 游标读。Java 大数据量（10⁵+）务必用 StreamTokenizer/BufferedReader，Scanner 会被卡 TLE。

四、易错点小结

① 下标基（0 还是 1）看题面约定，输出前确认；② 先查后存，避免元素与自己配对；③ Java 输出 println 每组一行，行末别多空格（有的判题机严格）；④ Python 读入用 sys.stdin.read().split() 一把梭，比逐行 readline 快且不怕换行分布怪异；⑤ 估算复杂度习惯：10⁸ 次运算是 1s 上限，n log n 稳过，n² 看数据范围。
