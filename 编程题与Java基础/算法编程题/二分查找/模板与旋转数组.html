二分查找模板与旋转数组（ACM 模式）

适用岗位：全部（小中厂 Java/Python 笔试高频） ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：二分死记三件套——左闭右闭 while l<=r、命中排除后 r=mid-1、mid=l+(r-l)/2 防溢出；先想清楚要"找到就返回"还是"找左边界"（第一个 >= target）；旋转数组：mid 切两半必有一半有序，先判有序半再看 target 在不在其中。

一、题目与 IO 约定

题 1（主打）有序数组中查找 target（多组输入）：每组数据第一行 n 与 target，第二行 n 个互不相同的升序整数；输出 target 所在下标（0 起始），不存在输出 -1。来源：牛客经典题。

输入格式（两组，读到 EOF）： 
5 7                     # n target
1 3 5 7 9               # n 个升序整数
3 2
1 4 6
输出格式（每组一行）： 
3
-1

题 2 搜索插入位置（LC35）：升序无重复数组，target 存在输出其下标，不存在输出按序插入的位置（保持有序）。来源：LeetCode 经典题（ACM 改编）。

输入格式（2 行）： 
4 2                     # n target
1 3 5 6
输出格式： 
1

题 3 搜索旋转排序数组（LC33，核心函数）：升序数组在未知下标处旋转（如 0 1 2 4 5 6 7 → 4 5 6 7 0 1 2），找 target 返回下标否则 -1，要求 O(log n)。来源：LeetCode 经典题（ACM 改编）。

题 4 x 的平方根（LC69，核心函数）：非负整数 x，返回 √x 的整数部分（截断小数）。来源：LeetCode 经典题（ACM 改编）。

二分题动笔前确认三件事：① 区间下标从 0 还是 1 起；② 元素"互不相同"还是"可重复"（可重复要找左/右边界）；③ 无解时输出什么（-1？n？）。本页统一 0 起始、左闭右闭。

二、思路

1. 标准二分（统一口径：左闭右闭）：循环不变量——target 若存在必在 [l, r] 内。while (l <= r) 配套：a[mid] > target 时 r = mid - 1（mid 已确认不是答案，闭区间连它一起排除）、a[mid] < target 时 l = mid + 1。时间 O(log n)。口径一旦选定全篇统一：左闭右开则是 while (l < r)、r = mid；开闭混用是死循环与漏解之源。

2. 搜索插入位置（LC35）：本质是找左边界——第一个满足 a[i] >= target 的下标（lower_bound）。写法：a[mid] >= target（可行）时 r = mid - 1 继续往左压，不可行 l = mid + 1；循环结束 l 即答案，天然可能是 n（插到末尾）。"找到就返回"与"找左边界"要分清：有重复元素时前者可能命中任意一个，后者才是确定位置。时间 O(log n)。

3. 搜索旋转排序数组（LC33）：mid 把 [l, r] 切成两半，必有一半完全有序：a[l] <= a[mid] ⇒ 左半有序（等号处理 l==mid 的单元素情形），否则右半有序。先判哪半有序，再看 target 是否落在有序半的值域内：在则收缩进有序半，否则去另一半。每轮规模减半，时间 O(log n)。

4. x 的平方根（LC69）：在 [1, x/2]（x ≥ 2）上二分"最大的 mid 使 mid² <= x"。防溢出两处：mid = l + (r - l) / 2；mid * mid 先转 long 再比——x 接近 2³¹−1 时 mid 可达 46341，而 46341² = 2147488281 已超 int 上限 2147483647。循环退出时 r < l，r 就是答案（最后一个平方 ≤ x 的值）。时间 O(log x)。

概念自测点击选项即时判分。

单选1. 左闭右闭区间 [l, r] 上二分，当 a[mid] > target 时应如何收缩（  ）

A. r = mid
B. r = mid - 1
C. r = mid + 1
D. l = mid + 1
答案 B。a[mid] 已确认不是 target，闭区间把 mid 一并排除；若写 r = mid 又配 while l<=r，区间不缩会死循环。来源：牛客经典题。

单选2. LC33 中判断"左半 [l..mid] 有序"用 a[l] <= a[mid]，这个等号为什么不能丢（  ）

A. l==mid（区间只剩一两个元素）时 a[l]==a[mid]，单元素也算有序半，漏等号会走错分支甚至死循环
B. 等号是为了处理 target 恰好等于 a[mid] 的情况
C. 没有等号会数组越界
D. 等号可有可无，只是习惯写法
答案 A。mid=(l+r)/2 向下取整，l==mid 会出现；此时必须按"左半有序"处理。来源：LeetCode 经典题（ACM 改编）。

三、ACM 完整代码（可直接粘贴牛客）

题 1 标准二分（完整程序，含多组输入写法）：Java StreamTokenizer 读到 EOF（Scanner 在 10⁵+ 数据量会被卡 TLE）；Python 游标分块读。

Java 
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        // 多组输入：循环读到 EOF
        while (in.nextToken() != StreamTokenizer.TT_EOF) {
            int n = (int) in.nval;
            in.nextToken(); int target = (int) in.nval;
            int[] a = new int[n];
            for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }

            int l = 0, r = n - 1, ans = -1;   // 左闭右闭
            while (l <= r) {
                int mid = l + (r - l) / 2;    // 防 (l+r) 溢出
                if (a[mid] == target) { ans = mid; break; }
                else if (a[mid] < target) l = mid + 1;
                else r = mid - 1;
            }
            System.out.println(ans);
        }
    }
}
Python 
import sys

def solve(n, target, a):
    l, r = 0, n - 1                     # 左闭右闭
    while l <= r:
        mid = l + (r - l) // 2
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1

def main():
    data = sys.stdin.read().split()
    i, out = 0, []
    while i < len(data):                # 多组：游标一块一块读
        n, target = int(data[i]), int(data[i + 1])
        a = list(map(int, data[i + 2:i + 2 + n]))
        out.append(str(solve(n, target, a)))
        i += 2 + n
    print('\n'.join(out))

main()

题 2 搜索插入位置（完整程序）：找左边界模板，命中也继续左压。

Java 
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int target = (int) in.nval;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }

        int l = 0, r = n - 1;                 // 左闭右闭，统一口径
        while (l <= r) {                      // 找左边界：第一个 >= target 的下标
            int mid = l + (r - l) / 2;
            if (a[mid] >= target) r = mid - 1;    // mid 可行，往左压找更左的
            else l = mid + 1;
        }
        System.out.println(l);                // l 即答案，可能是 n（插到末尾）
    }
}
Python 
import sys

def lower_bound(a, target):
    l, r = 0, len(a) - 1                  # 左闭右闭，统一口径
    while l <= r:
        mid = l + (r - l) // 2
        if a[mid] >= target:
            r = mid - 1                   # mid 可行，往左压
        else:
            l = mid + 1
    return l                              # 第一个 >= target 的下标，可能是 len(a)

def main():
    data = sys.stdin.read().split()
    n, target = int(data[0]), int(data[1])
    a = list(map(int, data[2:2 + n]))
    print(lower_bound(a, target))

main()

题 3 搜索旋转排序数组 / 题 4 x 的平方根（核心函数）

Java 
// LC33：mid 切两半必有一半有序，先判有序半再看 target 在不在其中
int search(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == target) return mid;
        if (a[l] <= a[mid]) {                  // 左半 [l..mid] 有序（等号管 l==mid）
            if (a[l] <= target && target < a[mid]) r = mid - 1;  // target 在有序左半
            else l = mid + 1;
        } else {                               // 右半 [mid..r] 有序
            if (a[mid] < target && target <= a[r]) l = mid + 1;
            else r = mid - 1;
        }
    }
    return -1;
}

// LC69：返回 sqrt(x) 的整数部分；mid*mid 必须用 long 防溢出
int mySqrt(int x) {
    if (x < 2) return x;
    int l = 1, r = x / 2;                // x>=2 时答案不超过 x/2
    while (l <= r) {
        int mid = l + (r - l) / 2;       // 防 l+r 溢出
        if ((long) mid * mid == x) return mid;
        else if ((long) mid * mid < x) l = mid + 1;
        else r = mid - 1;
    }
    return r;                            // 退出时 r < l，r 是最后一个平方 <= x 的
}
Python 
def search(a, target):
    l, r = 0, len(a) - 1
    while l <= r:
        mid = l + (r - l) // 2
        if a[mid] == target:
            return mid
        if a[l] <= a[mid]:                    # 左半有序
            if a[l] <= target < a[mid]:       # target 落在有序左半
                r = mid - 1
            else:
                l = mid + 1
        else:                                 # 右半有序
            if a[mid] < target <= a[r]:
                l = mid + 1
            else:
                r = mid - 1
    return -1

def my_sqrt(x):
    if x < 2:
        return x
    l, r = 1, x // 2
    while l <= r:
        mid = l + (r - l) // 2
        sq = mid * mid                # Python 无溢出，Java 要转 long
        if sq == x:
            return mid
        elif sq < x:
            l = mid + 1
        else:
            r = mid - 1
    return r
多组输入已在题 1 演示：Java 套 while (in.nextToken() != StreamTokenizer.TT_EOF)，Python 在 data 上移动游标；单组题把外层循环去掉即可。

四、易错点小结

① 口径统一：左闭右闭 ↔ while l<=r ↔ r=mid-1，三件套必须配套；写成 l=mid 却不换口径必死循环；② mid 一律 l+(r-l)/2，(l+r)/2 在 l、r 都接近 2³¹ 时溢出；③ 分清"找到就返回"（命中即出）与"找左边界"（命中也继续左压，返回 l 可为 n）；④ 旋转数组判有序半的等号 a[l]<=a[mid] 不能丢；⑤ mid*mid 用 long 接（46341² 已超 int）；⑥ 二分的前提是单调性，数组无序先排序或换思路；⑦ 可重复元素的数组要"第一个/最后一个 target"得用左右边界模板，"找到就返回"会拿到任意一个。
