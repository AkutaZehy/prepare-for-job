全排列、子集与组合（ACM 模式）

原型：LeetCode 46 / 78 / 77 / 39 ｜ 适用岗位：全部 ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：回溯 = 带撤销的 DFS 枚举，三要素是路径（已做的选择）、选择列表（当前还能选什么）、结束条件。模板永远一句话：做选择 → 递归 → 撤销选择。排列用 used[] 标记「谁在用」，组合与子集用 start 下标「只往后看」；先把候选排好序，输出天然字典序。

一、题目与 IO 约定

主打题（LC46 全排列）：n 个互不相同的整数，按字典序输出所有排列，每行一个、数字间空格分隔。

输入格式（2 行）： 
3                       # n
1 2 3                   # n 个互不相同的整数
输出格式（6 行，此处列前两行）： 
1 2 3
1 3 2
...

第二题（LC78 子集）：n 个互不相同的整数，输出全部 2ⁿ 个子集。约定：每个子集一行、数字间空格分隔，空集输出一个空行。

变体提前看：① 有重复元素的全排列/子集（LC47/90）：排序后 if (i > start && a[i] == a[i-1]) continue; 剪重复分支；② 组合要指定长度 k（LC77）；③ 元素可重复选取的组合总和（LC39）：递归传 i 而不是 i+1。

二、思路

  • 全排列：每层从 0 号扫描，用 used[i] 跳过已在路径里的元素；递归返回后必须撤销（path 弹出 + used 复位），否则下个分支看不到完整选择列表。复杂度 O(n · n!)——叶子 n! 个，每个还要 O(n) 复制输出。
  • 子集：与排列的区别是「每个节点都是答案」——进入递归先收录当前 path，再用 start 只往右选（保证组合不重不漏、内部有序）。复杂度 O(n · 2ⁿ)。
  • 组合（LC77）：子集框架 + 长度 k 的结束条件。剪枝：i <= n − (k − path.size()) + 1——剩下的元素不够凑满 k 个就别进了。
  • 输出字典序：把候选数组先升序排序，回溯按序号从小到大选，输出自然按字典序。
  • 判断能不能过：n ≤ 10 用排列枚举随便跑；n 到 20+ 只可能是 2ⁿ 状压/剪枝题，看到 n 的范围再定打法。

A. 把递归改成显式栈的迭代

多选2. 关于回溯模板，正确的有（  ）

A. 核心循环：做选择 → 递归 → 撤销选择，撤销必须与选择严格对称
B. 全排列用 used 数组，组合/子集用 start 参数防回头重复

三、ACM 完整代码（可直接粘贴牛客）

Java · 主打 LC46 全排列（字典序输出） 
import java.io.*;
import java.util.*;

public class Main {
    static int n;
    static int[] a;
    static boolean[] used;
    static List<Integer> path = new ArrayList<>();
    static StringBuilder out = new StringBuilder();

    static void dfs() {
        if (path.size() == n) {
            for (int v : path) out.append(v).append(' ');
            out.setCharAt(out.length() - 1, '\n');
            return;
        }
        for (int i = 0; i < n; i++) {
            if (used[i]) continue;
            used[i] = true; path.add(a[i]);        // 做选择
            dfs();
            path.remove(path.size() - 1); used[i] = false;   // 撤销选择
        }
    }

    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); n = (int) in.nval;
        a = new int[n]; used = new boolean[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }
        Arrays.sort(a);                            // 升序回溯 → 输出天然字典序
        dfs();
        System.out.print(out);
    }
}
Python · 主打 LC46 
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = sorted(map(int, data[1:1 + n]))
    used = [False] * n
    path, res = [], []

    def dfs():
        if len(path) == n:
            res.append(' '.join(map(str, path)))
            return
        for i in range(n):
            if used[i]:
                continue
            used[i] = True
            path.append(a[i])
            dfs()
            path.pop()
            used[i] = False

    dfs()
    sys.stdout.write('\n'.join(res) + '\n')

Java · 第二题 LC78 子集（空集输出空行） 
import java.io.*;
import java.util.*;

public class Main {
    static int n;
    static int[] a;
    static List<Integer> path = new ArrayList<>();
    static StringBuilder out = new StringBuilder();

    static void dfs(int start) {
        if (path.isEmpty()) {
            out.append('\n');                      // 空集
        } else {
            for (int v : path) out.append(v).append(' ');
            out.setCharAt(out.length() - 1, '\n');
        }
        for (int i = start; i < n; i++) {
            path.add(a[i]);
            dfs(i + 1);
            path.remove(path.size() - 1);
        }
    }

    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); n = (int) in.nval;
        a = new int[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }
        Arrays.sort(a);
        dfs(0);
        System.out.print(out);
    }
}

Java · 核心函数：LC77 组合（带剪枝）与 LC39 组合总和一句 
// 输出 1..n 中所有 k 个数的组合，剪枝：剩余元素不够凑满 k 个的分支直接不进
static void combine(int start, int n, int k) {
    if (path.size() == k) { record(path); return; }
    for (int i = start; i <= n - (k - path.size()) + 1; i++) {
        path.add(i);
        combine(i + 1, n, k);
        path.remove(path.size() - 1);
    }
}

四、易错点小结

① 忘撤销是第一大坑：path 弹出与 used 复位必须和选择严格配对；② 排列传 i 从 0 起 + used，组合/子集传 i+1 用 start，别混；③ 重复元素去重公式 i > start && a[i] == a[i-1] → continue 前提是先排序；④ 输出量 10⁵ 行以上必须 StringBuilder/统一 write，逐条 println 会拖慢；⑤ 报复杂度带输出代价：排列 O(n·n!)、子集 O(n·2ⁿ)。
