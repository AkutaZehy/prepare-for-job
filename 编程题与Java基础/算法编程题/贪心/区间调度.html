贪心与区间调度（ACM 模式）

原型：LeetCode 435 / 56 / 121 ｜ 适用岗位：全部 ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：区间题三板斧——按右端点排序（能留就留 → 保留最多/移除最少，LC435、射气球）；按左端点排序（合并区间，LC56）；排序后线性扫（维护一个边界变量）。Java 比较器写 Integer.compare 防减法溢出。贪心题面试要能说出「为什么贪」：交换论证一句即可。

一、题目与 IO 约定

主打题（LC435 无重叠区间）：n 个区间，求最少移除多少个区间，使剩余区间互不重叠（端点相接不算重叠，如 [1,2] 与 [2,3]）。

输入格式（n+1 行）： 
4                       # n
1 2                     # start end，共 n 行
2 3
3 4
1 3
输出格式（1 行）： 
1
变体提前看：① 「最多能参加多少场会议/活动」= n − 本题答案，同一套代码换个输出；② 射气球（LC452）：端点相接算引爆，判断条件从 >= 变 >；③ 区间值域到 10⁹ → 比较器必须防溢出。

二、思路

  • 无重叠区间（LC435）：按右端点升序排序，能保留就保留（start ≥ 上一个保留区间的 end），保留数最大化 → 移除数 = n − 保留数。为什么按右端点：结束得越早，给后面留的空间越大——交换论证：最优解里第一个被保留的区间若不是右端点最小的，换成它不会更差。
  • 合并区间（LC56）：按左端点升序排序，当前区间起点 ≤ 结果里最后一个区间的终点就合并（终点取两者较大值），否则另起一段。O(n log n)。
  • 买卖股票最佳时机（LC121）：一次遍历，维护历史最低买入价，每天试「今天卖」更新最大利润。O(n)。变体：允许多次交易 → 等价于收集所有正的相邻差值。
  • 贪心的一般姿势：先想清楚「每一步局部最优选什么」，再用交换论证/反例说服自己；举不出反例就先写，笔试用样例和对拍兜底。

概念自测点击选项即时判分。

单选1. 「移除最少区间使剩余互不重叠」要按右端点而不是左端点排序，原因是（  ）

A. 右端点排序后循环写起来更短
B. 左端点排序会改变区间本身
C. 结束越早给后面腾的空间越大，能保留的区间数才最多（交换论证可证最优）
D. 左端点排序无法处理重叠
答案 C。按左端点排序做本题可能保留一个「横跨很长」的区间挤掉多个短区间。经典反例：[1,100]、[2,3]、[3,4]。来源：面试高频改编。

多选2. 关于区间类贪心，正确的有（  ）

A. 「保留最多不重叠区间」与「移除最少区间」是同一排序框架，只差输出什么
B. 合并区间按左端点排序，合并时终点取 max(旧终点, 当前终点)
C. 贪心策略对所有优化问题都能得到全局最优
D. LC121 只需一次遍历：维护历史最低价，每天用「今日价 − 历史最低」更新答案
答案 ABD。贪心必须有适用条件，不满足时（如带冷却期的股票）要退回 DP，C 错。来源：牛客经典题。

三、ACM 完整代码（可直接粘贴牛客）

Java · 主打 LC435（按右端点贪心） 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        int[][] iv = new int[n][2];
        for (int i = 0; i < n; i++) {
            in.nextToken(); iv[i][0] = (int) in.nval;
            in.nextToken(); iv[i][1] = (int) in.nval;
        }
        Arrays.sort(iv, (a, b) -> Integer.compare(a[1], b[1]));   // 右端点升序；减法会溢出
        int keep = 0;
        int end = Integer.MIN_VALUE;
        for (int[] p : iv) {
            if (p[0] >= end) {                 // 端点相接不算重叠
                keep++;
                end = p[1];
            }
        }
        System.out.println(n - keep);
    }
}
Python · 主打 LC435 
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    iv = []
    for i in range(n):
        s, e = int(data[1 + 2 * i]), int(data[2 + 2 * i])
        iv.append((s, e))
    iv.sort(key=lambda x: x[1])
    keep = 0
    end = float('-inf')
    for s, e in iv:
        if s >= end:
            keep += 1
            end = e
    print(n - keep)

Java · 第二题 LC56 合并区间 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        int[][] iv = new int[n][2];
        for (int i = 0; i < n; i++) {
            in.nextToken(); iv[i][0] = (int) in.nval;
            in.nextToken(); iv[i][1] = (int) in.nval;
        }
        Arrays.sort(iv, (a, b) -> Integer.compare(a[0], b[0]));   // 左端点升序
        List<int[]> res = new ArrayList<>();
        for (int[] p : iv) {
            if (!res.isEmpty() && p[0] <= res.get(res.size() - 1)[1]) {
                int[] last = res.get(res.size() - 1);
                last[1] = Math.max(last[1], p[1]);
            } else {
                res.add(new int[]{p[0], p[1]});
            }
        }
        StringBuilder sb = new StringBuilder();
        for (int[] p : res) sb.append(p[0]).append(' ').append(p[1]).append('\n');
        System.out.print(sb);
    }
}
Python · 第二题 LC56 
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    iv = sorted((int(data[1 + 2 * i]), int(data[2 + 2 * i])) for i in range(n))
    res = []
    for s, e in iv:
        if res and s <= res[-1][1]:
            res[-1][1] = max(res[-1][1], e)
        else:
            res.append([s, e])
    out = '\n'.join(f'{s} {e}' for s, e in res)
    sys.stdout.write(out + '\n')

Java · 核心函数：LC121 买卖股票（一次遍历） 
static int maxProfit(int[] a) {
    int lo = a[0], best = 0;                 // lo：历史最低买入价
    for (int v : a) {
        best = Math.max(best, v - lo);
        lo = Math.min(lo, v);
    }
    return best;
}

四、易错点小结

① 重叠的定义看题面：LC435 端点相接不算重叠（>= 保留），射气球算重叠（>），先读清再写判断；② Java 比较器 a[1] - b[1] 在 10⁹ 级坐标上溢出，永远 Integer.compare；③ 排序的「稳定与否」不影响这三题，但 LC56 合并后输出顺序 = 左端点升序，题目另有要求时再排一次；④ 贪心说不出理由时，笔试退路是「排序 + 线性扫」再小数据对拍。
