反转、合并与判环（ACM 模式）

适用岗位：全部（小中厂 Java/Python 笔试高频） ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：反转=三指针（先存后继再转向）；合并=哑节点 dummy+双指针逐个摘小；判环=快慢指针（fast 一步两步），找入环点=相遇后一指针回 head 同步走（a = kL − b）；删倒数第 N=fast 先走 n 步再同步，一次遍历。

一、题目与 IO 约定

题 1（主打）反转链表：输入 n 和 n 个整数，按顺序构建单链表，输出反转后链表的节点值（空格分隔）。来源：LeetCode 经典题（ACM 改编）。

输入格式（2 行）： 
5                       # n
1 2 3 4 5               # n 个节点值，从头到尾
输出格式（1 行）： 
5 4 3 2 1

题 2 合并两个有序链表：给两条升序链表（长度 n、m 及各自节点值），合并为一条升序链表输出（稳定归并，相等时先取链表 1 的节点）。来源：LeetCode 经典题（ACM 改编）。

输入格式（3 行）： 
3 3                     # n m
1 2 4                   # 链表 1（升序）
1 3 4                   # 链表 2（升序）
输出格式（1 行）： 
1 1 2 3 4 4

题 3 环形链表判环与找入环点（LC141/142）：判断链表是否有环；进阶返回入环点。ACM 改编常见给法：n 个节点值 + 整数 pos（尾节点指向第 pos 个节点，0 起始；pos=-1 表示无环），输出 true/false。来源：LeetCode 经典题（ACM 改编）。

题 4 删除链表的倒数第 N 个结点（LC19）：输入 n、n 个节点值与 k，删除倒数第 k 个节点后输出剩余序列。如 5 / 1 2 3 4 5 / 2 → 输出 1 2 3 5。来源：LeetCode 经典题（ACM 改编）。

笔试建链的输入约定常见三种：① 先给 n 再给 n 个值（本页约定）；② 一行值以 -1 结尾；③ 不给长度直接读到 EOF。动笔前先看样例确认，别背死一种。

二、思路

1. 反转链表（LC206）

  • 迭代三指针 prev/cur/next：每轮 next 先记下 cur 的后继 → cur.next 改指 prev → prev、cur 同步后移。时间 O(n)、空间 O(1)，链表题首选（深链递归会爆栈）。
  • 递归两版：经典版——先递归反转 head 之后的部分，再让后继回指自己（head.next.next = head; head.next = null）；尾递归式——把 prev 作为参数往下传 f(cur, prev) = f(cur.next, cur)，语义与迭代一致。两版都是 O(n) 栈空间，Java 无尾递归优化。
  • Python 三连赋值 cur.next, prev, cur = prev, cur, cur.next 一行顶三行——右侧先整体求值，不怕顺序问题。
// 递归版一（经典）
Node reverse(Node head) {
    if (head == null || head.next == null) return head;
    Node newHead = reverse(head.next);
    head.next.next = head;    // 后继回指自己
    head.next = null;         // 自己成为新尾部
    return newHead;
}

2. 合并两个有序链表（LC21）：哑节点 dummy 收结果，双指针 p/q 每轮把较小者摘接到结果尾部；一方走完，把另一方整段接上。时间 O(n+m)、空间 O(1)。变体：k 条有序链合并 → 小顶堆 O(N log k)，或两两分治。

3. 判环与找入环点（LC141/142）：快慢指针 slow 一步、fast 两步——有环则 fast 每轮把差距缩小 1，必相遇；无环 fast 撞 null。哈希表法（记录访问过的节点）O(n) 空间做对照。找入环点（Floyd）：相遇后一个指针回 head，两指针同步一次一步，再相遇处即入口。数学一句话：设头到入口 a 步、入口到相遇点 b 步、环长 L，相遇时 fast 走了 a+b+kL = 2(a+b)，得 a = kL − b——头到入口的距离恰好等于相遇点绕回入口的距离，同步走必在入口碰头。时间 O(n)、空间 O(1)。

4. 删除倒数第 N 个（LC19）：哑节点 + 双指针一次遍历：fast 从 dummy 先走 n 步，然后 fast/slow 同步前进到 fast.next == null，此时 slow 停在被删节点的前驱，slow.next = slow.next.next。时间 O(n)、空间 O(1)。

概念自测点击选项即时判分。

单选1. 迭代反转链表的循环体内，正确的操作顺序是（  ）

A. 先执行 cur.next = prev，再保存原来的 cur.next
B. 先执行 cur = cur.next，再修改 cur.next 指向 prev
C. 先用临时变量保存 cur.next，再令 cur.next = prev，最后 prev、cur 同步后移
D. 三指针各走各的，不需要临时变量
答案 C。先改 cur.next 而不保存后继，后半段链就丢了，cur 无路可走；"先存后继→改指向→同步双移"是唯一不丢链的顺序。来源：LeetCode 经典题（ACM 改编）。

单选2. 判环快慢指针相遇后，找入环点的正确做法是（  ）

A. 相遇点本身就是入环点
B. 一个指针回到头节点，两指针同速（一次一步）前进，再次相遇处即入环点
C. 快指针保持每次两步，直到再次回到相遇点
D. 必须借助哈希表记录首次访问的节点才能找到
答案 B。数学依据 a = kL − b：头到入口的距离等于相遇点绕回入口的距离，同速前进必在入口碰头。来源：LeetCode 经典题（ACM 改编）。

多选3. 关于哑节点 dummy 的作用，正确的有（  ）

A. 合并两个有序链表时，省去"先比较两个头节点确定结果头"的特判
B. 删除倒数第 N 个（N 可等于链长即删头）时，省去删头特判
C. 哑节点会出现在最终输出序列里
D. 引入哑节点会把空间复杂度从 O(1) 拉到 O(n)
答案 AB。输出从 dummy.next 开始遍历，哑节点本身不进结果，C 错；哑节点只多一个节点，空间仍 O(1)，D 错。来源：LeetCode 经典题（ACM 改编）。

三、ACM 完整代码（可直接粘贴牛客）

题 1 反转链表（完整程序）：Java 用 StreamTokenizer 快读 + StringBuilder 输出（Scanner 在 10⁵+ 数据量会被卡 TLE）；Python 页内真建链表（更贴面试写法）。

Java 
import java.io.*;

public class Main {
    static class Node {
        int val; Node next;
        Node(int v) { val = v; }
    }

    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        Node dummy = new Node(0), tail = dummy;
        for (int i = 0; i < n; i++) {          // 按输入顺序建链
            in.nextToken(); tail.next = new Node((int) in.nval); tail = tail.next;
        }

        // 迭代三指针：next 先存后继 → cur.next 指向 prev → 双指针同步后移
        Node prev = null, cur = dummy.next;
        while (cur != null) {
            Node next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }

        StringBuilder sb = new StringBuilder();  // 拼好一次性输出
        for (Node p = prev; p != null; p = p.next)
            sb.append(p.val).append(p.next == null ? '\n' : ' ');
        System.out.print(sb);
    }
}
Python 
import sys

class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    dummy = Node(0)                  # 哑节点，建链不用特判空表
    tail = dummy
    for i in range(n):
        tail.next = Node(int(data[1 + i]))
        tail = tail.next

    prev, cur = None, dummy.next
    while cur:                       # 迭代三指针反转
        cur.next, prev, cur = prev, cur, cur.next   # 右侧先整体求值

    out = []
    while prev:
        out.append(str(prev.val))
        prev = prev.next
    print(' '.join(out))

main()

题 2 合并两个有序链表（完整程序）

Java 
import java.io.*;

public class Main {
    static class Node {
        int val; Node next;
        Node(int v) { val = v; }
    }

    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(
                new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int m = (int) in.nval;
        Node d1 = new Node(0), t1 = d1;
        for (int i = 0; i < n; i++) { in.nextToken(); t1.next = new Node((int) in.nval); t1 = t1.next; }
        Node d2 = new Node(0), t2 = d2;
        for (int i = 0; i < m; i++) { in.nextToken(); t2.next = new Node((int) in.nval); t2 = t2.next; }

        Node dummy = new Node(0), tail = dummy;   // 哑节点：结果头不用特判
        Node p = d1.next, q = d2.next;
        while (p != null && q != null) {
            if (p.val <= q.val) { tail.next = p; p = p.next; }
            else { tail.next = q; q = q.next; }
            tail = tail.next;
        }
        tail.next = (p != null) ? p : q;          // 剩余一整段直接接上

        StringBuilder sb = new StringBuilder();
        for (Node c = dummy.next; c != null; c = c.next)
            sb.append(c.val).append(c.next == null ? '\n' : ' ');
        System.out.print(sb);
    }
}
Python 
import sys

class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

def build(vals):
    dummy = tail = Node(0)
    for v in vals:
        tail.next = Node(int(v))
        tail = tail.next
    return dummy.next

def merge(p, q):
    dummy = tail = Node(0)              # 哑节点
    while p and q:
        if p.val <= q.val:
            tail.next, p = p, p.next    # 摘较小的头
        else:
            tail.next, q = q, q.next
        tail = tail.next
    tail.next = p if p else q           # 剩余整段直接接上
    return dummy.next

def main():
    data = sys.stdin.read().split()
    n, m = int(data[0]), int(data[1])
    p = build(data[2:2 + n])
    q = build(data[2 + n:2 + n + m])
    out, c = [], merge(p, q)
    while c:
        out.append(str(c.val))
        c = c.next
    print(' '.join(out))

main()

题 3 判环与找入环点 / 题 4 删除倒数第 N 个（核心函数，ACM 建链后调用即可）：判环题读入 pos 后让尾节点 next 指向第 pos 个节点即可造环。

Java 
// LC141 判环：快慢指针，O(n) 时间 O(1) 空间
boolean hasCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {   // 先判后走，防空指针
        slow = slow.next;           // 慢的一次一步
        fast = fast.next.next;      // 快的一次两步
        if (slow == fast) return true;   // 是"同一个节点"才叫相遇
    }
    return false;                   // fast 撞 null = 无环
}

// LC142 找入环点：相遇后一指针回 head，同步一步走，再相遇即入口
Node detectCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {         // 相遇 → 有环
            Node p = head;
            while (p != slow) { p = p.next; slow = slow.next; }
            return p;
        }
    }
    return null;
}

// LC19：哑节点 + 双指针，一次遍历删倒数第 n 个
Node removeNthFromEnd(Node head, int n) {
    Node dummy = new Node(0); dummy.next = head;  // 哑节点：删头免特判
    Node fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) fast = fast.next; // fast 先走 n 步
    while (fast.next != null) { fast = fast.next; slow = slow.next; }
    slow.next = slow.next.next;     // slow 停在被删节点的前一个
    return dummy.next;
}
Python 
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:            # is：同一个对象
            return True
    return False

def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:            # 相遇 → 有环
            p = head
            while p is not slow:
                p, slow = p.next, slow.next
            return p                # 再相遇处即入环点
    return None

def remove_nth_from_end(head, n):
    dummy = Node(0); dummy.next = head
    fast = slow = dummy
    for _ in range(n):
        fast = fast.next            # fast 先走 n 步
    while fast.next:
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next      # slow 停在被删节点的前一个
    return dummy.next
多组输入改法：Java 把主逻辑套进 while (in.nextToken() != StreamTokenizer.TT_EOF)；Python 在 data 上移动游标分块读。建链与算法逻辑不变。大数据量 Java 务必 StreamTokenizer/BufferedReader，Scanner 会被卡 TLE。

四、易错点小结

① 反转的断链顺序：先存 next 再转向，顺序颠倒后半段链就丢了；② 凡"可能动头节点"的操作（合并、删头）先挂哑节点，输出从 dummy.next 开始；③ 快慢指针循环条件 fast != null && fast.next != null 先判后走，防空指针；④ 判环相等用 ==（比较是否同一节点）而非值相等，Python 对应 is；⑤ 删倒数第 N 的 N 可能等于链长（即删头），哑节点让这步免特判；⑥ 输出用 StringBuilder/join 拼好再打印，行末别多空格；⑦ 链长 10⁵+ 时反转用迭代，递归可能爆栈。
