岛屿问题与 BFS（ACM 模式）

原型：LeetCode 200 / 695 / 994 ｜ 适用岗位：全部 ｜ 形态：ACM 判题题 + 思路 ｜ 更新：2026-09-30
要点速记：网格就是隐式图，格子是节点、上下左右是边。三板斧：flood fill（扫到 '1' 计数 +1，BFS/DFS 把整座岛标没）；沉岛技巧（直接把 '1' 改 '0'，省 visited 数组）；多源 BFS（所有源点同时入队当第 0 层，层数就是答案）。网格必须按字符串按行读——前导零用数字 tokenizer 一读就废。

一、题目与 IO 约定

主打题（LC200 岛屿数量）：n×m 的 0/1 网格，1 是陆地、0 是水，上下左右相连的陆地算同一座岛，输出岛的数量。

输入格式（n+1 行）： 
4 5                     # n m
11000
11000
00100
00011
输出格式（1 行）： 
3
变体提前看：① 求最大岛屿面积（LC695）或周长；② 每格给的是数字（空格分隔）而不是连续 01 串，读法不同但主体代码一致；③ 「被水包围的封闭岛屿」（边界不算）要先把边界淹一遍。

二、思路

  • 岛屿数量（LC200）：双重循环扫网格，遇到 '1' 计数 +1，然后从它出发 BFS（或 DFS）把整座连通块全标成 '0'（沉岛）。每个格子最多进出队一次，O(nm) 时间。
  • 沉岛 vs visited：直接改原数组省一个 O(nm) 数组；笔试里最省事。面试提醒一句「改了输入数据，工程上要 copy 或加 visited」。
  • 最大面积（LC695）：同一框架，flood fill 时数格子数，取 max。DFS 版代码最短（返回值累加），但大网格全 1 会递归爆栈，稳妥用 BFS。
  • 多源 BFS（LC994 腐烂橘子）：把所有初始腐烂橘子一起入队（时间 0），逐层扩散到新鲜橘子。层数 = 全部腐烂的分钟数；结束还有新鲜橘子 → -1。一句话：多源 BFS 等价于虚拟超级源点。
  • BFS 为什么能求最短路：无权图（每步代价 1）按层扩散，第一次到达某格时用的层数必然最少。

概念自测点击选项即时判分。

单选1. 网格 BFS 求起点到终点的最少步数，能保证最短的原因是（  ）

A. 网格每步代价相同（无权），BFS 按层扩散，首次到达某格的层数就是最少步数
B. 队列是先进先出，天然有序所以结果最短
C. BFS 比DFS 访问的格子更少
D. 只要网格不是环形连通的就行
答案 A。无权图 BFS 即最短路；一旦某步代价不同（如传送门），要改 Dijkstra。来源：面试高频改编。

多选2. 关于网格搜索的实现细节，正确的有（  ）

A. 常用方向数组 dx/dy 配 for 循环，省去四个 if
B. BFS 标记「已访问」要在入队时做，不能等出队才标，否则同一格重复入队
C. 沉岛（把 '1' 改 '0'）会破坏输入数据，所以任何场合都不能用
D. 多源 BFS 把所有源点一起当第 0 层入队，等价于加一个虚拟超级源点
答案 ABD。沉岛在笔试完全可用，工程上 copy 一份或用 visited 即可，C 错。来源：牛客经典题。

三、ACM 完整代码（可直接粘贴牛客）

Java · 主打 LC200（BFS + 沉岛；网格按行读） 
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        char[][] g = new char[n][];
        for (int i = 0; i < n; i++) g[i] = br.readLine().trim().toCharArray();

        int[] dx = {1, -1, 0, 0}, dy = {0, 0, 1, -1};
        int cnt = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (g[i][j] != '1') continue;
                cnt++;
                g[i][j] = '0';                       // 沉岛
                Queue<int[]> que = new ArrayDeque<>();
                que.add(new int[]{i, j});
                while (!que.isEmpty()) {
                    int[] cur = que.poll();
                    for (int d = 0; d < 4; d++) {
                        int x = cur[0] + dx[d], y = cur[1] + dy[d];
                        if (x >= 0 && x < n && y >= 0 && y < m && g[x][y] == '1') {
                            g[x][y] = '0';           // 入队即标记
                            que.add(new int[]{x, y});
                        }
                    }
                }
            }
        }
        System.out.println(cnt);
    }
}
Python · 主打 LC200 
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    n, m = int(data[0]), int(data[1])
    g = [list(data[2 + i]) for i in range(n)]
    cnt = 0
    for i in range(n):
        for j in range(m):
            if g[i][j] != '1':
                continue
            cnt += 1
            g[i][j] = '0'
            dq = deque([(i, j)])
            while dq:
                x, y = dq.popleft()
                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < m and g[nx][ny] == '1':
                        g[nx][ny] = '0'
                        dq.append((nx, ny))
    print(cnt)

Java · 第二题 LC695 最大面积（DFS 递归版，短但注意爆栈） 
import java.io.*;
import java.util.*;

public class Main {
    static char[][] g;
    static int n, m;

    static int dfs(int x, int y) {
        if (x < 0 || x >= n || y < 0 || y >= m || g[x][y] != '1') return 0;
        g[x][y] = '0';
        return 1 + dfs(x + 1, y) + dfs(x - 1, y) + dfs(x, y + 1) + dfs(x, y - 1);
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());
        g = new char[n][];
        for (int i = 0; i < n; i++) g[i] = br.readLine().trim().toCharArray();
        int best = 0;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                best = Math.max(best, dfs(i, j));
        System.out.println(best);
    }
}
Java · 核心函数：LC994 腐烂橘子（多源 BFS） 
// 返回全部腐烂所需分钟数；有新鲜橘子烂不到则 -1
static int oranges(int[][] g) {
    int n = g.length, m = g[0].length, fresh = 0, t = 0;
    Queue<int[]> que = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            if (g[i][j] == 2) que.add(new int[]{i, j, 0});   // 所有源点第 0 层
            else if (g[i][j] == 1) fresh++;
        }
    int[] dx = {1, -1, 0, 0}, dy = {0, 0, 1, -1};
    while (!que.isEmpty()) {
        int[] cur = que.poll();
        t = Math.max(t, cur[2]);
        for (int d = 0; d < 4; d++) {
            int x = cur[0] + dx[d], y = cur[1] + dy[d];
            if (x >= 0 && x < n && y >= 0 && y < m && g[x][y] == 1) {
                g[x][y] = 2; fresh--;
                que.add(new int[]{x, y, cur[2] + 1});
            }
        }
    }
    return fresh == 0 ? t : -1;
}

四、易错点小结

① 网格按字符串按行读：00100 用 StreamTokenizer 读成数字会丢前导零，必须 readLine/按词取；② Windows 判题机 readLine 可能带回车，trim() 防御；③ BFS 标记在入队时做，出队才标会重复入队拖成平方级；④ 1000×1000 全 1 网格 DFS 递归会 StackOverflow（Java 默认栈约 512KB~1MB），大网格用 BFS；⑤ 「步数/分钟数」存进队列元素里最省心，不必按层拆循环。
