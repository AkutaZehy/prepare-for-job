# prepare-for-job · 计算机基础与求职复习站

一套纯静态、可交互的复习站点：覆盖计算机基础（408）、Java、Python 与深度学习、前端四大方向共 **112 个知识点页**，每页自带考点讲解与即时判分的练习题，并配有学习进度记录。无需安装依赖，本地打开即用。

## 为什么有这个仓库

复习笔试/面试时有两个常见痛点：知识点散落在各个平台，看了就忘；算法题在力扣上练过，到了 ACM 模式的笔试平台上却不习惯自己处理输入输出。本仓库就是为这两个痛点准备的——

- 把高频考点整理成**一页一主题**的离线可读卡片，看完要点直接做题自测；
- 算法题统一按 **ACM 模式**书写：stdin/stdout 的完整可运行程序，可直接粘贴到牛客等判题平台；
- 配一个本地进度系统，学完一个勾一个，进度随浏览器保存、可导出备份。

## 如何使用

1. **打开进度清单**：双击 `index.html`。每个知识点一行，点击状态按钮循环切换 ○ 未学 → ◐ 学习中 → ● 已完成，自动记录最近学习日期；顶部支持按标题或分类搜索（试试 `Java`、`TCP`、`注意力`），右上角可导出/导入进度 JSON（进度保存在浏览器 localStorage，换浏览器或清缓存前先导出）。
2. **学习知识点页**：从清单点进任一页，固定四段结构——知识点梳理 → 考点说明 → 示例题目（单选/多选点击选项即时判分并标出正误与漏选，计算/口述题先自己想再展开参考答案）→ 易错点小结。算法题是 ACM 完整程序，**本站没有牛客那样的在线判分系统**：把代码复制到本地运行或粘贴到牛客等判题平台，对照页内给出的样例输入输出与解析自行核对。
3. **联网与断网**：MathJax 公式与 Mermaid 图走 CDN；断网时公式显示原文、图自动回退为 ASCII 版，不影响阅读。
4. **本地服务（可选）**：直接双击即是 `file://` 协议，清单通过 script 标签加载数据，无需起服务；如需配合本地测试，`python -m http.server` 即可。

## 构建方式

- **纯静态零依赖**：每个知识点页是单文件自包含 HTML（内嵌样式与判分脚本）。标题约定 `<title>页名 · 大类/子类</title>`，构建脚本按 ` · ` 前段提取标题。
- **进度系统**：`tools/build_checklist.py` 递归扫描目录，按固定大类顺序生成 `checklist.js / checklist.json`；`index.html` 渲染三态清单，进度存 localStorage，支持导出/导入 JSON。
- **代码语言规则**：能 Java 的给 Java + Python 双份；只能 Python 的给 Python（必要时加伪代码）；前端用 JS/TS。算法题与深度学习手撕题统一 ACM 模式，页面内样例均经实际运行核对。
- **图示规范**：Mermaid 图与 ASCII 回退成对出现（`pre.ascii-fallback` + `pre.mermaid`）：联网渲染成功删前者、断网删后者，任何环境都不会露出裸源码。
- **题目来源原则**：408 统考公开真题与常考题型、牛客/面经经典题（改编处标注）、LeetCode 等公开题库；不收录任何付费题库内容。
- **扩展新页**：把 `xxx.html` 放进对应子文件夹，重跑 `python tools/build_checklist.py`，新页面自动出现在清单。
- **构建内幕**：参照了哪些项目、批量铺量的模式与 prompt 样例、页面规格全文，见 [docs/BUILD.md](docs/BUILD.md)、[docs/SPEC.md](docs/SPEC.md)、[docs/PROMPT-SAMPLE.md](docs/PROMPT-SAMPLE.md)。
