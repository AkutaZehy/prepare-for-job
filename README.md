# prepare-for-job 求职复习站

面向小中厂软工岗（测开 Java / AI·Agent 开发 / 通用软开与前端）的本地复习站：四大类知识点页 + 可交互自测题 + 学习进度记录。全部为自包含静态 HTML，双击即用，无需任何服务或构建。

## 目录结构

```
408基础/            数据结构 · 计算机组成原理 · 操作系统 · 计算机网络
编程题与Java基础/    算法编程题(按专题, ACM模式完整程序) · Java语言基础 · 集合并发JVM · 生态(MySQL·Redis·SpringBoot)
深度学习与Python进阶/ Python进阶 · NumPy与Pandas · 机器学习 · 深度学习 · 大模型与LLM应用 · 深度学习手撕编程题
前端/               JS与HTML · TypeScript · Vue · React
index.html          进度清单页（三态标记 + 日期 + 导出/导入）
build_checklist.py  清单扫描脚本
```

## 用法

1. **看进度**：双击 `index.html`。每个知识点一行，点击左侧状态按钮循环切换 ○ 未学 → ◐ 学习中 → ● 已完成，自动记录日期；右上可按标题过滤、导出/导入进度 JSON（备份在浏览器 localStorage，换浏览器前先导出）。
2. **学知识点**：点清单条目打开知识点页。每页固定四段：知识点梳理 → 考点说明 → 示例题目（选择题点击选项即时判分，计算题先自算再展开解析）→ 代码/易错点。部分页面含 MathJax 公式，需联网加载；断网时公式显示为原文，不影响阅读。
3. **加新页**：把 `xxx.html` 放进对应子文件夹，然后重跑 `python build_checklist.py`，新页面自动出现在清单。

## 知识点页规格

- 单文件自包含（内嵌样式与交互脚本），标题格式 `<title>页名 · 大类/子类</title>`（脚本按 ` · ` 前段提取标题）。
- 代码规则：能 Java 的给 Java+Python 双份；只能 Python 的给 Python+伪代码；前端用 JS/TS。
- 算法编程题与深度学习手撕题均为 **ACM 模式**（stdin/stdout 完整程序，可直接粘贴牛客判题）。
- 题目来源：408 统考公开真题（标注来源）、牛客/面经经典题（部分改编标注），不收录付费题库内容。

## 铺量约定

样板先行：每类先出样板页锁定风格，后续按高频优先批量铺量（规划总量 100+ 页）。仓库已推送 GitHub private 一次；日常学习不产生 git 提交，需要同步时手动操作。
