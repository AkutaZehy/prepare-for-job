要点速记：8 位补码范围 $-128\sim+127$，负数多一个（10000000 规定为 $-128$）；溢出判断：双符号位 01 正溢、10 负溢；或最高位进位 $\oplus$ 次高位进位 $=1$ 则溢出；负数补码算术移位左移补 0、右移补 1；IEEE754 单精度 1+8+23（偏移 127）、双精度 1+11+52（偏移 1023），规格化形如 $1.M\times 2^{E}$，整数位 1 隐藏不占位数；浮点加减五步：对阶（小阶向大阶）→ 尾数加减 → 规格化 → 舍入 → 溢出判断；x86 是小端（低位字节放低地址），Java 的 ByteBuffer 默认按大端。

一、知识点梳理

四种机器码：原码 = 符号位 + 绝对值；反码：正数同原码，负数数值位按位取反；补码：正数同原码，负数 = 反码 + 1；移码 = 补码符号位取反（即 $[x]_{移}=2^{n-1}+x$），浮点阶码专用——移码大 ⇔ 真值大，便于直接按无符号比较阶的大小。

x（8 位）[x]原[x]反[x]补[x]移
+10000 00010000 00010000 00011000 0001
−11000 00011111 11101111 11110111 1111
+1270111 11110111 11110111 11111111 1111
−128不存在不存在1000 00000000 0000

8 位补码范围 $-2^{7}\sim 2^{7}-1$ 即 $-128\sim+127$，为什么负数多一个：补码中 0 只有一个编码（全 0），原码里"±0"占用的 10000000 空了出来，规定它表示 $-128$——所以 $-128$ 有补码、没有对应的原码/反码。n 位补码统一为 $-2^{n-1}\sim 2^{n-1}-1$。快速求负数补码：符号位不变，数值位从右往左找到第一个 1，它及其右边照抄，左边数值位全部取反。

补码加减法与溢出判断：补码加法统一——$[x+y]_补=[x]_补+[y]_补 \pmod{2^n}$，减法化为加负数的补码，符号位直接参与运算。溢出只可能发生在同号相加（或异号相减）且结果超界时。两种判断法：

  • 双符号位（变形补码）：运算后两位符号位 00 为正、11 为负（未溢出）；01 正溢、10 负溢（第一位才是真正的符号）。
  • 单符号位进位异或：最高位（符号位）进位 $C_7$ 与次高位（最高数值位）进位 $C_6$ 异或，$C_7\oplus C_6=1$ 即溢出。

算术移位（符号位不变，补什么看码制）：

数据类型左移补右移补
正数（原/反/补）00
负数原码00
负数反码11
负数补码01

口诀：负数补码"左 0 右 1"。对照：逻辑移位（无符号数）一律补 0。

IEEE754 浮点标准：单精度 float 32 位 = 1 位符号 + 8 位阶码（偏移 127）+ 23 位尾数，值 $=(-1)^s\times 1.f\times 2^{e-127}$；双精度 double 64 位 = 1 + 11（偏移 1023）+ 52。隐藏位：规格化二进制数必形如 $1.xxx$，最高位的 1 不存储，相当于尾数白赚一位精度（单精度实际 24 位有效尾数）。阶码真值范围 $-126\sim+127$：e 全 0 表示 ±0 与非规格化小数，e 全 1 表示 $\pm\infty$（f=0）与 NaN（f≠0）。单精度规格化数范围 $\pm 2^{-126}\sim\pm(2-2^{-23})\times 2^{127}$（约 $\pm 3.4\times 10^{38}$）。

大小端（面试也问）：多字节数据在内存中的字节序。大端（big-endian）：高位字节放低地址，符合人的书写顺序（网络字节序、Java 默认）；小端（little-endian）：低位字节放低地址（x86 默认）。以 int 0x12345678 从低地址到高地址排布为例：

大端：  12 34 56 78      （12 是最高位字节，放在最低地址）
小端：  78 56 34 12      （78 是最低位字节，放在最低地址）
Java 
import java.nio.ByteBuffer;

public class EndianDemo {
    public static void main(String[] args) {
        ByteBuffer buf = ByteBuffer.allocate(4);  // Java 默认 BIG_ENDIAN
        buf.putInt(0x12345678);
        for (int i = 0; i < 4; i++) {
            System.out.printf("byte[%d]=%02X%n", i, buf.get(i));
        }
        // 输出 byte[0]=12 byte[1]=34 byte[2]=56 byte[3]=78 → 大端
        // 本机真实字节序用 ByteOrder.nativeOrder() 查看
    }
}
Python 
import struct, sys

big = struct.pack(">I", 0x12345678)     # 强制大端打包
little = struct.pack("<I", 0x12345678)  # 强制小端打包
print(big.hex(" "))      # 12 34 56 78
print(little.hex(" "))   # 78 56 34 12 ← x86 真机内存就是这个字节序
print(sys.byteorder)     # little（x86 与多数 ARM 默认）

浮点加减法五步骤：① 对阶——求阶差，小阶向大阶对齐（小阶的尾数右移，每移一位阶码加 1）；② 尾数加减（用补码、双符号位，便于判溢出）；③ 规格化——尾数不在 $[\frac12,1)$ 时：左规（尾数左移、阶码减 1）或右规（尾数右移、阶码加 1）；④ 舍入（0 舍 1 入、恒置 1 等）；⑤ 溢出判断——看阶码是否溢出：阶码上溢才算浮点溢出（中断/置 $\infty$），阶码下溢按机器零处理。为什么小阶向大阶：尾数右移丢失的是低位、精度损失小；若大阶向小阶，尾数要左移，丢失高位直接出错，还可能移出寄存器。

三、示例题目（选择题点击选项即时判分）

计算1. 求 $-100$ 的 8 位补码，写出原码 → 反码 → 补码的变换过程，并给出十六进制形式。

先自己算，再展开对答案100 = 64+32+4 = 1100100₂。
原码：符号 1 + 1100100 = 1110 0100；
反码：符号位不变、数值位取反 = 1001 1011；
补码：反码 +1 = 1001 1100，即 9CH。
验算：1001 1100 = 128+16+8+4 = 156 = 256−100 ✓（负数补码按无符号读就是 $2^8+ x$）。来源：408 统考高频题型（公开真题常考形式）。

单选2. 用双符号位（变形补码）计算：$[x]_补=00\ 1100100$（即 100），$[y]_补=00\ 0110010$（即 50），则 $[x+y]_补$ 与溢出情况是（  ）

A. 结果为 00 1001011，无溢出
B. 结果符号位为 01，发生正溢出
C. 结果符号位为 10，发生负溢出
D. 结果符号位为 11，无溢出
答案 B。00 1100100 + 00 0110010 = 01 0010110。双符号位 01 → 正溢出（真值 150 超出 8 位补码上限 127）。用进位法验证：次高位进位 $C_6=1$、最高位进位 $C_7=0$，$1\oplus 0=1$ → 溢出，且两正数相加结果符号变负特征 → 正溢。来源：408 统考高频题型（公开真题常考形式）。

计算3. 把十进制数 $-12.5$ 写成 IEEE754 单精度（float）的二进制位串，并给出十六进制形式。要求按"符号位 → 尾数规格化 → 阶码"逐步写出。

先自己算，再展开对答案① 符号：负数 → s = 1。
② 尾数规格化：$12.5 = 1100.1_2 = 1.1001_2\times 2^{3}$ → 尾数小数部分 f = 1001 后补 0 至 23 位：1001 0000 0000 0000 0000 000（整数位 1 隐藏不存）。
③ 阶码：真阶 3 + 偏移 127 = 130 = 1000 0010₂。
拼接：1 | 10000010 | 10010000000000000000000。
按 4 位一组转十六进制：1100 0001 0100 1000 0000 0000 0000 0000 = 0xC1480000。来源：面试高频改编。

计算4. 阅读上面 Java 与 Python 两段代码（不运行），写出各自注释处的输出，并回答：x86 机器上 int 0x12345678 从低地址到高地址的内存字节序列是什么？如何判断本机字节序？

先自己算，再展开对答案Java：ByteBuffer 默认 BIG_ENDIAN，输出 byte[0]=12、byte[1]=34、byte[2]=56、byte[3]=78——高位字节在低地址。Python：struct.pack(">I") 得 12 34 56 78；struct.pack("<I") 得 78 56 34 12。
x86 是小端：0x12345678 内存低→高为 78 56 34 12（低位字节在低地址）。
判断本机字节序：Python sys.byteorder（'little'/'big'）；Java ByteOrder.nativeOrder()。工程意义：网络字节序是大端，跨机传输多字节数值要 htons/ntohl 这类转换。来源：牛客经典题。

单选5. 两个浮点数相加，阶码不同，对阶的正确做法是（  ）

A. 小阶向大阶对齐，小阶的尾数右移
B. 大阶向小阶对齐，大阶的尾数左移
C. 两个阶码同时取中间值
D. 直接把两尾数相加，不必对阶
答案 A。对阶必须小阶向大阶：小阶尾数右移只丢低位、精度损失小；若大阶向小阶，尾数左移会丢失高位有效数字，甚至左移出寄存器，错误严重。对阶后才能按位对齐相加，D 不对阶必错。来源：408 统考高频题型（公开真题常考形式）。

单选6. 已知 $[x]_补 = 1110\ 1100$，则真值 $x$ 等于（  ）

A. −20
B. −19
C. +20
D. −116
答案 A。符号位 1 → 负数。求真值：数值位取反加 1（或对整个补码再取补）：1110 1100 → 取反 0001 0011 → +1 → 0001 0100 = 20，故 x = −20。选 B 是"取反忘了 +1"（0001 0011 = 19）——最常见的丢分点。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① 负数补码"反码 +1"，忘加 1 结果就差 1（−20 算成 −19）；② 补码 1000 0000 是 −128 不是 −0，且它没有对应的原码/反码；③ 溢出只发生在同号相加（异号相减）——异号相加永远不会溢出；④ IEEE754 还原数值时记得把隐藏的整数位 1 加回（是 $1.f$ 不是 $0.f$），阶码先减偏移再当指数；⑤ 二进制转十六进制按 4 位一组（八进制才是 3 位一组）；⑥ 浮点"溢出"指阶码上溢，尾数加减的进位只需右规；⑦ Java 的 int 溢出不报错、按补码回绕（面试口述点），float/double 严格遵循 IEEE754。
