指令系统与流水线

适用岗位：全部（笔试选择 + 计算；测开/嵌入式尤其常考） ｜ 形态：公式 + 对比表 + 手算过程 ｜ 更新：2026-09-30
要点速记：寻址方式记三件事——EA 怎么算、访存几次、寄存器归谁管；基址 = 操作系统管 BR（面向重定位），变址 = 用户管 IX（面向遍历数组）；RISC 四特征：指令少、定长、只有 LOAD/STORE 访存、硬布线控制 + 寄存器多；流水线总时间 $T=(k+n-1)\Delta t$、加速比 $S=\dfrac{nk\Delta t}{T}$（上限 = 段数 k）；三类冒险：结构 = 资源冲突、数据 = 后用前果（转发旁路）、控制 = 转移改 PC（分支预测）。

一、知识点梳理

八种常见寻址方式（访存次数指执行阶段取操作数的访存，不含取指令；(X) 表示"X 单元/寄存器的内容"）：

寻址方式有效地址 EA / 操作数位置访存次数特点与用途
立即寻址操作数在指令中（#123）0取指后立即可用、最快；立即数范围受 A 位数限制
直接寻址EA = A1寻址范围受 A 位数限制（A 有 n 位则可寻 $2^n$ 个单元）
一次间接寻址EA = (A)2先访存取出 EA、再访存取数；扩大寻址范围，速度慢
寄存器寻址操作数就在 Ri 中0不访存、快；寄存器数量与位数有限
寄存器间接寻址EA = (Ri)1地址放在寄存器里，比间接寻址快、比直接寻址范围大
基址寻址EA = (BR) + A1BR 由操作系统管理；程序重定位、多道程序设计
变址寻址EA = (IX) + A1IX 由用户设定；数组遍历、循环批量处理
相对寻址EA = (PC) + A1A 为位移量（补码）；程序整体搬移后转移目标仍正确

基址 vs 变址（最爱考的区别）：两者 EA 都是"寄存器内容 + 形式地址"，判别靠寄存器归谁管、谁变谁不变——

  • 基址寻址：BR 由操作系统（系统程序）设定，用户不能修改。程序装入主存时确定基址，一道程序执行中 BR 不变、指令中的偏移 A 固定；程序整体搬家（重定位）时只需改基址寄存器，程序本身一字不改——面向操作系统，服务于多道程序与浮动装配，同时扩大寻址范围。
  • 变址寻址：IX 由用户（程序员）设定并可修改。形式地址 A 作基准（如数组首地址）保持不变，IX 按规律递增/递减逐个访问元素——面向用户，适合数组遍历、字符串循环处理。

CISC vs RISC 对比：

对比维度CISC（复杂指令集）RISC（精简指令集）
指令数量与复杂度指令多（200 条以上）、长短不一、格式多指令少而简单、格式与寻址方式种类少
指令字长变长定长
访存指令多种指令都能访存只有 LOAD / STORE 指令访存，运算只在寄存器间进行
指令执行时间相差悬殊（多数多周期）大多数一个机器周期完成
通用寄存器较少数量多
控制方式微程序控制为主（复杂指令要解释执行）组合逻辑（硬布线）为主
流水线指令规整性差，难以优化定长规整，便于采用流水线技术
典型代表x86ARM、MIPS、RISC-V

注：x86 对外是 CISC，内部把复杂指令拆成类 RISC 的微操作再流水执行。

指令流水线（五段）：取指 IF → 译码/取数 ID → 执行 EX → 访存 MEM → 写回 WB。这是时间并行：第 i 条指令在 EX 段时，第 i+1 条已在 ID、第 i+2 条已在 IF。理想条件：各段时间相等（都为 Δt）、无冒险、指令连续流入。以 3 条指令、5 段为例的时空图：

总时间与加速比：k 段流水线执行 n 条指令——第一条指令走完全程需 kΔt，此后每 Δt 流出一条：

$$T = k\Delta t + (n-1)\Delta t = (k+n-1)\Delta t$$

不采用流水线时总时间 $nk\Delta t$，加速比 $S=\dfrac{nk\Delta t}{T}=\dfrac{nk}{k+n-1}$；当 n 充分大时 $S\to k$，段数 k 就是加速比的上限。吞吐率 TP = n/T，理想时每 Δt 完成一条。口诀："第一条走全程，剩下每拍出一条"。

三类流水线冒险与对策：

冒险类型成因（典型场景）对策
结构冒险（资源冒险）多条指令同时争用同一硬件资源：如指令与数据存在同一个存储器，IF 段与 MEM 段同时访存插入停顿（气泡）；指令/数据存储器分开（哈佛结构）；资源重复设置
数据冒险后面的指令要用到前面指令尚未写回的结果（最常见：写后读 RAW）数据转发/旁路（forwarding：把上条指令的结果直接送给需要它的下条指令）；插入暂停；编译器调整指令顺序。注意 load-use 相关即使有转发也要停 1 拍（数据到 MEM 段末才产生）
控制冒险转移/分支指令改变 PC，已按顺序取入流水线的后续指令作废分支预测（静态猜方向/动态按历史猜）、延迟分支、尽早判别转移条件

提高并行度三条路线（各一句）：超标量——一个时钟周期内发射多条指令，配置多条流水线/多套功能部件，靠编译静态调度或硬件动态调度；超流水——把流水段切得更细、时钟周期更短（主频更高），代价是段间锁存开销与冒险增多；SMT（同时多线程）——单个物理核在同一周期从多个线程取指令，填满空闲部件（Intel 超线程是其商业实现），提高部件利用率。

三、示例题目（点击选项即时判分）

计算1. 某机器指令中形式地址 A=500（十进制）。已知主存 (500)=800、(800)=1000，寄存器 R1=400，基址寄存器 BR=2000，变址寄存器 IX=350，取指后 PC=1000（已指向下一条指令）。分别写出直接、一次间接、寄存器间接、基址、变址、相对六种寻址方式下操作数的有效地址 EA。

先自己算，再展开对答案逐个套 EA 公式：
① 直接：EA = A = 500；
② 一次间接：EA = (A) = (500) = 800（执行阶段访存 2 次：先取 EA 再取数）；
③ 寄存器间接：EA = (R1) = 400；
④ 基址：EA = (BR) + A = 2000 + 500 = 2500；
⑤ 变址：EA = (IX) + A = 350 + 500 = 850；
⑥ 相对：EA = (PC) + A = 1000 + 500 = 1500。
易混点：④⑤公式同形，判别看寄存器归谁管——BR 系统设、IX 用户设。来源：408 统考高频题型（公开真题常考形式）。

计算2. 某流水线分 5 段（IF/ID/EX/MEM/WB），每段耗时 Δt=1ns，连续输入 10 条指令。求：(1) 流水线总执行时间；(2) 与串行执行相比的加速比；(3) 吞吐率。

先自己算，再展开对答案① 套公式 $T=(k+n-1)\Delta t$：k=5、n=10 → T = (5+10−1)×1ns = 14ns（第 1 条 5ns 走完全程，剩余 9 条每 1ns 流出一条）。
② 串行时间 = nkΔt = 10×5×1 = 50ns，加速比 $S=\dfrac{50}{14}\approx$ 3.57（上限是段数 5，10 条指令还远没逼近极限）。
③ 吞吐率 = 10 条 ÷ 14ns ≈ 0.71 条/ns（理想极限为每 1ns 一条）。
验算：14 = 5 + 9 ✓，第 10 条指令的 WB 恰发生在第 14 个节拍 ✓。来源：408 统考高频题型（公开真题常考形式）。

单选3. 关于基址寻址与变址寻址，下列说法正确的是（  ）

A. 基址寄存器由操作系统管理，便于程序重定位；变址寄存器由用户设定，便于数组遍历
B. 两者完全等价，寄存器都可由用户随意修改
C. 变址寄存器的内容由操作系统在程序装入时确定，执行中用户不可修改
D. 相对寻址的有效地址计算公式是 EA = (BR) + A
答案 A。基址 = 系统级：BR 由操作系统设定，程序整体搬移（重定位）只改基址，程序不变；变址 = 用户级：IX 程序员可改，A 作数组首址基准、IX 递增遍历。B 错在基址寄存器对用户透明；C 把两者说反；D 是基址寻址的公式，相对寻址是 (PC)+A。来源：牛客经典题。

多选4. 下列流水线工作情形中，属于数据冒险的有（  ）

A. 第 i+1 条指令的源操作数是第 i 条指令刚算出、还没写回的结果
B. 第 i 条指令在 MEM 段访存时，第 i+2 条指令恰在 IF 段取指，两者争用同一个存储器
C. 条件转移指令成立，导致已取入流水线后面的指令全部作废
D. load 指令后紧跟使用其加载结果的指令，即使有转发机制也需停顿 1 拍
答案 AD。A 是典型的 RAW（写后读）数据冒险；D 是 load-use 数据冒险——数据要到 MEM 段末才产生，转发也来不及，必须停 1 拍。B 是结构冒险（资源冲突，对策：指令/数据存储分开）；C 是控制冒险（对策：分支预测）。来源：408 统考高频题型（公开真题常考形式）。

多选5. 下列关于 RISC（精简指令集计算机）的叙述，正确的有（  ）

A. 指令条数少、指令长度固定、指令格式和寻址方式种类少
B. 只有 LOAD 和 STORE 指令可以访存，其余指令都在寄存器之间进行
C. 控制器以微程序控制为主，便于实现功能复杂的指令
D. CPU 中设置大量通用寄存器，大多数指令单周期完成，便于采用流水线
答案 ABD。RISC 靠"简单 + 规整"换流水线效率：定长、少格式、load/store 式访存、寄存器多、硬布线（组合逻辑）控制——C 恰好说反，微程序控制是 CISC 的特征（复杂指令需要微程序解释执行）。来源：408 统考高频题型（公开真题常考形式）。

单选6. 某程序在主存中被整体搬移到另一位置后，其中的条件转移指令仍能跳到正确目标。该转移指令最可能采用的寻址方式是（  ）

A. 直接寻址
B. 间接寻址
C. 相对寻址
D. 立即寻址
答案 C。相对寻址 EA=(PC)+A，转移目标随 PC（指令自身位置）浮动：程序整体搬移后偏移量 A 不变、目标依然正确——这正是转移指令普遍采用相对寻址的原因。直接/间接寻址写的是绝对地址，搬移后目标失效。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① "寄存器 + 形式地址"型（基址/变址/相对）公式同形，判别靠寄存器归谁管：BR=系统、IX=用户、PC=隐含给出；② 相对寻址的 PC 是取指后已自增、指向下一条指令的 PC，别拿当前指令地址去算；③ 一次间接寻址执行阶段访存 2 次（第一次取 EA、第二次取数），别漏第一次；④ 流水线公式先确认段数 k、每段等长 Δt，加速比上限是 k 而不是 n；⑤ load-use 冒险有转发也要停 1 拍，"转发能解决一切数据冒险"是错误说法；⑥ 对策别安错对象：结构冒险靠分资源/重复设置，数据冒险靠转发/停顿，控制冒险靠分支预测。
