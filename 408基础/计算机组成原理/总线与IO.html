总线与 I/O

适用岗位：全部（笔试选择 + 计算；嵌入式/驱动/测开更爱问） ｜ 形态：概念 + 对比表 + 手算过程 ｜ 更新：2026-09-30
要点速记：三总线——数据（双向）/地址（单向，位数 n 决定可寻址 2n 个单元）/控制；带宽 = 工作频率 × (位宽/8) × 每周期传输次数；中断流程：关中断 → 保存断点与现场 → 中断服务 → 恢复现场 → 开中断返回，中断隐指令 = 硬件自动做的关中断 + 保存断点 + 引出入口；屏蔽字 1=屏蔽、每源自屏蔽、1 越多优先级越高；DMA 三方式（停 CPU / 周期挪用 / 交替访问），外设↔内存直接通路、一块数据传完才中断一次；通道 = 跑通道程序的专用 I/O 处理机。

一、知识点梳理

系统总线三分类：

总线方向作用与要点
数据总线 DB双向传数据（也可传指令码、中断类型号）；位数 = 一次能并行传输的位数，与机器字长相关
地址总线 AB单向（CPU→外）指出源/目的地址；位数 n 决定寻址空间：最多 2n 个单元（按字节编址即 2n 字节）
控制总线 CB整体双向（每根线单向）传时序与命令：读/写命令、中断请求、总线请求/授权、时钟；对 CPU 有出（读写命令）有入（中断请求）

总线带宽 = 工作频率 × 每次传输的字节数 = f × (位宽/8)。

  • 例：数据总线 32 位（4B）、工作频率 100MHz、每时钟周期传一次 → 100M × 4B = 400MB/s。
  • 若每周期传 2 次（时钟上升沿、下降沿各传一次，DDR 口径）→ 带宽翻倍为 800MB/s。做题先看清"每周期传几次"，按题目给的口径算。

串行 vs 并行、半双工 vs 全双工：串行 = 一根线逐位传（USB、SATA，成本低、适合长距离）；并行 = 多根线同时传一个字节/字（机内总线，长距离受线间串扰与偏移限制）；半双工 = 可双向但不能同时（对讲机）；全双工 = 同时双向（电话）。

总线仲裁：解决多个主设备同时申请总线的冲突。集中式三种：① 链式查询——总线授权信号 BG 沿设备链串行传递，离控制器越近优先级越高（固定、省线、对故障敏感）；② 计数器定时查询——控制器用计数器逐个询问设备号；③ 独立请求方式——每台设备独立请求线，优先级灵活可编程、速度最快、控制线最多。分布式仲裁：无中央控制器，各设备自行竞争裁决。

中断处理全流程（单重中断）：

中断请求 → 中断判优 → 中断响应（中断隐指令，硬件自动完成）
  → 保护现场 → 中断服务 → 恢复现场 → 开中断 → 中断返回
  • 中断隐指令：不是指令系统里的真指令，而是中断响应周期由硬件自动完成的动作——① 关中断；② 保存断点（PC 压栈或存入指定单元）；③ 引出中断服务程序入口地址。
  • 中断向量 = 中断服务程序的入口地址；中断向量表存放各中断向量；向量地址 = 中断向量在向量表中的单元地址（指向入口地址的"指针"）。三者别混。
  • 单重 vs 多重（中断嵌套）：单重中断在服务期间不再响应新中断；多重中断运行中若出现更高级请求，可暂停当前服务转去处理（嵌套）。运行优先级由屏蔽字控制。
  • 屏蔽字判处理次序：每个中断源对应一个屏蔽字，某位 =1 表示屏蔽对应中断源、=0 表示开放。规则：每个中断源必屏蔽自己；优先级越高的源屏蔽字中 1 越多（把不高于自己的全部屏蔽）。拿到一组屏蔽字：数每行 1 的个数，从多到少即处理次序。

DMA（直接存储器存取）：在主存与高速外设之间开辟直接数据通路，成块传送由 DMA 控制器硬件全权管理，CPU 不当搬运工。三种方式：

  • 停止 CPU 访存：DMA 传送期间 CPU 暂停访存——控制最简单，CPU 利用率最低；
  • 周期挪用（周期窃取）：DMA 挪用一个存储周期传一个字/字节，DMA 与 CPU 交替使用内存——最常用；
  • 交替访问：CPU 与 DMA 各按固定时间片轮流访存，无需申请/归还总线，硬件最复杂。

DMA 传送三阶段：预处理（CPU 初始化：主存起始地址、传送字数、方向，启动设备）→ 数据传送（DMA 控制器独立完成，与 CPU 并行工作）→ 后处理（一块传完，DMA 向 CPU 发一次中断，CPU 做校验、善后）。所以一块数据从头到尾只在结束时打扰 CPU 一次。

对比中断方式DMA 方式
数据传送单位字节/字（每次一个）数据块
CPU 介入程度每传一个数据都要执行一段中断服务程序仅预处理与后处理介入
数据通路外设 → CPU 寄存器 → 内存（CPU 搬运）外设 ↔ 内存直接，不经过 CPU
响应时机指令执行周期结束后才可响应存取周期结束后即可响应
优先级低高（不及时响应会丢失数据）
适用场景中低速、少量数据设备（键盘）高速成块设备（磁盘、网卡）

通道一句：通道是能执行通道程序的专用 I/O 处理机，CPU 只负责启动，整块甚至多块数据的传送与调度都由通道完成，独立性比 DMA 更高（大中型机配置，成本高）。

三、示例题目（点击选项即时判分）

计算1. 某同步总线的数据线宽 32 位，工作频率 200MHz，每个时钟周期传送一次数据。(1) 求总线带宽；(2) 若改为时钟上升沿与下降沿各传送一次（DDR 口径），带宽又是多少？

先自己算，再展开对答案① 每次传送 32 位 = 4B，带宽 = 200M 次/s × 4B = 800MB/s。
② 上下沿各传一次 → 每周期传 2 次 → 带宽翻倍 = 1600MB/s。
验算：带宽 = 频率 × 每次字节数 × 每周期次数 = 200M × 4 × 2 = 1600MB/s ✓。来源：408 统考高频题型（公开真题常考形式）。

计算2. 某机有 4 个中断源 A、B、C、D，运行时采用的屏蔽字如下（每行 4 位，从左到右对应 A、B、C、D；"1"=屏蔽，"0"=开放）：A：1011　B：0100　C：1111　D：0101。给出 CPU 实际处理这些中断的优先次序，并说明判断依据。

先自己算，再展开对答案判断依据：每个源都屏蔽自己（自查：A 行第 1 位、B 行第 2 位、C 行第 3 位、D 行第 4 位均为 1 ✓）；屏蔽字中 1 越多，处理优先级越高。
数 1 的个数：C=4 个、A=3 个、D=2 个、B=1 个 → 处理次序 C → A → D → B。
语义自洽性检查：C 屏蔽所有人（1111，谁也打不断它）；A 屏蔽自己/B/D、放开 C（C 能打断 A）；D 屏蔽自己/B、放开 A/C；B 只屏蔽自己（谁都能打断它）✓。来源：408 统考高频题型（公开真题常考形式）。

多选3. 关于中断方式与 DMA 方式，下列说法正确的有（  ）

A. DMA 方式下数据在外设与主存之间直接传送，不经过 CPU 内部寄存器
B. 中断方式下每传送一个字节/字，CPU 都要执行一段中断服务程序
C. DMA 请求与中断请求一样，都要等到一条指令执行结束后才被响应
D. 一块数据传送结束时，DMA 控制器才向 CPU 发出一次中断请求做善后处理
答案 ABD。C 错：中断请求在指令执行周期结束后查询响应，而 DMA 请求在存取周期结束后即可响应（不等整条指令结束），这也是 DMA 优先级更高的原因之一——不及时响应可能丢失数据。来源：408 统考高频题型（公开真题常考形式）。

单选4. 采用 DMA 方式传送数据时，数据的传送通路是（  ）

A. 外设 ↔ 主存直接传送，不经过 CPU
B. 外设 → CPU 通用寄存器 → 主存，由 CPU 逐字搬运
C. 外设 → CPU 的程序计数器 PC → 主存
D. 外设必须先送入 Cache，再由 Cache 写入主存
答案 A。DMA 全称"直接存储器存取"：由 DMA 控制器接管总线，数据在外设与主存间直传，CPU 只做预处理（设地址/字数/方向）和后处理（收一次中断善后）。B 是中断方式的通路；C 的 PC 与数据传送无关；D 无此要求。来源：牛客经典题。

单选5. 下列关于系统总线的说法，正确的是（  ）

A. 地址总线是双向的，用于在 CPU 与主存间来回传输地址
B. 数据总线的位数决定了主存的最大寻址空间
C. 地址总线是单向的，其位数 n 决定 CPU 可直接寻址的空间为 2n 个单元
D. 控制总线上的所有信号都由 CPU 发出
答案 C。地址总线单向（CPU 发出），n 位 → 可寻址 2n 个单元；A 方向说反；B 张冠李戴——决定寻址空间的是地址总线位数；D 错：控制总线整体双向，中断请求、总线请求等信号是设备发往 CPU 的。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① 数据总线双向、地址总线单向，"位数决定寻址空间"的是地址总线；② 带宽 = 频率 × 每次字节数 × 每周期传输次数，DDR 口径乘 2；③ 中断隐指令只有三件事（关中断、保存断点、引出入口），保存现场是中断服务程序用指令做的，两者别混；④ 屏蔽字 1=屏蔽、每源自屏蔽、1 越多优先级越高（个别题目用 0 表屏蔽，按题给口径换算）；⑤ 中断响应看指令周期结束、DMA 响应看存取周期结束；⑥ DMA 只在预处理/后处理被 CPU 打扰，一块数据结束才中断一次；链式查询优先级离控制器越近越高且固定。
