数据链路层：CRC、滑动窗口与 CSMA/CD

适用岗位：全部（CRC 手算与最小帧长是笔试传统艺能） ｜ 形态：概念 + 计算 ｜ 更新：2026-09-30
要点速记：CRC = 数据后补 (生成多项式位数−1) 个 0 再模二除法，余数即 FCS；HDLC 发送端遇到 5 连 1 插一个 0（比特填充）；GBN 发送窗口 ≤ 2ⁿ−1、SR ≤ 2ⁿ⁻¹（详见 TCP 可靠传输与拥塞控制 同款窗口表）；CSMA/CD 最小帧长 = 2τ × 数据率（争用期=2τ），10Mbps 以太网最小帧 64B；交换机靠自学习建 MAC 表，转发时查表、表缺则泛洪。

一、知识点梳理

封装成帧与透明传输：帧定界用首尾标志（HDLC 的 01111110）。为让数据里出现标志位也不出错——字节填充（字符计数法/转义字符）与比特填充：发送端每遇 5 个连续 1 就插一个 0，接收端删掉。例：数据 011111101 → 发送 011111001。

差错检测：CRC 循环冗余校验（模二除法，必考手算）。约定生成多项式 P（r 位，最高位 1）：

① 数据 M 后补 r−1 个 0
② 用补 0 后的数 模二除 P（异或，不进位不借位）
③ 余数即 FCS（r−1 位），拼在 M 后发送
④ 接收方用收到的整帧 ÷ P，余数为 0 视为无错

经典例（教材）：M=101001，P=1101。补 3 个 0 得 101001000，逐步异或：

1010 ^ 1101 = 0111 → 下拖 0：1110 ^ 1101 = 0011 → 下拖 1：0111（首位0，商0）
下拖 0：1110 ^ 1101 = 0011 → 下拖 0：0110（首位0，商0）→ 下拖 0：1100 ^ 1101 = 0001
余数 FCS = 001，发送帧 = 101001 001
验证：101001001 ÷ 1101 余 0 ✓

注意：CRC 只能检错不能纠错（发现错就丢弃，重传交给上层）；链路层的可靠传输（滑动窗口）在有线网络中通常不做，可靠交给 TCP。

流量控制与可靠传输：停止-等待 / GBN / SR 三协议的窗口公式与机制与传输层同构（TCP 可靠传输与拥塞控制 页有完整对比表），链路层语境下叫"滑动窗口机制"，考试给编号位数算窗口：GBN ≤ 2ⁿ−1，SR 双方 ≤ 2ⁿ⁻¹。

介质访问控制 CSMA/CD（半双工以太网）：先听后发、边听边发、冲突停发、二进制指数退避后重发。关键推导：信号往返时延 2τ 内必须还在发送（才能"边发边检测"到碰撞），所以最小帧长 = 2τ × 数据率。以太网取争用期 2τ = 51.2μs，10Mbps 下最小帧 = 10⁷ × 51.2×10⁻⁶ = 512bit = 64 字节。检测到冲突后第 i 次重传：从 {0..2ⁱ−1} 随机选 k 个争用期等待（i 上限 16，超限放弃报错）。无线网不能用 CD（信号衰减大、无法边发边听），改 CSMA/CA 冲突避免。

以太网与交换机：MAC 地址 48 位；以太网 V2 帧格式 = 目的 MAC(6) + 源 MAC(6) + 类型(2) + 数据(46~1500) + FCS(4)，MTU=1500（不含首尾）。交换机自学习：收到帧时把"源 MAC + 入端口"写入 MAC 表；转发时查目的 MAC——表中有则定点转发，无则向除入口外所有端口泛洪；同一广播域内广播帧必泛洪。交换机每个端口独享带宽（对比集线器共享带宽一个大冲突域）。VLAN：把一个物理交换网络切成多个隔离的广播域（概念）。

二、考点说明

计算题笔试选择

  • CRC 手算：给数据与生成多项式求 FCS，或验证接收帧——模二除法一步不能错。
  • 比特填充/删填充的转换题。
  • 最小帧长计算（给传播时延与带宽），或反向求电缆最大长度。
  • GBN/SR 窗口大小（m 位编号）。
  • 交换机自学习表的推演（给一系列帧收发，问表内容与转发/泛洪动作）。

三、示例题目（点击选项即时判分 / 计算题先自算）

计算1. 数据 M=101001，生成多项式 P=1101（对应 x³+x²+1）。求 CRC 校验码 FCS 与发送帧。

先自己算，再展开对答案P 为 4 位 → 补 3 个 0：101001000。模二除：
1010^1101=0111 → 拖 0：1110^1101=0011 → 拖 1：0111（首位 0 商 0）→ 拖 0：1110^1101=0011 → 拖 0：0110（商 0）→ 拖 0：1100^1101=0001
余数 FCS = 001，发送帧 = 101001001。校验：101001001 ÷ 1101 余 0。来源：408 统考高频题型（公开真题常考形式）。

计算2. 以太网争用期 2τ = 51.2μs，数据率 10Mbps。求最小帧长；若某网段传播时延单程 τ = 10μs、数据率 100Mbps，最小帧长又是多少？

先自己算，再展开对答案最小帧长 = 2τ × 数据率。10Mbps：10⁷ b/s × 51.2×10⁻⁶ s = 512 bit = 64 字节（这正是以太网帧数据下限 46B+首尾凑 64B 的由来）。第二问：2τ = 20μs，100Mbps → 10⁸ × 20×10⁻⁶ = 2000 bit = 250 字节。来源：408 统考高频题型（公开真题常考形式）。

单选3. HDLC 链路层发送数据 011111101（不含首尾标志），比特填充后线上传输的序列是（  ）

A. 011111101（无需填充）
B. 011111001
C. 0111111101
D. 011111011
答案 B。数据里出现 5 个连续 1（01111101），发送端在其后自动插一个 0：0 11111 0 01 → 011111001。接收端遇 5 连 1 就看下一位：0 则删除还原，1 则可能是标志/错误。来源：408 统考高频题型（公开真题常考形式）。

单选4. 数据链路层采用 GBN 协议、帧序号 3 位，发送窗口的最大值是（  ）

A. 8
B. 6
C. 7
D. 4
答案 C。GBN 发送窗口 ≤ 2ⁿ−1 = 7；若是 SR 则双方 ≤ 2ⁿ⁻¹ = 4。窗口超限会导致"新帧"与"重传旧帧"序号无法区分。来源：408 统考高频题型（公开真题常考形式）。

多选5. 关于以太网与交换机，正确的有（  ）

A. 交换机根据帧的源 MAC 地址自学习建立转发表
B. 交换机转发表查不到目的 MAC 时直接丢弃该帧
C. 交换机的每个端口是独立的冲突域，集线器所有端口共享一个冲突域
D. 以太网帧的数据字段有效范围是 46~1500 字节（MTU=1500）
答案 ACD。B 错——查不到就泛洪（除入口外所有端口发出），这也是广播帧的处理方式；无冲突域/有冲突域的对比是集线器与交换机的本质差异。来源：408 统考高频题型（公开真题常考形式）。

单选6. 无线局域网不用 CSMA/CD 而用 CSMA/CA 的根本原因是（  ）

A. 无线带宽太小，用不起冲突检测
B. 无线帧太短，来不及检测
C. 无线不需要介质访问控制
D. 无线信道信号强度衰减大，设备发送时无法可靠检测到碰撞（无法边发边听）
答案 D。CSMA/CD 的前提是"边发送边检测冲突"，无线网卡收到的自身信号远强于远处站点的碰撞信号，检测不可行——只能转向"尽量避免冲突+确认重传"（CSMA/CA）。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① CRC 的模二除法是异或不是减法，商的规则只看当前余数首位是 1 还是 0；② FCS 位数 = 生成多项式位数 − 1；③ 最小帧长公式里是往返时延 2τ，别只乘单程；④ 比特填充是"5 连 1 后插 0"，出现在考题里的常见变形是让你删填充还原数据；⑤ 交换机"查不到泛洪"与"广播必泛洪"是两件事但动作相同；⑥ CRC 检错不纠错，链路层有线网通常不做可靠传输——"链路层保证可靠交付"是错误说法。
