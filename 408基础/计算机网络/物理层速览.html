物理层速览

适用岗位：全部（笔试计算高频；通信/嵌入式向必问） ｜ 形态：公式 + 手算过程 ｜ 更新：2026-09-30
要点速记：比特率 = 波特率 × log₂V（V = 每码元状态数）；奈氏（理想无噪声）：极限码元速率 2W 波特、极限信息速率 $2W\log_2 V$；香农（有噪声）：$C=W\log_2(1+S/N)$，dB = 10·lg(S/N)，30dB → 1000 倍；双重限制取较小者；曼彻斯特每比特中间必跳变、波特率 = 2×比特率（10Mb/s 以太网 → 20M 波特）。

一、知识点梳理

码元、波特率与比特率：码元 = 一个固定时长的信号波形（可取 V 种离散状态，每种状态携带若干比特）；波特率 B = 每秒码元数（单位 Baud，波特）；比特率 R = 每秒比特数（b/s）。三者关系：

$$R = B\log_2 V$$

例：波特率 2400 Baud、四进制码元（V=4）→ 比特率 = 2400×log₂4 = 4800 b/s。注意"波特"是码元单位、不是 b/s，两者不能混写。

奈氏准则（理想无噪声信道）：带宽 W（Hz）的理想低通信道，极限码元速率 = 2W Baud（超过就会严重的码间串扰，接收端无法识别码元）。此时极限信息速率 = $2W\log_2 V$ b/s。要点：奈氏只卡码元速率，与噪声无关（前提是无噪声）；想提高信息速率只能增大 V（每码元多带比特）。

香农定理（有噪声信道）：带宽 W、信噪比 S/N 的信道，无差错传输的极限信息速率：

$$C = W\log_2(1+S/N)\ \text{(b/s)}$$

信噪比常以分贝给出：dB = 10·lg(S/N)。换算速查：20dB→100 倍、30dB→1000 倍、3dB≈2 倍、6dB≈4 倍。香农给的是信息速率上限，实际系统只能逼近、达不到；要提升 C 只能增大带宽或信噪比。

两定理关系（联合计算题套路）：奈氏限制码元速率（波特率上限 2W），香农限制信息速率（比特率上限 C）。信道同时受两重限制时取较小者：先算奈氏极限信息速率 $2W\log_2 V$，再算香农 $W\log_2(1+S/N)$，实际可达速率 = min(两者)。

经典例：W=4kHz、16 进制码元、信噪比 30dB。奈氏侧：2×4000×log₂16 = 8000×4 = 32kb/s；香农侧：30dB→S/N=1000，4000×log₂(1+1000) ≈ 4000×9.97 ≈ 39.9kb/s → 取 min = 32kb/s（此时奈氏是瓶颈：再增大 V 只会抬高"想用的速率"，但码元速率 2W 先到顶，瓶颈转到香农侧才有用）。

四种编码：

编码规则要点
不归零 NRZ整个码元期间电平恒定（如 1 高 0 低）最简单、最省带宽；无自同步能力（长串相同比特电平不变，时钟漂移累积）
归零 RZ每个码元中间回归零电平可自同步；带宽要求高
曼彻斯特每个比特正中间必有一次电平跳变，跳变既是时钟又承载数据自同步、无直流分量；波特率 = 2×比特率（10Mb/s 以太网 → 20M 波特，编码效率 50%）；跳变方向有两种约定（IEEE 802.3 与 G.E. Thomas 恰好相反），做题以题目给图为准
差分曼彻斯特看每个码元开始处有无跳变定数据（常见约定：有跳变=0、无跳变=1）；中间照样必跳变（只作时钟）抗传输极性接反，自同步

复用技术（各一句）：FDM 频分——所有用户同一时间占用不同频段（模拟通信）；TDM 时分——各用户轮流独占整个频带的一个时隙（按时隙划帧）；统计 TDM——按需动态分配时隙（时隙不固定），利用率高于同步 TDM，但须携带地址标识；WDM 波分——一根光纤传多个波长（光的频分复用）；CDMA 码分多址——每站分配正交的码片序列，所有站同频同时通信靠码型区分（发 1 比特=发本站码片序列，发 0=发其反相）。

宽带接入（概念级）：ADSL——电话线上用频分复用划出电话/上行/下行三个频段，下行快上行慢（不对称）；FTTx——光纤到路边/楼/户（FTTH 到户带宽最大）。

二、考点说明

计算笔试选择

  • 计算：波特率↔比特率换算、奈氏（2W 与 2W·log₂V）、香农（dB 先换倍数）、曼彻斯特波特率、奈氏+香农联合取 min——408 网络层计算题的常客。
  • 选择：编码方式特征与自同步能力判断、复用技术归属、码元/波特/比特概念辨析、奈氏与香农的适用条件。

三、示例题目（点击选项即时判分）

计算1. 某理想无噪声信道带宽 W=4kHz，采用 16 个状态的码元传输。求极限码元速率与极限信息速率。

先自己算，再展开对答案奈氏准则：极限码元速率 = 2W = 2×4000 = 8000 Baud（8000 波特）。
每码元携带 log₂16 = 4 比特 → 极限信息速率 = 8000×4 = 32kb/s。
注意：奈氏直接给出的是码元速率上限；问信息速率还要乘 log₂V。来源：408 统考高频题型（公开真题常考形式）。

计算2. 电话信道带宽 3kHz，信噪比 30dB。求该信道的极限（无差错）信息速率。

先自己算，再展开对答案第一步（dB 换倍数）：30dB = 10·lg(S/N) → lg(S/N)=3 → S/N = 10³ = 1000。
第二步代入香农：C = 3000×log₂(1+1000) = 3000×log₂1001 ≈ 3000×9.97 ≈ 29.9kb/s（估算常取 30kb/s）。
验算：log₂1024 = 10，1001 略小于 1024，故 log₂1001≈9.97 合理 ✓。来源：408 统考高频题型（公开真题常考形式）。

计算3. 传统 10Mb/s 以太网采用曼彻斯特编码。求它的波特率，以及每个码元携带的比特数。

先自己算，再展开对答案曼彻斯特每个比特分前半+后半两段电平，1 比特 = 2 个码元 → 波特率 = 2×比特率 = 20M 波特（20MBaud）。
每码元携带比特数 = 比特率/波特率 = 10M/20M = 0.5 比特/码元。
这就是"编码效率 50%"：两种电平本可 1 码元带 1 比特，曼彻斯特只用了一半。来源：408 统考高频题型（公开真题常考形式）。

计算4. 信道带宽 W=4kHz，信噪比 30dB。(1) 若采用 256 个状态的码元，实际可达到的最大信息速率是多少？(2) 此时哪条定理构成瓶颈？为什么继续增加码元状态数没有用？

先自己算，再展开对答案① 奈氏极限信息速率：2W·log₂V = 2×4000×log₂256 = 8000×8 = 64kb/s。
② 香农极限：30dB → S/N=1000，C = 4000×log₂1001 ≈ 4000×9.97 ≈ 39.9kb/s。
取较小者：实际最大 ≈ 39.9kb/s，香农定理是瓶颈。
瓶颈分析：速率上限由信道容量决定，继续增大 V 只会抬高"想用的速率"，超过 C 必然出错；此时提速率的正确手段是增大信噪比或带宽。来源：408 统考高频题型（公开真题常考形式）。

多选5. 关于数字基带传输的编码方式，下列说法正确的有（  ）

A. 曼彻斯特编码每个比特的正中间必有一次电平跳变，该跳变可用作时钟同步
B. 采用曼彻斯特编码时，波特率是比特率的 2 倍
C. 不归零制编码包含丰富的电平跳变，接收方很容易从中提取时钟信号
D. 差分曼彻斯特编码用"码元开始处有无跳变"表示数据（常见约定：有跳变为 0、无跳变为 1）
答案 ABD。曼彻斯特/差分曼彻斯特都是自同步编码，且波特率 = 2×比特率；C 恰好说反——NRZ 长串相同比特时电平长时间不变，没有自同步能力，这正是需要自同步编码或额外传时钟的原因。来源：牛客经典题。

四、易错点小结

① dB 换倍数：20dB=100、30dB=1000、3dB≈2、6dB≈4；把 10·lg 当成 lg（忘乘 10）是最常见错；② 奈氏管波特（2W）、香农管比特（C），双重限制取 min；V 只影响奈氏一侧，S/N 只影响香农一侧；③ 曼彻斯特波特率 = 2×比特率：10Mb/s → 20MBaud；"波特率"单位是 Baud，别写成 b/s；④ "0.5 比特/码元"= 编码效率 50%，与"V=2 可带 log₂2=1 比特"不矛盾——只是没用满；⑤ CDMA 同频同时靠正交码片区分，不是频分也不是时分；统计 TDM 时隙不固定、需带地址；⑥ 曼彻斯特跳变方向有两种相反约定，考研只考"中间必跳变 + 波特率翻倍"，方向看题目给的图。
