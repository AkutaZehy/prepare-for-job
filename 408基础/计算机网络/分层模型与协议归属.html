分层模型与协议归属

适用岗位：全部（笔试必考选择；面试开场必问"说说 OSI 和 TCP/IP"） ｜ 形态：对应表 + 速查表 ｜ 更新：2026-09-30
要点速记：OSI 7 层 = 物理/链路/网络/传输/会话/表示/应用，TCP/IP 4 层 = 网络接口/网际/传输/应用（教学五层折中）；设备归属：集线器-物理层、交换机-链路层（隔冲突域不隔广播域）、路由器-网络层（两者都隔）；封装 PDU：报文→报文段→分组→帧→比特；RIP 跑 UDP 520、OSPF 直接封 IP（协议号 89）、BGP 跑 TCP 179——三个路由协议三种承载；ARP 按 408 口径属网络层；FTP 控制 21 / 数据 20。

一、知识点梳理

三套模型的关系：OSI 先定模型后补协议（7 层，理论完整但繁杂，实际没人完整实现）；TCP/IP 从实践中归纳（4 层，事实标准）；教学五层（物理+链路+网络+传输+应用）是折中讲法，408 按五层组织。

OSI（7 层）教学五层TCP/IP（4 层）功能一句话
7 应用应用应用按协议为用户进程提供服务（HTTP、DNS…）
6 表示数据格式转换、加密压缩（TCP/IP 中并入应用层）
5 会话建立与管理会话（TCP/IP 中并入应用层）
4 传输传输传输端到端（进程到进程）：TCP 可靠、UDP 尽力而为
3 网络网络网际主机到主机：路由选择与分组转发（IP）
2 数据链路链路网络接口相邻节点：成帧、差错检测（以太网、PPP）
1 物理物理比特流透明传输，规定接口与介质特性

设备归属（考选择）：

设备工作层次要点
中继器、集线器（Hub）物理层只放大转发信号；集线器不隔离冲突域（所有端口同一个冲突域）
网桥、以太网交换机链路层按 MAC 地址查表转发帧；隔离冲突域、不隔离广播域（VLAN 才能隔离广播域）
路由器网络层按 IP 地址转发分组；既隔离冲突域又隔离广播域
网关高层（传输层及以上，常见应用层）做协议转换；日常说"网关"多指默认网关（路由器接口 IP），注意区分

数据封装与 PDU：发送方自上而下逐层加头（链路层还加尾），接收方自下而上解封装。各层 PDU 依次为：应用报文 → 传输层报文段（segment）→ 网络层分组/IP 数据报（packet）→ 链路层帧（frame）→ 物理层比特。反之自物理层向上就是解封装方向。

"哪个协议在哪层"速查表（408/王道口径）：

层次协议
应用HTTP、FTP、DNS、SMTP、POP3、DHCP、Telnet、SNMP、RIP（跑 UDP 520）、BGP（跑 TCP 179）
传输TCP、UDP
网络IP、ICMP、IGMP、ARP、RARP、OSPF（报文直接封装在 IP 数据报中，IP 协议号 89）
链路以太网（IEEE 802.3）、PPP、CSMA/CD
物理TCP/IP 体系在物理层没有自己的协议，只有接口标准与传输介质规范（RS-232 等）

注：ARP 的归属各教材有分歧——408/王道归网络层（个别教材归链路层），做题按题目口径。

"路由协议跑在应用层"三大易错：

路由协议层次归属承载方式
RIP（距离向量，域内）应用层封装在 UDP 报文（端口 520）中
OSPF（链路状态，域内）网络层直接封装在 IP 数据报中（IP 协议号 89）
BGP（路径向量，域间）应用层封装在 TCP 报文段（端口 179）中

二、考点说明

笔试选择面试口述

  • 选择：协议归属判断（RIP/OSPF/BGP/ARP/DHCP 是标准干扰项池）、设备与层次匹配（谁隔离冲突域/广播域）、封装顺序、端口匹配、"某功能属于哪一层"。
  • 面试口述：OSI 与 TCP/IP 的区别与联系、为什么网络层有 IP 还要 ARP/ICMP、一个 URL 请求经过哪些层哪些协议（综合串讲题）。

三、示例题目（点击选项即时判分）

多选1. 下列协议归属正确的有（  ）

A. RIP 是应用层协议，其报文封装在 UDP 数据报（端口 520）中传送
B. BGP 是应用层协议，其报文封装在 TCP 报文段（端口 179）中传送
C. ARP 是链路层协议，直接封装在以太网帧中传送
D. DHCP 是应用层协议，基于 UDP 实现，服务器使用 67 号端口
答案 ABD。C 错：408/王道口径 ARP 属网络层（个别教材归链路层，做题先认口径，考研答网络层）。A/B/D 三对：RIP-UDP520、BGP-TCP179、DHCP-UDP67 都是"路由协议/配置协议跑在应用层"的经典陷阱点。来源：408 统考高频题型（公开真题常考形式）。

单选2. 某设备收到帧后根据帧中目的 MAC 地址查表转发，能隔离冲突域，但它连接的所有端口仍处于同一个广播域。该设备是（  ）

A. 集线器
B. 网桥 / 以太网交换机
C. 路由器
D. 中继器
答案 B。按帧（MAC）转发 = 链路层设备：交换机每个端口一个冲突域（隔离冲突域）、默认所有端口同广播域（不隔离广播域）。路由器按 IP 转发且广播域也隔离（C 多了"不隔离广播域"这一条）；集线器/中继器是物理层设备，连冲突域都不隔离。来源：408 统考高频题型（公开真题常考形式）。

单选3. 主机 A 向远端主机发送数据，数据自上而下经过协议栈，正确的 PDU 封装顺序是（  ）

A. 报文 → 报文段 → 分组（IP 数据报）→ 帧 → 比特
B. 报文 → 分组 → 报文段 → 比特 → 帧
C. 帧 → 分组 → 报文段 → 报文 → 比特
D. 比特 → 帧 → 分组 → 报文段 → 报文
答案 A。发送方封装方向 = 应用 → 物理：应用层报文，传输层加 TCP/UDP 头成报文段，网络层加 IP 头成分组（IP 数据报），链路层加帧头帧尾成帧，物理层变比特。D 是接收方解封装的顺序（自下而上）；C 层次颠倒；B 报文段与分组顺序错。来源：牛客经典题。

单选4. 下列熟知端口与协议的对应关系，错误的是（  ）

A. DNS — 53
B. SMTP — 25
C. FTP 控制连接 — 20
D. HTTPS — 443
答案 C。FTP 用两个端口：控制连接 21、数据连接 20，"控制 20"张冠李戴；A、B、D 均正确。同表记忆：Telnet 23、HTTP 80、POP3 110、DHCP 67/68。来源：408 统考高频题型（公开真题常考形式）。

多选5. 关于 OSI 参考模型与 TCP/IP 模型，下列说法正确的有（  ）

A. 传输层提供端到端（进程到进程）的通信，网络层提供主机到主机的通信
B. 网络层的主要任务是在相邻节点之间传输帧并进行差错检测
C. 物理层的传输单位是比特，链路层的传输单位是帧
D. TCP/IP 模型把 OSI 的会话层、表示层功能并入网络接口层
答案 AC。B 说的是链路层职能——网络层负责路由选择与分组转发（主机到主机）；D 错：会话、表示两层的功能并入的是应用层，不是网络接口层。补充（面试口述）：OSI 是先有模型后有协议的"理论标准"，TCP/IP 是先有协议后归纳的"事实标准"。来源：面试高频改编。

四、易错点小结

① 路由协议承载三连：RIP-UDP520（应用层）、OSPF 直接封 IP 协议号 89（网络层）、BGP-TCP179（应用层），"路由协议都在网络层"是最大误区；② ARP 归网络层（408 口径），ICMP/IGMP 也封装在 IP 中、同属网络层；③ 设备口诀：集线器什么域都不隔，交换机隔冲突域不隔广播域，路由器两个都隔；④ FTP 双端口 21 控制/20 数据；DNS 主要 UDP 53（区域传送 TCP）；DHCP 服务器 67/客户端 68；⑤ PDU 五件套按"报文→报文段→分组→帧→比特"背；会话/表示层并入的是 TCP/IP 的应用层；⑥ 物理层没有 TCP/IP 协议，别把 RS-232 当成 TCP/IP 的物理层协议。
