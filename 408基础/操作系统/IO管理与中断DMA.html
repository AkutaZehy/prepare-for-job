I/O 管理与中断、DMA

适用岗位：全部（缓冲计算与中断/DMA 对比是笔试常客） ｜ 形态：概念 + 计算 ｜ 更新：2026-09-30
要点速记：三种 I/O 方式 CPU 介入程度递减——程序查询（忙等全程占 CPU）→ 中断驱动（每字一次中断）→ DMA（每块一次中断，数据设备↔内存直传不经过 CPU）；CPU 在指令周期末尾采样中断信号；单缓冲每块耗时 max(C,T)+M，双缓冲 max(C+M, T)（王道口径，做题先对题设）；SPOOLing 用磁盘当中转把独占设备（打印机）改造成共享。

一、知识点梳理

I/O 软件层次结构（从上到下）：用户层 I/O 软件 → 设备独立性软件（命名、保护、缓冲、分配）→ 设备驱动程序（操作寄存器，每类设备一个）→ 中断处理程序 → 硬件。考"一次打印请求经过哪些层"的排序题。

三种 I/O 控制方式：

方式CPU 介入数据通路中断粒度适用
程序直接控制（轮询）全程忙等测试设备状态设备 → CPU 寄存器 → 内存无中断最早的简单系统
中断驱动每传送一个字/字节中断一次，CPU 执行中断处理程序搬数据设备 → CPU → 内存每字一次低速设备（键盘）
DMA 直接存储器存取CPU 只在初始化和结束时介入，传数据由 DMA 控制器（DRU）完成设备 ↔ 内存直接，不经过 CPU每块（一批数据）一次高速块设备（磁盘）
  • CPU 在每条指令执行周期末尾采样中断请求线（中断响应时机），不是任意时刻。
  • DMA 的三种方式：停止 CPU 访存（最霸道）、周期挪用/窃取（DMA 与 CPU 交替用内存总线，最常用）、交替访问。DMA 传输结束才发一次中断通知 CPU 处理。
  • 通道：更高级的"设备处理机"，能执行通道程序，进一步解放 CPU（概念级）。

缓冲区（考试公式，先对题设口径）：设 T=输入一块到缓冲的时间、M=缓冲→工作区传送时间、C=处理时间（王道口径）：

单缓冲：每块耗时  max(C, T) + M
双缓冲：每块耗时  max(C + M, T)
循环缓冲：多个缓冲区轮转，取最大者近似
（若题面另给口径，按题面公式）

缓冲的作用：缓和 CPU 与设备速度矛盾、减少中断频率、提高二者并行度。

SPOOLing（假脱机）：用磁盘上的输入/输出井做中转，外围控制机模拟，把独占设备改造成共享设备（如共享打印机：任务先排队写入输出井）。需要磁盘与多道程序支持。

设备分配：独占设备、共享设备、虚拟设备（SPOOLing 实现的）；设备独立性软件用逻辑设备名，驱动层映射物理设备。

二、考点说明

  • 中断响应时机、中断处理流程排序。
  • SPOOLing 的本质（独占→共享）判断。
  • I/O 软件层次排序题。

三、示例题目（点击选项即时判分 / 计算题先自算）

多选1. 关于中断驱动与 DMA，正确的有（  ）

A. 中断驱动下数据要经过 CPU（设备→CPU 寄存器→内存），DMA 不需要
B. DMA 传输期间完全不需要 CPU 参与
C. 中断驱动以字为单位传、DMA 以块为单位传
D. DMA 更适合高速块设备，中断驱动适合低速设备
答案 ACD。B 错在"完全"——DMA 传输前 CPU 要初始化控制器（内存起始地址、块数），结束后 CPU 要处理中断，只是传输过程中不参与。来源：408 统考高频题型（公开真题常考形式）。

单选2. CPU 响应外部中断的时间点是（  ）

A. 一条指令执行的任何时刻
B. 一个时钟周期结束时
C. 一个总线周期结束时
D. 一条指令执行周期结束时
答案 D。CPU 在每条指令执行完毕后的周期末采样中断请求——保证一条指令的原子完成，这也是"中断保护现场"能精确恢复的前提。来源：408 统考高频题型（公开真题常考形式）。

计算3. 某块设备把一块数据输入缓冲区需 T=100μs，缓冲区到工作区传送 M=10μs，CPU 处理一块需 C=50μs。分别求单缓冲与双缓冲下系统处理一块数据的耗时。

先自己算，再展开对答案单缓冲：max(C, T) + M = max(50, 100) + 10 = 110μs（输入与处理可并行，但缓冲区要串行"腾空再装"）。双缓冲：max(C+M, T) = max(60, 100) = 100μs（两个缓冲区轮换，传送与输入不互斥，瓶颈落在输入 T）。来源：408 统考高频题型（公开真题常考形式）。

单选4. SPOOLing 技术的主要作用是（  ）

A. 提高磁盘的读写速度
B. 把共享设备改造成独占设备
C. 把独占设备改造成共享设备
D. 替代设备驱动程序
答案 C。以共享打印机为例：所有任务的打印内容先排队写入磁盘输出井，由打印进程逐一取出——物理上独占的打印机在用户视角变成"随到随用"。方向别背反（B 是反向陷阱）。来源：408 统考高频题型（公开真题常考形式）。

排序5. 用户进程发出一次系统调用"读文件"，请求自上而下会经过哪些 I/O 软件层？

先自己排，再展开对答案用户层 I/O 接口 → 设备独立性软件（把逻辑设备名映射物理设备、缓冲/分配）→ 设备驱动程序（写设备寄存器、发命令）→ 中断处理程序（完成后响应）→ 硬件。口诀"独驱中断硬"。易混点：缓冲管理在设备独立性软件层，不在驱动层。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① DMA 不是"零 CPU 成本"——初始化与结束仍需 CPU，传输中可能与 CPU 争抢内存总线（周期挪用）；② 中断驱动每字中断一次，高速设备用它会中断风暴，这正是 DMA 存在的理由；③ 缓冲公式各教材口径有差异（有的把 M 定义为工作区到用户的传送），先读题设符号表再套公式；④ 中断响应在指令周期末，"任何时刻都能响应"是经典错误选项；⑤ SPOOLing 方向是"独占→共享"，且必须有磁盘与多道程序支持。
