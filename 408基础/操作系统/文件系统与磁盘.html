文件系统与磁盘

适用岗位：全部（混合索引与磁盘调度是笔试经典计算） ｜ 形态：概念 + 计算 ｜ 更新：2026-09-30
要点速记：FCB（如 inode）= 文件控制块，目录=FCB 的有序集合，检索按文件名；混合索引最大文件 = (直接块数 + 1024 + 1024² + 1024³) × 块大小（4KB 块、4B 地址时）；位示图块号 = 字号×位长 + 位号；磁盘访问时间 = 寻道 + 旋转延迟(半圈) + 传输；寻道调度 SSTF 贪最近可能饿死远端，SCAN 电梯式单向扫、到头（或最远请求，LOOK）折返。

一、知识点梳理

文件的物理结构（分配方式）：

方式实现优点缺点
连续分配占连续盘块，FCB 记起始块号+长度支持随机访问、顺序读快扩展难、外部碎片
链接分配隐式链接：每块带下一块指针；显式=FAT 表（FAT 整表常驻内存）无外部碎片、扩展易随机访问慢（隐式要逐块找）；FAT 占内存
索引分配每文件一张索引块（块号数组）支持随机访问、易扩展小文件也要占一个索引块；大文件需链接/多层/混合索引

混合索引（UNIX 经典，必背计算）：inode 中设若干直接地址 + 一级间址 + 二级间址 + 三级间址。以块 4KB、块地址 4B（一块可存 4096/4 = 1024 个地址）、结构"10 直接 + 1 一级 + 1 二级 + 1 三级"为例：

直接:   10 块
一级间址: 1024 块        （读 1 个索引块再定位）
二级间址: 1024² = 1,048,576 块
三级间址: 1024³ = 1,073,741,824 块
最大文件 ≈ (10+1024+1024²+1024³) × 4KB ≈ 4TB
访问盘块次数（不含读数据本身）: 直接 0 次、一级 1 次、二级 2 次、三级 3 次
（考试口径通常：读数据共 1+间址层数 次访存）

小文件全走直接地址 → 访问快，这就是混合索引"兼顾大小文件"的设计动机。

位示图管理盘块：每个盘块对应一个比特（0 空闲 1 占用）。字号 i、位长 m、位号 j：块号 = i×m + j（从 0 起）；反算：字号 = 块号 ÷ m 取整、位号 = 块号 mod m。位示图大小 = 盘块数 ÷ 8 字节（4096 块 → 512B）。

磁盘结构与时间：盘面（磁头号）→ 磁道（柱面号）→ 扇区。读一块的时间 = 寻道时间（磁头移动）+ 旋转延迟（平均半圈）+ 传输时间。7200rpm → 一圈 60/7200 ≈ 8.33ms → 平均旋转延迟 ≈ 4.17ms。

磁盘调度算法（只优化寻道）：

算法规则要点
FCFS按请求顺序公平但寻道长
SSTF每次找最近请求平均短，但可能饿死远端
SCAN 电梯沿一个方向扫到磁道尽头再折返无饥饿、两端与中部响应不均
C-SCAN单向扫，到头直接回到另一端重新扫各磁道等待更均匀
LOOK/C-LOOKSCAN/C-SCAN 但只到最远请求处即折返实际系统常用

RAID 一句话：0 条带无冗余最快、1 镜像、5 分布式奇偶校验（坏一块可恢复）——概念级。

二、考点说明

计算题笔试选择

  • 混合索引最大文件字节数（必考计算：先算每索引块地址数，再逐层乘，最后 × 块大小）。
  • 给定逻辑块号判断走直接/一级/二级间址、共访存几次。
  • 位示图：块号↔（字号，位号）互算、位示图大小。
  • 磁盘调度：给请求序列求移动道数（注意 SCAN 方向题面会给）。
  • 旋转延迟/存取时间计算（7200rpm 之类的换算）。

三、示例题目（点击选项即时判分 / 计算题先自算）

计算1. UNIX 混合索引：块 4KB，块地址 4B，inode 含 10 个直接地址、1 个一级、1 个二级、1 个三级间址。求最大文件大小（估算到 TB 量级即可）。

先自己算，再展开对答案每块可存地址数 = 4096/4 = 1024。总块数 = 10 + 1024 + 1024² + 1024³ = 1,074,791,434 块。乘 4KB ≈ 4.0 TB（约 4.1×10¹² 字节）。做题先在草稿写"1024/1024²/1024³"骨架再代数字。来源：408 统考高频题型（公开真题常考形式）。

计算2. 同上结构，访问文件的逻辑块号 5000 需要几次访存（含读数据）？

先自己算，再展开对答案直接地址覆盖 0~9；一级间址覆盖 10~1033（10+1024−1）；二级间址覆盖 1034~1049609。5000 落在二级间址范围。访存 = 读二级索引块 + 读一级索引块 + 读数据块 = 3 次（若题目已把 inode 调入内存）。来源：408 统考高频题型（公开真题常考形式）。

单选3. 位示图字长 32 位、共 200 个字，磁盘块号 1000（从 0 编号）对应的字号与位号是（  ）

A. 字号 30，位号 40
B. 字号 31，位号 8
C. 字号 31，位号 40
D. 字号 32，位号 8
答案 B。块号 = 字号×32 + 位号 → 1000 ÷ 32 = 31 余 8 → 字号 31、位号 8。位示图总大小 200×32/8 = 800B。来源：408 统考高频题型（公开真题常考形式）。

计算4. 磁道 0~199，磁头当前在 53，请求队列到达顺序：98, 183, 37, 122, 14, 124, 65, 67。分别求 FCFS、SSTF、SCAN（当前向磁道增大方向、扫到 199）、LOOK（向大扫到最远请求即折返）的移动道数。

先自己算，再展开对答案FCFS：45+85+146+85+108+110+59+2 = 640。SSTF（贪最近）：53→65→67→37→14→98→122→124→183 = 12+2+30+23+84+24+2+59 = 236。SCAN：53→65→67→98→122→124→183→199→37→14 = 12+2+31+24+2+59+16+162+23 = 331。LOOK：53→65→67→98→122→124→183→37→14 = 12+2+31+24+2+59+146+23 = 299。SSTF 的危险在这题里看不出来，但它会饿死远端新请求。来源：408 统考高频题型（公开真题常考形式）。

单选5. 磁盘转速 7200rpm（转/分），忽略寻道与传输，读取任意一个随机扇区的平均旋转延迟约为（  ）

A. 8.33ms
B. 2.08ms
C. 4.17ms
D. 16.67ms
答案 C。一圈 60000ms/7200 ≈ 8.33ms，平均旋转延迟 = 半圈 ≈ 4.17ms。A 是一整圈、B 是四分之一圈——记住"平均=半圈"。来源：408 统考高频题型（公开真题常考形式）。

多选6. 关于文件物理结构与目录，正确的有（  ）

A. 连续分配支持随机访问但难以动态扩展
B. 隐式链接分配也支持高效随机访问
C. FAT 是显式链接，表常驻内存，查块无需逐块读盘
D. 引入索引结点（inode）后，目录项只保留文件名与 inode 号，目录变瘦检索更快
答案 ACD。B 错：隐式链接要顺着指针逐块读盘，随机访问慢；C 是 FAT（显式链接）的核心优势——整表常驻内存；D 是 inode 设计动机——目录项瘦身、按名检索时读盘更少。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① 混合索引每块地址数 = 块大小 ÷ 地址长度，以题设为准（1KB 块 4B 地址时是 256 不是 1024）；② 位示图编号从 0 起，公式别用成 (i+1)×m；③ SCAN 方向与"扫到尽头还是最远请求"（SCAN vs LOOK）必须按题面来，答案差很多；④ 平均旋转延迟 = 半圈；⑤ FAT 是显式链接不是索引分配——两者都支持随机访问但机制不同，选择题爱混着考。
