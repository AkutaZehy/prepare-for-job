进程与线程

适用岗位：全部（笔试选择 + 面试必问） ｜ 形态：概念 + 状态机 ｜ 更新：2026-09-30
要点速记：进程是资源分配的基本单位，线程是处理机调度的基本单位；线程私有栈/寄存器/程序计数器，共享进程的堆、全局变量、打开文件；状态图里阻塞不能直接跳到运行（必须先回到就绪等调度）；进程通信里共享内存最快但需要同步，管道是半双工；协程在用户态切换，不进内核。

一、知识点梳理

进程：程序的一次执行过程，是系统进行资源分配和保护的基本单位。PCB（进程控制块）是进程存在的唯一标志，记录：进程标识（PID）、状态、现场信息（寄存器组）、资源清单、调度信息。进程 = 程序段 + 数据段 + PCB。

五状态模型（考转换边的方向）：

创建 ──调度──→ 就绪 ──调度选中──→ 运行 ──退出──→ 终止
                ↑↖时间片到/抢占      │等待事件(P操作)
                │└────等待完成(V操作)── 阻塞
stateDiagram-v2
    direction LR
    [*] --> 创建态: new
    创建态 --> 就绪态: 启动完成
    就绪态 --> 运行态: 被调度选中
    运行态 --> 就绪态: 时间片到 / 被抢占
    运行态 --> 阻塞态: 等待事件(P操作)
    阻塞态 --> 就绪态: 事件完成(V操作唤醒)
    运行态 --> 终止态: exit
    终止态 --> [*]
  • 考法是问"某条转换边是否存在"：阻塞→运行、阻塞→终止 都不存在——阻塞的进程必须先被唤醒回就绪队列排队；运行→阻塞是进程主动行为（发起系统调用），运行→就绪是被动被剥夺 CPU。

线程：进程内的执行流。引入线程后，进程只作为资源分配单位，线程才是调度单位。同一个进程内的线程切换不引起进程切换（开销小），不同进程的线程切换开销大。

归属内容
线程私有（切换要换的现场）栈、寄存器组、程序计数器 PC、线程控制块 TCB、状态字
线程共享（同进程内）地址空间（代码段、数据段、堆）、全局变量、打开的文件表、信号量等进程资源

用户级线程 vs 内核级线程：用户级线程由用户态线程库管理，内核看不见——切换不需要进内核（快），但一个线程阻塞，整个进程都阻塞，且不能利用多核；内核级线程由内核管理，可并行占多核，切换要进内核。组合方式多对多。考点：哪种线程阻塞会拖死全进程（用户级）。

进程通信（IPC）方式对比：

方式要点特点/场景
管道内核中的缓冲区，半双工，随进程创建销毁父子/兄弟进程（匿名管道）；有名管道可用于无亲缘进程
消息队列消息链表，按类型收发有格式、可跨进程，速度一般
共享内存划出一块物理内存映射进多个进程最快，但需要信号量等同步互斥配合
信号量PV 原语，传信号不传数据同步互斥工具，也可做极简通信
socket网络/本机通信统一接口跨机器也能用，最通用

协程：用户态实现的"轻量线程"，调度与切换在用户态完成，不进内核、不占多线程开销，一个线程内可跑成千上万个协程；遇到真 IO 阻塞时整个线程会卡住，所以适合 IO 密集场景（Python asyncio、Go goroutine 是运行时调度）。考点与 Python 岗的 GIL 问题联动。

二、考点说明

笔试选择计算面试必问

  • 状态转换边方向的判断题（408 每年常客）：给一条转换问可能不可能，给事件问转到哪个状态。
  • 线程共享/私有的判断（多选重灾区）：记住"栈和寄存器一定私有"。
  • 通信方式特点匹配：最快的（共享内存）、半双工的（管道）、可跨网络的（socket）。
  • 计算类：单核 n 个进程运行态的最大/最小个数。
  • 面试：进程 vs 线程区别（背资源分配/调度单位+共享私有+开销三条就够），什么时候用多进程（隔离性、崩溃不影响）什么时候多线程（共享数据、切换轻），协程适用场景（Python/Go 岗必问）。

三、示例题目（点击选项即时判分）

单选1. 下列进程状态转换中，不可能发生的是（  ）

A. 运行 → 就绪
B. 运行 → 阻塞
C. 阻塞 → 就绪
D. 阻塞 → 运行
答案 D。阻塞进程被唤醒后进入就绪队列，必须等调度程序选中才能运行，不存在阻塞直接跳运行。同理"阻塞→终止"也不存在。来源：408 统考高频题型（公开真题常考形式）。

多选2. 同一进程内的多个线程共享的资源有（  ）

A. 各自的栈空间
B. 堆内存
C. 全局变量
D. 打开的文件描述符表
答案 BCD。栈、寄存器组、程序计数器是线程私有的；堆、全局变量、打开文件表属于进程级资源，同进程线程共享——这也是"多线程改共享变量要加锁"的原因。来源：408 统考高频题型（公开真题常考形式）。

单选3. 关于管道（pipe）通信，正确的是（  ）

A. 匿名管道是半双工的，数据单向流动，要双向需建两根管道
B. 管道中的数据可以随机访问
C. 匿名管道可用于任意两个无亲缘关系的进程
D. 管道的容量是无限的，写进程永远不必等待
答案 A。匿名管道半双工、先进先出且只能顺序读，写满后写者阻塞；它通过 fork 继承打开的文件描述符使用，所以限父子/兄弟进程（有名管道 FIFO 才能跨亲缘）。来源：408 统考高频题型（公开真题常考形式）。

计算4. 单处理机系统中有 5 个进程（不含空闲态），处于运行态的进程最多几个？最少几个？

先自己算，再展开对答案最多 1 个——单处理机同一时刻只能有一个进程在 CPU 上运行。最少 0 个——5 个进程可以全部处于阻塞态（都在等 I/O），此时 CPU 空闲。前提"不含空闲态"是排除干扰的题眼。来源：408 统考高频题型（公开真题常考形式）。

面试口述5. 进程和线程的区别？什么时候选多进程、什么时候选多线程？

参考回答三层说：①本质——进程是资源分配的基本单位，线程是调度执行的基本单位；②共享与隔离——同进程线程共享地址空间和资源（通信免费但要加锁），进程间地址空间独立（隔离性好，一个崩不影响别的）；③开销——线程切换只换栈和寄存器现场，进程切换还要换页表/地址空间并使 Cache 失效，开销大得多。选型：要共享大量数据、追求轻量并发→多线程；要隔离与稳定（如 Chrome 多进程）、或绕过 GIL→多进程。加分点：提到协程做 IO 密集的高并发（用户态切换不进内核）。

四、易错点小结

① "线程共享地址空间"指的是代码段/数据段/堆，栈不共享；② 运行→阻塞是主动行为，就绪→阻塞不可能（就绪进程没在 CPU 上执行，无从发起等待）；③ PCB 是进程存在的唯一标志，创建进程实质是建 PCB；④ 用户级线程一个阻塞全进程阻塞，是它相对内核级线程的核心缺点；⑤ 共享内存"快"的前提是配好同步互斥，否则读到的就是脏数据——面试常顺着追问。
