内存管理与页面置换

适用岗位：全部（地址转换与置换手算是笔试计算重灾区） ｜ 形态：概念 + 计算 ｜ 更新：2026-09-30
要点速记：页大小决定页内偏移位数（4KB=12 位），页号位数 = 逻辑地址位数 − 偏移位数；只有 FIFO 有 Belady 异常（帧数变多缺页反而变多），LRU/OPT 是堆栈类算法没有；OPT 是缺页下界但无法实现；抖动 = 页面频繁换入换出，根因是分配帧数少于工作集；有效访问时间 EAT = 命中率×快路径 + 未命中率×慢路径。

一、知识点梳理

连续分配的三种动态分区适配算法：

算法策略特点
首次适应 First Fit从低地址找第一个放得下的分区简单、综合性能最好（低地址优先被用，高地址留大块）
最佳适应 Best Fit找容量最接近需求的分区省空间但产生大量难以利用的外部碎片小分区
最坏适应 Worst Fit每次挑最大的分区剩余大块仍可用，但大作业后患无穷

分页存储：物理内存划成等大的帧（页框），逻辑地址空间划成等大的页，页与帧同大小（常见 4KB）。逻辑地址 = 页号 P + 页内偏移 W：页号 = 逻辑地址 ÷ 页大小（取商），偏移 = 取余；偏移位数只由页大小决定（4KB→12 位，1KB→10 位）。地址转换：页号查页表得物理帧号，帧号×页大小 + 偏移。页表本身放在内存，32 位系统 4KB 页单级页表要 4MB/进程——太大，于是引入二级/多级页表（页表也分页，可离散存放、部分换出），代价是缺页表时要多次访存。

快表 TLB：高速缓存里的"页表项缓存"。命中时：查 TLB(t) + 访存(m)；未命中：查 TLB + 查页表访存 + 再访存 = t + 2m（题设通常如此，看清题目是否计入）。EAT = H×(t+m) + (1−H)×(t+2m)。

页面置换算法（给访问串和帧数，手算缺页次数是必考计算）：

算法淘汰谁要点
OPT 最佳以后最长时间不再使用的页缺页率下界，无法实现（要预知未来），用作评价基准
FIFO 先进先出最早进入内存的页实现最简单；唯一有 Belady 异常（帧数增多缺页可能反而增多）
LRU 最近最久未使用最久未被访问的页堆栈类算法，无 Belady；硬件开销大（要记访问时间戳/栈）
Clock / NRU循环扫描，淘汰访问位为 0 的页访问位 1 清 0 跳过、遇到 0 淘汰——"二次机会"，LRU 的低成本近似

抖动（颠簸）：页面频繁换入换出，CPU 大部分时间在做换页。根因：分配的帧数 < 该进程的工作集（一段时间内实际活跃访问的页面集合）。对策：按工作集分配帧、降低多道程序度。缺页时缺页中断属于内中断（故障），在指令执行期间产生并被处理。

分段 vs 分页：分页是一维地址（物理划分、页大小固定、对用户透明，有内部碎片）；分段是二维地址（按逻辑意义划分、段长可变，便于共享保护，有外部碎片）；段页式=先分段再分页，取长补短。

二、考点说明

笔试选择计算题

  • 地址转换计算（给页大小与逻辑地址求页号/偏移/物理地址）——纯套公式但要快且准。
  • 置换手算：给访问串与帧数，分别求 FIFO/LRU/OPT 的缺页次数；或给缺页次数反推算法。
  • Belady 异常、抖动根因、Clock 算法访问位的动作。
  • EAT 计算（快表命中率题），看清题设的访存次数约定。
  • 动态分区三种适配的匹配题。

三、示例题目（点击选项即时判分）

计算1. 页大小为 4KB，逻辑地址 8645（十进制）对应的页号与页内偏移是（  ）

A. 页号 1，偏移 4549
B. 页号 2，偏移 353
C. 页号 2，偏移 453
D. 页号 2，偏移 553
答案 C。4096×2 = 8192 ≤ 8645 < 4096×3 = 12288，页号 2；偏移 = 8645 − 8192 = 453。快速法：4KB=2¹²，8645 = 10000110000101₂，低 12 位是偏移 453，其余是页号 2。来源：408 统考高频题型（公开真题常考形式）。

计算2. 访问串 1,2,3,4,1,2,5,1,2,3,4,5，内存 3 帧（初始为空，FIFO 置换）。求缺页次数；若帧数增到 4 帧呢？（教材经典序列）

先自己算，再展开对答案3 帧 FIFO：缺页 9 次。轨迹：1缺 2缺 3缺 → 4淘汰1缺 → 1淘汰2缺 → 2淘汰3缺 → 5淘汰4缺 → 1命中 2命中 → 3淘汰5缺 → 4淘汰1缺 → 5淘汰2缺（共 9）。4 帧时反而缺 10 次——帧数变多缺页变多，这就是 Belady 异常（同串 LRU 3 帧 10 次、4 帧 8 次，OPT 3 帧 7 次）。来源：408 统考高频题型（公开真题常考形式）。

单选3. 关于页面置换算法，正确的是（  ）

A. LRU 算法可能出现 Belady 异常
B. OPT 缺页次数最少但需要预知未来访问序列，无法实际实现
C. Clock 算法淘汰访问位为 1 的页
D. FIFO 是堆栈类算法，不会出现 Belady 异常
答案 B。Belady 异常是 FIFO 专属（LRU/OPT 是堆栈类算法）；Clock 淘汰的是访问位为 0 的页（遇到 1 就清 0 跳过，给第二次机会）；D 的"堆栈类"说反了，FIFO 恰恰不是堆栈类。来源：408 统考高频题型（公开真题常考形式）。

计算4. 某系统 TLB 访问 20ns，内存访问 100ns，TLB 命中率 90%。TLB 命中时"查 TLB+访存"一步完成，未命中时"查 TLB+查页表+访存"。求有效访问时间 EAT。

先自己算，再展开对答案命中路径：20 + 100 = 120ns；未命中路径：20 + 100（查页表）+ 100（取数）= 220ns。EAT = 0.9×120 + 0.1×220 = 108 + 22 = 130ns。注意：不同教材对未命中是否要"查 TLB"计一次有出入，按题目给定的路径算，先读清题设再动笔。来源：408 统考高频题型（公开真题常考形式）。

多选5. 关于内存管理，正确的有（  ）

A. 最佳适应算法容易产生大量难以利用的外部碎片
B. 分页管理会产生内部碎片（最后一页装不满）
C. 抖动的常见根因是分配的帧数少于进程的工作集
D. 分段管理的地址是一维的，与分页相同
答案 ABC。D 错：分段是二维地址（段号+段内偏移，段长可变），分页才是一维；分段有外部碎片、分页有内部碎片，段页式两者兼而有之。来源：408 统考高频题型（公开真题常考形式）。

四、易错点小结

① 页内偏移位数只看页大小（4KB→12 位），与总地址位数无关；页号位数 = 总位数 − 偏移位数；② 缺页次数统计惯例：首次装入也算缺页（初始为空时必缺），做题先对答案口径；③ 只有 FIFO 有 Belady 异常，"LRU 也可能"是常见干扰项；④ 银行家/置换/EAT 计算题先读题设约定（是否算查 TLB 一次、是否计入初始装入），再套公式；⑤ 二级页表的动机是"页表太大且必须连续存放"，不是加速——加速靠 TLB。
