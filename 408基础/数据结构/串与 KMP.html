串与 KMP

适用岗位：全部（408 选择 + 手算 next 大题高频） ｜ 形态：手算表格 + 算法对比 ｜ 更新：2026-09-30
要点速记：朴素匹配失配时主串指针 i 回退，最坏 (n−m+1)×m ≈ O(nm)；KMP 失配时 i 不动，j 跳到 next[j]，整体 O(n+m)；next 只由模式串决定，手算口诀：next[1]=0、next[2]=1，next[j] = 模式串前 j−1 个字符的最长相等前后缀长度 + 1；nextval 一句话：若 p[j] == p[next[j]]，则 nextval[j] = nextval[next[j]]，把无效跳转改得更彻底。

一、知识点梳理

串的存储（一句带过，考得少）：定长顺序存储（静态数组，超长截断）、堆分配存储（运行时按实际长度申请，主流）、块链存储（每结点存 1 个或若干个字符，指针开销大、存储密度低）。

朴素模式匹配（BF）：主串指针 i、模式串指针 j 从头逐位比；失配则 i 回退到本趟起点的下一位（i = i−j+2，按 1 起编），j 回到 1，重比。最坏情形：模式串形如"aa…ab"、主串全 a，每趟都比较到第 m 个字符才失败，共 (n−m+1)×m 次，时间 O(n×m)。

next 数组（408 教材约定）：next[j] 描述"在 p[j] 处失配后 j 该跳到哪"。定义：next[1] = 0、next[2] = 1；对 j 大于 2，next[j] = 模式串前 j−1 个字符构成子串的"最长相等前后缀"长度 + 1。"相等前后缀"指：存在 k，使前 k 个字符与后 k 个字符完全相同（k 可为 0，即不存在）。手算就用"逐位看前串"的表格法，见本页例题 1。注意工程实现里常直接存"最长相等前后缀长度"（即教材值减 1），两种约定差 1，做题先认约定。

KMP 匹配过程：失配时 i 永不回退，j = next[j]；j = 0 是特殊信号——i、j 同步加 1（主串当前位作废，从下一位重新开始）。预处理求 next 花 O(m)，匹配最多 O(n)，总时间 O(n+m)。

j = 6 失配 ──(next=3)──→ j = 3 ──(next=1)──→ j = 1 ──(next=0)──→ j = 0
                                                  j = 0 时 i 前进一格, j 从 1 重开
主串 i 全程不回退: 已匹配信息被 next 完整复用

nextval（一句带过）：在 next 基础上修正"跳过去要比的字符还是同一个"的浪费——若 p[j] == p[next[j]]，则 nextval[j] = nextval[next[j]]，否则 nextval[j] = next[j]。失配时 j 直接跳到 nextval[j]，一次到位。

// 朴素匹配 BF：失配整体回退，i 回到本趟起点的下一位
static int bf(String s, String p) {
    int i = 1, j = 1;                          // 按 1 起编的思想, charAt 里减 1
    while (i <= s.length() && j <= p.length()) {
        if (s.charAt(i - 1) == p.charAt(j - 1)) { i++; j++; }
        else { i = i - j + 2; j = 1; }         // 关键: 主串指针回退
    }
    return j > p.length() ? i - p.length() : -1;
}

// KMP：求 next（408 约定 next[1]=0），再主串只进不退
static int[] getNext(String p) {
    int m = p.length();
    int[] next = new int[m + 1];   // 下标 0 弃用
    next[1] = 0;
    int i = 1, j = 0;              // i: 算到第几位, j: 当前最长相等前后缀长度
    while (i < m) {
        if (j == 0 || p.charAt(i - 1) == p.charAt(j - 1)) {
            i++; j++;
            next[i] = j;           // 前后缀延长一位, next 加 1
        } else {
            j = next[j];           // 前缀自己跟自己匹配, 回退 j
        }
    }
    return next;                   // getNext("abaabc") = [_,0,1,1,2,2,3]
}

static int kmp(String s, String p) {
    int[] next = getNext(p);
    int i = 1, j = 1;
    while (i <= s.length() && j <= p.length()) {
        if (j == 0 || s.charAt(i - 1) == p.charAt(j - 1)) { i++; j++; }
        else j = next[j];          // 主串指针不回退
    }
    return j > p.length() ? i - p.length() : -1;   // 首次出现位置(1 起)
}
def get_next(p):
    m = len(p)
    nxt = [0] * (m + 1)            # 下标 0 弃用, nxt[1] = 0
    i, j = 1, 0
    while i < m:
        if j == 0 or p[i - 1] == p[j - 1]:
            i, j = i + 1, j + 1
            nxt[i] = j
        else:
            j = nxt[j]
    return nxt                     # "abaabc" -> [0,0,1,1,2,2,3]

二、考点说明

笔试选择手算大题面试口述

  • 选择：失配后 i、j 的行为、next/nextval 的性质与依赖关系、KMP 与 BF 的时间复杂度对比。
  • 手算：给模式串求 next 数组（要求写步骤表，408 大题常客）、朴素匹配比较次数。
  • 面试口述：next[j] 的含义、KMP 为什么快（用"已匹配信息复用"来讲，别背定义）。

三、示例题目（选择题点击选项即时判分）

计算1. 求模式串 p = "abaabc" 的 next 数组（408 约定），要求写出完整的手算步骤表。

先自己算，再展开对答案逐位填表：对每个 j，看前 j−1 个字符构成的子串，找它的"最长相等前后缀"长度 L，则 next[j] = L + 1（j=1、2 直接按规定写 0、1）。
j123456
p[j]abaabc
前串 p[1..j−1]—aababaabaaabaab
最长相等前后缀—无无aaab
长度 L—00112
next[j] = L+1011223
即 next = 0 1 1 2 2 3。易错点：j=5 时前串是 abaa，只有前后缀 "a" 相等（"ab" 与 "aa" 不等），别顺手写成 3。来源：408 统考高频题型（公开真题常考形式）。

计算2. 用朴素匹配在主串 S = "aaaaab"（n=6）中找模式串 T = "aab"（m=3），共进行多少次字符比较？归纳出最坏情况的比较次数公式。

先自己算，再展开对答案逐趟数：
趟 1：从 S[1] 起，a=a、a=a、a≠b → 3 次失败；
趟 2：从 S[2] 起，a=a、a=a、a≠b → 3 次失败；
趟 3：从 S[3] 起，a=a、a=a、a≠b → 3 次失败；
趟 4：从 S[4] 起，a=a、a=a、b=b → 3 次成功。
合计 4 × 3 = 12 次。规律：最坏时每趟都比较满 m 次，共 n−m+1 趟，公式 (n−m+1) × m，验证 (6−3+1)×3 = 12 ✓。来源：牛客经典题。

单选3. KMP 匹配过程中，若在模式串第 j 个字符处失配，接下来算法的行为是（  ）

A. 主串指针 i 回退到本趟比较的起点
B. 模式串指针 j 直接回到 1，从头重新比较
C. i 和 j 同时回退一格
D. i 不动，j 回退到 next[j]（j 为 0 时 i、j 同步加 1）
答案 D。"主串指针不回退"是 KMP 的全部意义所在：已匹配的那段主串信息由 next 数组完整复用，失配后模式串滑到能对齐的最长前缀处继续比。j=0 表示模式串第一位就对不上，i、j 一起前进一位重开。来源：408 统考高频题型（公开真题常考形式）。

多选4. 关于 KMP 算法，下列说法正确的有（  ）

A. 匹配阶段主串指针不回退，一遍扫完，总时间 O(n+m)
B. 任何输入下，KMP 的字符比较次数都一定比朴素匹配少
C. next 数组只由模式串本身决定，与主串无关
D. nextval 是对 next 的改进：消除"跳过去仍遇到相同字符"的无效比较
答案 ACD。B 错：KMP 要先花 O(m) 预处理 next，模式串很短或运气好时朴素匹配可能更少；KMP 的优势是保证最坏 O(n+m)，而非"每一次都更少"。C 是常考性质：求 next 的过程是模式串前缀自己匹配自己，主串换一万次 next 都不变。来源：面试高频改编。

面试口述5. 用两三句话讲清 next[j] 的含义，以及失配时为什么 j 跳到 next[j] 是安全的。

参考回答next[j] 的含义：模式串前 j−1 个字符中"最长相等前后缀"的长度加 1（next[1]=0、next[2]=1 是规定）。失配发生在 p[j] 时，说明前 j−1 个字符已经和主串对上；这段串的长度为 next[j]−1 的前缀与它自己的后缀相等，于是主串里已匹配部分的后缀天然等于模式串同长的前缀，直接把模式串滑到这个前缀对齐，从 p[next[j]] 继续比即可——i 不用动，也不会漏解，因为更长的对齐方式都被"最长相等前后缀"排除掉了。加分点：提 nextval 进一步修正、KMP 最坏 O(n+m)。来源：面试高频改编。

四、易错点小结

① next 有两套约定（教材"长度+1"版 vs 工程存长度版），值差 1，做题先看清题目用哪种；② next[1]=0、next[2]=1 是规定不是推的；③ 手算 next 只看模式串，主串再长也无关；④ KMP 失配 i 不动、j 跳 next[j]，j=0 时 i、j 同步 +1；⑤ 朴素匹配最坏 (n−m+1)×m 趟内比较，别记成 n×m 就完事，具体次数要会逐趟数；⑥ nextval 修正规则只在 p[j] == p[next[j]] 时才改。
