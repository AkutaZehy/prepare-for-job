图的存储与遍历

适用岗位：全部（笔试选择 + 手算遍历序列） ｜ 形态：结构对比 + DFS/BFS 手算 ｜ 更新：2026-09-30
要点速记：邻接矩阵 O(n²)、判边 O(1)、适合稠密图（无向图对称，行非零元数 = 度）；邻接表 O(n+e)、适合稀疏图（有向图链长得出度，入度要逆邻接表）。DFS 走到底再回退（递归栈），BFS 按层扩散（队列，无权图首达即最短跳数）；邻接表遍历 O(n+e)、矩阵 O(n²)。非连通图调用遍历的次数 = 连通分量个数，连通图一次遍历得 n−1 条边的生成树。

一、知识点梳理

邻接矩阵 vs 邻接表：

维度邻接矩阵邻接表
空间O(n²)，与边数无关O(n+e)
判边 (u,v)O(1)，直接查矩阵元素O(度(u))，要扫 u 的邻接链
求度（无向）第 i 行（列）非零元个数 = 顶点 i 的度边结点个数 = 度（一条边存两份）
出度/入度（有向）第 i 行非零元 = 出度，第 i 列 = 入度链长 = 出度好求；入度要遍历全表或建逆邻接表（每条边反向再存一份）
适合稠密图（e 接近 n²）稀疏图（e 远小于 n²）

DFS（深度优先）：类似树的先根遍历——访问 u 后挑一个未访问的邻接点扎进去，走不动了自动回退换路；实现用递归（系统栈）或显式栈。BFS（广度优先）：访问 s 后把未访问邻接点依次入队，出队时同样处理；按"离起点的跳数"分层扩散，所以无权图里 BFS 首次到达某点走过的跳数就是最短跳数。两者时间复杂度：邻接表 O(n+e)，邻接矩阵 O(n²)（每个顶点要扫一整行找邻接点）。

连通分量与生成树：连通图一次遍历就能访问全部 n 个顶点，走过的 n−1 条边构成生成树（DFS 生成树与 BFS 生成树形态不同，边数都是 n−1）；非连通图要对每个未访问顶点各调一次遍历，实际启动的次数 = 连通分量个数，所有分量的生成树合起来是生成森林。

并查集（两行带过）：用"双亲数组"维护若干棵树，find(x) 沿双亲找到集合代表元（根），union(a,b) 把两棵树并成一棵；配上路径压缩 + 按秩合并，单次操作近似 O(1)。无向图判连通、Kruskal 判环都靠它（见最小生成树一页）。

import java.util.*;

// 邻接表: adj.get(u) 是 u 的邻居列表(按序号升序存, 遍历序列才唯一)
static boolean[] vis = new boolean[N];

// DFS: 递归栈. 能深入就深入, 走不动自动回退
static void dfs(int u, List<List<Integer>> adj, List<Integer> order) {
    vis[u] = true;
    order.add(u);
    for (int v : adj.get(u))
        if (!vis[v]) dfs(v, adj, order);
}

// BFS: 队列. 出队时把未访问邻居依次入队, 按层扩散
static void bfs(int s, List<List<Integer>> adj, boolean[] vis, List<Integer> order) {
    Queue<Integer> qe = new ArrayDeque<>();
    vis[s] = true;
    qe.offer(s);
    while (!qe.isEmpty()) {
        int u = qe.poll();
        order.add(u);
        for (int v : adj.get(u))
            if (!vis[v]) { vis[v] = true; qe.offer(v); }
    }
}
def dfs(u, adj, vis, order):
    vis[u] = True
    order.append(u)
    for v in adj[u]:
        if not vis[v]:
            dfs(v, adj, vis, order)

from collections import deque
def bfs(s, adj, vis, order):
    qe = deque([s]); vis[s] = True
    while qe:
        u = qe.popleft(); order.append(u)
        for v in adj[u]:
            if not vis[v]:
                vis[v] = True; qe.append(v)

三、示例题目（选择题点击选项即时判分）

单选1. 对本页知识点中的 6 顶点无向图（邻接表中邻接点按序号升序），从 v1 出发进行 DFS，得到的访问序列是（  ）

A. v1，v2，v3，v4，v5，v6
B. v1，v2，v5，v6，v4，v3
C. v1，v2，v4，v6，v5，v3
D. v1，v3，v5，v6，v4，v2
答案 C。DFS 是"能深就深"：v1 的最小未访问邻接点是 v2 → v2 的是 v4（v1 已访问）→ v4 的是 v6 → v6 的是 v5 → v5 剩下 v3 → v3 的邻接点全访问过，逐层回退。A 是 BFS 的味道（按层选点），D 是第一步就选了 v3。来源：408 统考高频题型（公开真题常考形式）。

计算2. 对同一张图从 v1 出发进行 BFS：① 写出访问序列；② 列出队列演化的每一步；③ 给出 v1 到各顶点的最短跳数。

先自己算，再展开对答案① 序列：v1，v2，v3，v4，v5，v6。② 队列演化（出队即访问）：出 v1 → 入 v2、v3；出 v2 → 入 v4、v5；出 v3 →（无新点）；出 v4 → 入 v6；出 v5、出 v6。③ 跳数表：
顶点v1v2v3v4v5v6
最短跳数011223
v6 的邻居 v4、v5 都在第 2 层，所以 v6 在第 3 层——无权图 BFS 首达即最短。来源：牛客经典题。

多选3. 关于图的邻接矩阵存储，下列说法正确的有（  ）

A. 无向图的邻接矩阵是对称矩阵，可只存上三角压缩空间
B. 无向图的边数等于邻接矩阵中非零元素的个数
C. 无向图邻接矩阵第 i 行（或第 i 列）非零元素的个数等于顶点 i 的度
D. 有向图邻接矩阵中，第 i 行非零元个数是 i 的出度，第 j 列非零元个数是 j 的入度
答案 ACD。B 错：无向图每条边在对称位置贡献两个非零元，边数 = 非零元个数 ÷ 2（这是选择题的经典陷阱）。D 是"行出列入"口诀。邻接矩阵空间 O(n²) 与边数无关，稠密图才划算。来源：面试高频改编。

计算4. 某无向非连通图有 10 个顶点、3 个连通分量。① 从每个顶点出发各调用一次 DFS（已访问的顶点调用直接返回），真正"新启动"的遍历共几次？② 得到的生成森林共有几条边？

先自己算，再展开对答案① 每次新启动的 DFS 恰好访问其出发顶点所在连通分量的全部顶点，之后同分量的调用都被"已访问"挡住，所以新启动次数 = 连通分量数 = 3 次（另外 7 次调用直接空手而归）。② 每个分量的生成树边数 = 分量顶点数 − 1，求和 = 10 − 3 = 7 条。通式：n 个顶点 k 个分量，森林边数 = n − k。来源：408 统考高频题型（公开真题常考形式）。

面试口述5. DFS 和 BFS 的时间复杂度相同，空间复杂度也都是 O(n)，但两者的 O(n) 来源不同——说说差在哪。

参考回答DFS 的空间在栈（递归栈）：同一时刻栈里存的是"从起点到当前点的一条路径"，大小取决于图的深度，最坏是一条长链，栈深 O(n)；一条细长路径的图 DFS 只用很小的栈。BFS 的空间在队列：同一时刻队列里存的是"同一层及下一层的顶点"，大小取决于最宽一层的宽度，星形图/完全图一层就能有 O(n) 个顶点同时入队。一句话：DFS 吃深度，BFS 吃宽度，时间同为邻接表 O(n+e)、矩阵 O(n²)。来源：面试高频改编。

四、易错点小结

① 遍历序列只有在"邻接点顺序"确定后才唯一，题目没给顺序要先按序号升序处理；② 非连通图遍历新启动次数 = 分量数，不是 n；③ BFS 求的是"跳数"最短，只对无权图成立，带权图要找 Dijkstra；④ 无向图邻接表一条边存两个边结点，空间按 2e 算；⑤ 有向图邻接表表头链长给出度、给不出入度，入度靠逆邻接表或全表扫描；⑥ 矩阵判边 O(1) 但找邻接点要扫整行，复杂度别记混。
