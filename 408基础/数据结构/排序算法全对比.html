排序算法全对比

适用岗位：全部（笔试选择题必考 + 机试手写） ｜ 形态：知识点 + 计算 ｜ 更新：2026-09-30
要点速记：不稳定口诀"快些选堆"（快速/希尔/选择/堆排）；快排一趟只保证枢轴归位；建堆 O(n)、调整一次 O(log n)；Top-K 用大小为 k 的堆 O(n log k)；m 段 k 路归并趟数 ⌈logkm⌉。

一、知识点梳理

稳定性：排序后相等元素的相对次序与排序前相同则称稳定。稳定有什么用？多关键字排序——先按低关键字稳定排，再按高关键字排，低关键字次序得以保留（基数排序的原理）。

算法平均时间最坏最好空间稳定一句话要点
直接插入O(n²)O(n²)O(n)（基本有序）O(1)稳基本有序或规模小时最快之一
冒泡O(n²)O(n²)O(n)（可提前终止）O(1)稳每趟冒出一个极值
简单选择O(n²)O(n²)O(n²)O(1)不稳比较次数固定 n(n-1)/2，与初始状态无关
希尔≈O(n1.3)O(n²)—O(1)不稳分组插入，步长序列影响复杂度
快速O(n log n)O(n²)（基本有序时退化）O(n log n)O(log n) 递归栈不稳平均性能之王；枢轴每趟归位一个
堆排O(n log n)O(n log n)O(n log n)O(1)不稳建堆 O(n)，每次调整 O(log n)
归并O(n log n)O(n log n)O(n log n)O(n)稳m 个有序段归并趟数 = ⌈log₂m⌉
基数O(d(n+r))O(d(n+r))O(d(n+r))O(r)稳d 位数、r 基数；不比较关键字
  • 堆：n 个元素建大根堆从 ⌊n/2⌋ 号结点开始向下调整，建堆总代价 O(n)；删除堆顶后"末尾换顶再下调"一次 O(log n)。
  • 快排：每趟至少一个元素（枢轴）放到最终位置；基本有序时取首元素为枢轴退化为 O(n²)——改进：三者取中、随机枢轴。
  • 归并：对 m 个初始有序段做 k 路归并，趟数 s=⌈logkm⌉；外部排序多路归并考点同源。
  • Top-K 选型：n 个数里取最大 k 个，维护 k 大小的（小根）堆，O(n log k)，优于全排序。
  • 工程提醒：Java Arrays.sort 基本类型用双枢轴快排（不稳），对象用 TimSort（归并+插入，稳定）；Python sorted 是 TimSort，稳定。

二、考点说明

笔试选择计算题机试手写面试口述

  • 给一串初始序列，问一趟排序后的结果（快排/冒泡/选择/插入各来一遍；反过来"看一趟结果辨认排序"也是经典出题法）。
  • 复杂度与初始序列是否相关：插入/冒泡与初始有关，选择/归并/堆排的比较次数与初始无关。
  • 计算类：建堆过程写堆、第一次交换、比较次数、归并趟数、基数排序"分配-收集"趟数。
  • 机试：快排/归并/堆排要求独立手写（完整 ACM 模板见「算法编程题」各专题）。
  • 面试："快排为什么快""稳定有什么用""Top-K 为什么用堆不用全排序"。

三、示例题目（点击选项即时判分）

单选1. 下列排序方法中，不稳定的一组是（  ）

A. 直接插入排序、冒泡排序
B. 快速排序、堆排序
C. 归并排序、基数排序
D. 直接插入排序、希尔排序
答案 B。口诀"快些选堆"：快（快速）、些（希尔）、选（简单选择）、堆（堆排）不稳定；其余插入/冒泡/归并/基数均稳定。来源：408 统考高频题型（公开真题常考形式）。

单选2. 对初始序列 {49, 38, 65, 97, 76, 13, 27, 49} 做一趟快速排序（以第一个元素 49 为枢轴），一趟结束后序列为（  ）

A. {27, 38, 13, 49, 76, 97, 65, 49}
B. {13, 27, 38, 49, 65, 76, 97, 49}
C. {49, 38, 13, 27, 76, 97, 65, 49}
D. {27, 38, 65, 13, 49, 97, 76, 49}
答案 A。经典教材例题（408 高频改编）。挖坑法：high 从右找比 49 小的 27 填坑，low 从左找比 49 大的 65 填坑……最终枢轴落在下标 3，左边 {27,38,13} 全小于 49，右边 {76,97,65,49} 全不小于 49。注意快排一趟只保证枢轴归位，B 是最终有序结果，属典型干扰项。

计算3. 将序列 {4, 9, 3, 7, 1, 6} 调整为大根堆（写出数组形态），并写出删除堆顶 9 后（末尾元素补顶、再下调）一次调整后的数组。

先自己算，再展开对答案建堆：从 ⌊6/2⌋=3 号（值 7）开始下调，再处理 2 号（3）、1 号（4）。结果（1 起始下标）：{9, 7, 6, 4, 1, 3}。删 9：末尾 3 换到顶 → {3,7,6,4,1}，与较大孩子 7 交换 → {7,3,6,4,1}，3 再与 4 交换 → {7, 4, 6, 3, 1}。来源：408 统考计算题常考形式（改编）。

单选4. 从 10000 个数中选出最大的 10 个，最合适的算法是（  ）

A. 全部快速排序后取前 10
B. 维护一个 10 大小的最小堆，扫描一遍
C. 简单选择排序跑 10 趟
D. 归并排序后取前 10
答案 B。k 大小的最小堆：新元素比堆顶大就替换并下调，总代价 O(n log k) ≈ 10⁴ 量级，空间 O(k)。A/D 是 O(n log n) 全排序，C 是 O(kn)，都更慢。来源：笔试经典题型（牛客高频）。

计算5. 对 1000 个彼此无序的元素做二路归并排序需要多少趟？若是 8 个长度为 25 的有序段做四路归并呢？

先自己算，再展开对答案趟数 = ⌈logkm⌉。二路归并 1000 段：⌈log₂1000⌉ = 10 趟。8 段四路归并：⌈log₄8⌉ = 2 趟（8→2→1）。来源：408 统考计算题常考形式。

四、手撕模板：快速排序（Java / Python）

Java 
// 挖坑法，平均 O(n log n)，原地
public static void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = a[lo], i = lo, j = hi;
    while (i < j) {
        while (i < j && a[j] >= pivot) j--;   // 从右找小的
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;   // 从左找大的
        a[j] = a[i];
    }
    a[i] = pivot;                              // 枢轴归位
    quickSort(a, lo, i - 1);
    quickSort(a, i + 1, hi);
}
Python 
def quick_sort(a, lo, hi):
    if lo >= hi:
        return
    pivot, i, j = a[lo], lo, hi
    while i < j:
        while i < j and a[j] >= pivot: j -= 1
        a[i] = a[j]
        while i < j and a[i] <= pivot: i += 1
        a[j] = a[i]
    a[i] = pivot
    quick_sort(a, lo, i - 1)
    quick_sort(a, i + 1, hi)
易错点：① 循环条件里 >=/<= 少写等号，大量重复元素时死循环；② ACM 场景用内置排序不丢分，手撕多出现在面试白板；③ Python 递归深时注意 sys.setrecursionlimit。
