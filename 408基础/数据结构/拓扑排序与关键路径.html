拓扑排序与关键路径

适用岗位：全部（408 手算大题 + 面试口述） ｜ 形态：拓扑枚举 + ve/vl 表格手算 ｜ 更新：2026-09-30
要点速记：拓扑序列存在 ⇔ AOV 网无环；同一图拓扑序列一般不唯一。Kahn 删点法：输出顶点数小于 n 就是有环。AOE 网四件套：ve 正推取 max、vl 逆推取 min；活动 a=弧 u→v（工期 w）：e=ve(u)、l=vl(v)−w，e==l 即关键活动；关键路径 = 最长路径 = 最短工期。缩短关键活动不一定缩短工期——多条关键路径只缩一条等于白缩。

一、知识点梳理

AOV 网与拓扑排序：顶点 = 活动，有向弧 u→v 表示"v 必须排在 u 之后"。拓扑序列：把全部顶点排成一行，使每条弧都从前指向后。拓扑序列存在 ⇔ 网中无回路（环上的顶点互相等待，谁也排不进去）；同一个 AOV 网的拓扑序列一般不唯一（无先后约束的活动随便换位）。

Kahn 算法（删点法）：反复输出一个入度为 0 的顶点并删去它的出边（后继入度减 1），减到 0 就入队。结束时输出的顶点数小于 n ⇒ 有环——这是工程上判环的标准手段。逆拓扑序列：把图反转（建逆邻接表）后做拓扑排序；或对 DFS 的"退栈序"倒过来取。求 vl 要从汇点往回推，用的正是它。

AOE 网与关键路径：边 = 活动（带工期 w），顶点 = 事件。四个量：
① ve(k)：事件 k 的最早发生时刻。按拓扑序正推，源点 ve=0，取各入边的 max：ve(v) = max(ve(u)+w(u,v))。
② vl(k)：事件 k 的最迟发生时刻。按逆拓扑序回推，汇点 vl=ve（=工期），取各出边的 min：vl(u) = min(vl(v)−w(u,v))。
③ 活动 a = 弧 u→v（工期 w）：最早开始 e = ve(u)，最迟开始 l = vl(v) − w。
④ e == l 的时间余量为 0，即关键活动；关键活动串成的从源点到汇点的最长路径就是关键路径，其长度 = 工期（项目最快完工时间）。

缩短关键活动 ≠ 缩短工期：关键路径可能不止一条，只缩短其中一条上的活动，另一条立刻"补位"，工期纹丝不动；缩得太狠的活动还会失去关键地位（余量被别的路径接管）。要真正提速，得压所有关键路径共有的活动，或者多条同时压。

// Kahn 拓扑排序: 反复摘出入度为 0 的顶点. 输出个数小于 n 说明有环
static List<Integer> topoSort(int n, List<List<Integer>> adj, int[] indeg) {
    Queue<Integer> qe = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
        if (indeg[i] == 0) qe.offer(i);
    List<Integer> order = new ArrayList<>();
    while (!qe.isEmpty()) {
        int u = qe.poll();
        order.add(u);
        for (int v : adj.get(u))
            if (--indeg[v] == 0) qe.offer(v);
    }
    return order;   // order.size() 小于 n 即图中有回路
}

三、示例题目（选择题点击选项即时判分）

计算1. AOV 网含 5 个活动 A、B、C、D、E，弧为：A→B、A→C、B→D、C→E、D→E。写出所有拓扑序列并给出个数，说明枚举方法。

先自己算，再展开对答案用"删点法"分层枚举，保证不重不漏：
① A 入度为 0，必排第一；删 A 后 B、C 入度同时归零，分两个分支。
② 走 B：剩余 C、D、E，此时 D 已解锁（B 已排），剩余约束只有 C→E 和 D→E，即 E 必须最后，C、D 可换序：得 ABCDE、ABDCE（验证 ABDCE：B→D ✓、C→E ✓、D→E ✓）。
③ 走 C：剩余 B、D、E，约束链 B→D、D→E 完全串死，只有一种排法：得 ACBDE。
共 3 个：ABCDE、ABDCE、ACBDE。易错：别把 ABDEC、ACBED 数进去——它们违反弧 D→E（E 必须在 D 之后）。来源：408 统考高频题型（公开真题常考形式）。

单选3. 对一个含有回路的 AOV 网执行 Kahn 拓扑排序，结果是（  ）

A. 照常输出全部顶点，只是顺序不同
B. 输出部分顶点后停止，剩余顶点的入度都不为 0
C. 程序必然报错终止
D. 算法自动去掉环上的顶点后继续输出
答案 B。环上顶点互相等待：要删它们的入边的前驱都在环里，永远轮不到入度归零，于是队列空了、还有顶点没输出——"输出个数 < n"就是判环信号，工程上 Check DAG 就这么写。不报错、不会自动处理环。来源：面试高频改编。

多选4. 关于 AOE 网与关键活动，下列说法正确的有（  ）

A. 只要缩短任何一个关键活动的持续时间，总工期一定缩短
B. 关键路径是 AOE 网中路径长度（各活动工期之和）最大的路径
C. 同一个 AOE 网的关键路径可能不止一条
D. 时间余量 e−l 等于 0 的活动是关键活动
答案 BCD。A 错：关键路径有多条时只缩其中一条，最长的那条补位，工期不变——本页例题 2 第④问的 a3 就是现成反例；缩过头的关键活动还会自动"退籍"。要提速得压各条关键路径共有的活动。来源：408 统考高频题型（公开真题常考形式）。

面试口述5. 完整说出求关键路径的五个步骤，并补一句"为什么缩关键活动不一定缩工期"。

参考回答五步：① 对 AOE 网做拓扑排序得事件序列（顺便验证无环）；② 按拓扑序正推 ve：源点 0，每个事件取各入边 ve(前驱)+工期 的 max；③ 按逆拓扑序回推 vl：汇点 vl=ve（=工期），每个事件取各出边 vl(后继)−工期 的 min；④ 对每个活动（弧 u→v，工期 w）算 e=ve(u)、l=vl(v)−w；⑤ e==l 的活动即关键活动，串起来就是关键路径，长度即工期。补充：关键路径常有多条，只压一条上的活动另一条补位，工期不变；有效做法是压所有关键路径的公共活动，或多条同压。来源：面试高频改编。

四、易错点小结

① 有环 ⇔ 拓扑排序输出不全，判环用 Kahn 不用 DFS 硬绕；② ve 正推 max、vl 逆推 min，方向搞反全盘错；③ ve/vl 是"点"（事件）的属性，e/l 是"边"（活动）的属性：e=ve(弧尾)、l=vl(弧头)−w，弧尾弧头别对调；④ 关键路径 = 最长路径（不是最短），长度 = 工期；⑤ 数拓扑序列个数时先删点分层枚举，特别注意某条弧是否把两个"看似独立"的活动锁了先后；⑥ 拓扑序列不唯一，但约束关系个个都满足。
