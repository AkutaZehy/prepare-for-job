栈与队列

适用岗位：全部（笔试选择 + 计算 + 机试手写常客） ｜ 形态：知识点 + 手算技巧 + 图解 ｜ 更新：2026-09-30
要点速记：栈 FILO 只在栈顶进出、队列 FIFO 队尾入队头出；出栈序列合法性用"进栈—比栈顶—弹栈"模拟 30 秒判定，n 个元素合法出栈序列共 C(2n,n)/(n+1) 种（卡特兰数）；循环队列牺牲一格法：判空 rear==front，判满 (rear+1)%size==front，元素个数 (rear-front+size)%size；共享栈两栈顶相向生长，栈满条件 top1+1==top2；中缀转后缀口诀：操作数直接输出，运算符先弹"优先级不低于自己"的再进栈，右括号弹到左括号为止。

一、知识点梳理

栈（Stack）：先进后出 FILO，只在栈顶插入（push）与删除（pop）。典型应用：函数调用与返回（调用栈/栈帧）、表达式求值与括号匹配、深度优先搜索（DFS）、递归转非递归、编辑器撤销/浏览器回退。

队列（Queue）：先进先出 FIFO，队尾（rear）入队、队头（front）出队。典型应用：任务调度与消息队列（Kafka/RabbitMQ 的排队语义）、广度优先搜索（BFS）、打印任务与 IO 缓冲区。延伸：双端队列（deque）两头均可进出。

出栈序列合法性（笔试最爱）：给定进栈序列与出栈序列，判断能否实现——用模拟法：对出栈序列从左到右取"期望元素"，进栈序列依次入栈，每入栈一个就比较栈顶：等于期望元素就一直弹出并前进；若进栈序列已耗尽而栈顶仍不等于期望元素 → 非法。数量上，n 个不同元素依次进栈，合法出栈序列共 C(2n,n)/(n+1) 种（卡特兰数：n=3 有 5 种，n=4 有 14 种）。

循环队列与假溢出：顺序队列反复入队出队后，rear 到达数组末尾，但 front 前面明明有空位却"装不进"——这叫假溢出，解决办法是把数组逻辑上接成环。循环队列常用牺牲一格法区分空与满：

  • 判空：rear == front
  • 判满：(rear + 1) % size == front（牺牲一格，最多存 size−1 个元素）
  • 元素个数：(rear - front + size) % size（先加 size 再取模，避免负数）
  • 不牺牲格的变体：设计数器 count（判满 count == size），或操作标志 tag（入队后置 1、出队后置 0，则 front == rear 时看 tag：1 为满、0 为空），此时 size 个位置全部可用。
循环队列 size=6（牺牲一格最多存 5 个），下图 front=3，rear=1
下标    0    1    2    3    4    5
      +----+----+----+----+----+----+
      | x  |    |    | F  |    | R  |    F=front(队头)  R=rear(下一入队位置)
      +----+----+----+----+----+----+
元素占 3,4,5,0 共 4 个；个数 = (1-3+6)%6 = 4；判满：(1+1)%6 = 2 ≠ 3 未满

共享栈：两个栈共享一个大小为 n 的数组，栈 1 栈底在下标 0、向上生长，栈 2 栈底在下标 n−1、向下生长，两栈顶相向而行。栈 1 空 top1 == -1，栈 2 空 top2 == n；栈满：top1+1==top2（两栈顶之间只剩一格）。只有整个数组占满才溢出，空间利用率高，适合"两栈空间需求此消彼长"的场景。

共享栈：数组 [0 .. n-1]，栈1 向上长，栈2 向下长
栈1底                                              栈2底
  ↓                                                  ↓
 [ 0 ][ 1 ][ 2 ][   ][   ][   ] ... [n-1]
        top1 →                    ← top2
栈1空: top1 == -1     栈2空: top2 == n     栈满: top1 + 1 == top2

中缀转后缀（手算全过程）：后缀式又叫逆波兰式。转换规则：操作数直接输出；运算符入栈前，先把栈顶优先级不低于自己的运算符依次弹出输出（左括号挡住不弹，同级按从左到右）；左括号直接进栈；右括号把栈顶弹到左括号为止（左括号出栈丢弃）；表达式结束时把栈中剩余运算符全部弹出。后缀式求值只需一个操作数栈：操作数进栈，遇到运算符弹出两个操作数——先弹出的是右操作数——计算后把结果压回，最后栈中剩下的就是答案。

求后缀式 6 3 2 + - 3 8 2 / + *   （对应中缀 (6-(2+3))*(3+8/2)）
读 6 → 栈 [6]
读 3 → 栈 [6,3]
读 2 → 栈 [6,3,2]
读 + → 弹 2,3 → 2+3=5        栈 [6,5]     （先弹的 2 是右操作数）
读 - → 弹 5,6 → 6-5=1        栈 [1]
读 3 → 栈 [1,3]
读 8 → 栈 [1,3,8]
读 2 → 栈 [1,3,8,2]
读 / → 弹 2,8 → 8/2=4        栈 [1,3,4]
读 + → 弹 4,3 → 3+4=7        栈 [1,7]
读 * → 弹 7,1 → 1*7=7        栈 [7]   → 结果 7

递归与栈：递归调用由系统栈支撑——每层调用压入一个活动记录（参数、返回地址、局部变量），返回时弹出，"最后调用的最先返回"天然符合 FILO。递归深度受栈空间限制，过深会栈溢出（如 Java 的 StackOverflowError）；任何递归都可改写为"循环 + 显式栈"，树的遍历、汉诺塔的非递归版就是显式栈的典型应用。

三、示例题目（选择题点击选项即时判分）

单选1. 元素 a、b、c、d 依次进栈（进栈与出栈可任意交替），不可能得到的出栈序列是（  ）

A. a，b，c，d
B. d，c，b，a
C. c，a，d，b
D. b，d，c，a
答案 C。模拟：进 a、b、c 后弹出 c（输出第 1 个 ✓）；下一个期望 a，但栈顶是 b、a 被 b 压着，且进栈序列已耗尽，a 无法先于 b 出栈 → 非法。验证其余：A 进一个弹一个；B 全部进栈再依次弹出；D 进 a、b 弹 b，进 c、d 弹 d、弹 c、弹 a，均合法。技巧：出栈序列中只要存在"某元素之后有两个都比它小且顺序颠倒"即为非法（312 模式），拿不准时花 30 秒模拟最稳。来源：408 统考高频题型（公开真题常考形式）。

计算2. 循环队列用大小为 6 的数组实现（牺牲一格法），当前 front=3、rear=1。求：① 队中元素个数；② 队列当前是否已满；③ 还能连续入队几个元素？

先自己算，再展开对答案① 个数 = (rear−front+size)%size = (1−3+6)%6 = 4（占下标 3、4、5、0）。② 判满：(rear+1)%size = 2 ≠ front(3) → 未满。③ 牺牲一格法容量为 size−1 = 5，已存 4 个，还能入队 1 个；该元素入队后 rear=2，(2+1)%6=3==front，恰好判满。来源：408 统考高频题型（公开真题常考形式）。

计算3. 将中缀表达式 A + B * ( C - D ) - E / F 转换为后缀表达式，要求写出用运算符栈逐步处理的过程。

先自己算，再展开对答案 
读 A → 输出 A                    栈: []
读 + → 进栈                      栈: [+]
读 B → 输出 A B                  栈: [+]
读 * → 优先级高于 +，进栈         栈: [+, *]
读 ( → 进栈                      栈: [+, *, (]
读 C → 输出 A B C                栈: [+, *, (]
读 - → 栈顶是 ( ，进栈           栈: [+, *, (, -]
读 D → 输出 A B C D              栈: [+, *, (, -]
读 ) → 弹出 - 输出，( 出栈丢弃    输出: A B C D -        栈: [+, *]
读 - → 弹出 * 与 + （优先级≥）再进栈  输出: A B C D - * +   栈: [-]
读 E → 输出 … E                  栈: [-]
读 / → 优先级高于 -，进栈         栈: [-, /]
读 F → 输出 … F                  栈: [-, /]
结束 → 依次弹出 /、-              输出: A B C D - * + E F / -
结果：A B C D - * + E F / -。验算：两个 - 优先级最低、最后运算，且先算左边的 +（同级从左到右）✓。来源：408 统考高频题型（公开真题常考形式）。

单选4. 两个栈共享一个大小为 n 的数组空间：栈 1 栈顶指针 top1 初始为 −1、向上生长，栈 2 栈顶指针 top2 初始为 n、向下生长。栈满的判定条件是（  ）

A. top1 + top2 == n
B. top1 == top2
C. top1 + 1 == top2
D. top1 - top2 == 1
答案 C。两栈顶相向而行，中间只剩一格时数组全满：top1+1==top2。若等到 top1==top2 才算满，两栈顶已指向同一格，任何一方再进栈都会覆盖对方——正确分界就是"还差一格即满"。A、D 为杜撰条件。来源：408 统考高频题型（公开真题常考形式）。

多选5. 下列场景中，适合用"栈"这种结构（或其 FILO 语义）的有（  ）

A. 函数调用时保存返回地址与局部变量（调用栈）
B. 表达式求值与括号匹配
C. 打印任务排队，先提交的先打印
D. 递归程序改写为非递归程序
答案 ABD。调用栈保存"最后调用的最先返回"，FILO ✓；表达式求值靠运算符栈/操作数栈，括号匹配靠栈做最近匹配 ✓；递归本质就是系统栈，转非递归用显式栈保存状态 ✓。C 是"先来先服务"，属于队列（FIFO）——排队类需求一律队列，是本题干扰项。来源：面试高频改编。

四、易错点小结

① 牺牲一格的循环队列最多存 size−1 个元素，"还能入队几个"要按容量 5（size=6 时）算；② 元素个数公式 (rear−front+size)%size 中的 +size 是防负数的，忘加会算出负值；③ 后缀求值先弹出的是右操作数，减法、除法顺序最容易反（6−5 算成 5−6）；④ 出栈序列合法性别背结论，直接模拟最稳；⑤ 共享栈栈底在两端、栈顶相向，判满是 top1+1==top2 而不是 top1==top2；⑥ "排队/先来先服务"是队列不是栈，多选里常做干扰项。
