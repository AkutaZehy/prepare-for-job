最小生成树与最短路

适用岗位：全部（408 计算大题重灾区，手算迭代表必练） ｜ 形态：选边 / 松弛手算 + 算法选型口述 ｜ 更新：2026-09-30
要点速记：Prim 加点（O(n²) 与边数无关 → 稠密图）；Kruskal 加边（排序 + 并查集判环，O(e log e) → 稀疏图）；MST 树形可能不唯一但权值和一定唯一，各边权互不相同时 MST 唯一。Dijkstra 贪心不许负权边（定了的点可能被负边拉低，直接给错答案）；Floyd O(n³) 允许负权边、不允许负回路（负环上最短路不存在）。

一、知识点梳理

最小生成树（MST）：带权无向连通图中，各边权值和最小的生成树。任何生成树都恰有 n−1 条边；MST 的树形可能不唯一（等权边可互换、可拆可接），但最小权值和唯一；若各边权值互不相同，则 MST 唯一。

Prim（加点法）：从某顶点出发，每轮把"离树最近"的未入树顶点拉进树（维护每个圈外点到树的最短边）。O(n²)，开销只跟顶点数挂钩、与边数无关 → 稠密图首选。Kruskal（加边法）：把边按权从小到大排序，依次试选，两端点不在同一集合（并查集判环）就选入，选满 n−1 条为止。O(e log e)，瓶颈在排序 → 稀疏图首选。

Dijkstra（单源最短路，贪心）：dist[v] 是"当前已知最短估计"。每轮选出 dist 最小的未定顶点 u，宣布它定型（此时它不可能再被拉低——这是贪心的根基），再用 u 松弛它的出边：dist[v] = min(dist[v], dist[u]+w)。n−1 轮结束。前提是无负权边：若有负权边，"已定型"的点可能后来被负边改小，贪心直接产出错误答案（不报错，更隐蔽）。朴素实现 O(n²)。

Floyd（多源最短路，DP）：思想是"允许中转前 k 个顶点时 i→j 的最短路"，滚动掉一维后就是三重循环：d[i][j] = min(d[i][j], d[i][k]+d[k][j])，O(n³)，五个循环变量循环序不能乱。允许负权边，不允许权值和为负的回路——负环上可以无限绕圈，最短路根本不存在。

// Kruskal: 边已按权从小到大排序, 并查集判环
static int[] fa = new int[N];
static int find(int x) { return fa[x] == x ? x : (fa[x] = find(fa[x])); }

static long kruskal(int[][] edges, int n) {   // edges: {u, v, w}
    for (int i = 0; i < n; i++) fa[i] = i;
    long total = 0;
    int cnt = 0;
    for (int[] e : edges) {
        int ru = find(e[0]), rv = find(e[1]);
        if (ru != rv) {            // 不在同一集合: 选这条边不成环
            fa[ru] = rv;
            total += e[2];
            cnt++;
        }
        if (cnt == n - 1) break;   // 选满 n-1 条收工
    }
    return cnt == n - 1 ? total : -1;   // -1 表示图不连通
}
import heapq
def dijkstra(n, g, s):             # g[u] = [(v, w), ...]
    INF = float('inf')
    dist = [INF] * n
    dist[s] = 0
    h = [(0, s)]
    while h:
        d, u = heapq.heappop(h)
        if d > dist[u]:            # 堆里的过期项, 跳过
            continue
        for v, w in g[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(h, (dist[v], v))
    return dist                    # 堆优化 O((n+e)log n)

单选3. 图中存在负权边（但不存在权值和为负的回路）时，下列说法正确的是（  ）

A. Dijkstra 算法仍能得到正确的单源最短路
B. Floyd 算法仍能得到正确的任意两点间最短路
C. 一切最短路算法都会失效
D. Dijkstra 只要换一种选点顺序就能修正结果
答案 B。Floyd 是动态规划，按"允许中转的顶点集"递推，负权边不破坏递推——只要没有负回路，最短路存在且能算对。A、D 错：Dijkstra 的根基是"定型的 dist 不可能再被拉低"，负权边恰好破坏它，问题出在贪心本质，换选点顺序也救不了（此时该用 Bellman-Ford/SPFA）。C 错得离谱。来源：牛客经典题。

多选4. 关于最小生成树，下列说法正确的有（  ）

A. n 个顶点的连通图的任何生成树都恰好有 n−1 条边
B. 最小生成树的树形可能不唯一，但最小权值和一定唯一
C. 若图中各边权值互不相同，则最小生成树唯一
D. Prim 适合稀疏图，Kruskal 适合稠密图
答案 ABC。D 把结论说反了：Prim O(n²) 只跟顶点数挂钩、不看边数，稠密图（边多）才不亏；Kruskal O(e log e) 要先排序所有边，边少才省。B 与 C 搭档记忆：互异必唯一，有等权才可能不唯一，但和永远唯一。来源：面试高频改编。

面试口述5. 拿到一张图，怎么判断该用 Prim 还是 Kruskal？最短路那边又怎么选？

参考回答先看稠密还是稀疏：边数接近 n² 的稠密图用 Prim——它 O(n²) 只扫顶点，边再多也不加价；边数远小于 n²（比如 O(n) 级）的稀疏图用 Kruskal——排序 + 并查集 O(e log e)，边少时非常快。最短路对应地选：单源、稠密图用朴素 Dijkstra O(n²)；单源、稀疏图用堆优化 Dijkstra O((n+e)log n)；要多源且 n 较小（如 n ≤ 500）直接 Floyd O(n³)，五行代码换全部点对。顺带交代前提：图里有负权边就别用 Dijkstra，有负回路则最短路本身不存在。来源：面试高频改编。

四、易错点小结

① Prim 加点、Kruskal 加边，别背反；② "MST 不唯一"指树形，权值和永远唯一；③ Dijkstra 遇负权边不报错、直接给错答案，笔试给个负边小图要能举反例；④ Floyd 循环 k 必须在最外层，k 是"允许中转的顶点"不是路径端点；⑤ 负回路 ⇒ 最短路不存在，不是"等于 0"也不是"随便算"；⑥ 生成树边数 n−1 与权值正负无关，负权边的 MST 照选。
